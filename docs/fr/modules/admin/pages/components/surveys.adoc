= Enquête

Le volet Enquête permet aux gens de répondre aux questionnaires. Ceci est utile lorsqu'une organisation souhaite recevoir des commentaires privés
, bien qu'il soit également possible de publier les réponses manuellement. Il permet de définir un ensemble de questions avec plusieurs types de réponses.

À partir de ce point de départ, il pourrait y avoir d'autres configurations, telles que:

* si la réponse est limitée à une période de temps
* quels types de réponses devraient avoir les questions, comme les courtes (une seule ligne), longues (plusieurs lignes), simples ou multiples,
triant à travers une liste, etc.
* s'il y a une validation de réponse comme le nombre maximum de caractères doit avoir une réponse
* s'il y a un nombre maximum d'options à sélectionner dans plusieurs options questions

Quelques exemples d'utilisation de ce composant :

* https://consultation.quebec.ca/processes/donneesquebec/f/82/[Données Québec: participer à son amélioration! (Données Québec : participez à son amamélioration!) dans les consultations du Quebec]
* https://meta.decidim.org/conferences/decidimfest2020/f/1403/?locale=fr[Enquête d'évaluation DecidimFest2020]

image:components/surveys/example01.png[Exemple d'une enquête]

Pour configurer le composant Enquête:

. Se connecter en tant qu'administrateur
. Aller au panneau d'administration
. Dans la barre latérale principale, cliquez sur le bouton de l'espace dont vous voulez configurer la fonctionnalité.
Par exemple, il peut s'agir de "Concertations", d'"Assemblées" ou de "Conférences".
. Aller dans les fonctionnalités
. Cliquez sur le bouton "Ajouter une fonctionnalité"
. Cliquez sur "Enquête"
. Remplissez le formulaire xref:_add_component[Ajouter une fonctionnalité]

Une fois qu'une enquête a déjà reçu une réponse de certains utilisateurs, il n'est pas possible de modifier ses questions, car cela affecterait l'intégrité
des réponses. S'il est nécessaire de modifier les questions, alors il est nécessaire de créer une nouvelle enquête et de dépublier celle originale.

== Nouveau formulaire d'enquête

Lorsque vous créez une nouvelle enquête, vous devrez remplir le formulaire avec les champs suivants :

image:components/surveys/edit_form.png[Modifier le formulaire d'enquête]

NOTE: Avez-vous des enquêtes répétitives ? Par exemple, le même formulaire de rétroaction pour chaque processus ? Vous pouvez avoir une enquête que
est copié et est utilisé comme plan pour vous permettre de ne pas avoir à configurer manuellement la même enquête à chaque fois. En savoir plus
sur xref:_templates[Templates].


.Nouveau formulaire d'enquête
|===
|Champ |Type |Description

|Titre
|Obligatoire
|Quel est le titre de cette enquête. Par exemple, "Feedback"

|Description
|Facultatif
|Quelle est la description de cette enquête.

|Conditions d'utilisation
|Obligatoire
|Les conditions légales auxquelles les participants doivent consentir pour répondre à l'enquête.
|===

En bas de ce formulaire il y a un bouton qui vous permet de "Ajouter une question".

image:components/surveys/add_question_button.png[]

Vous pouvez ajouter plusieurs questions par sondage, et les réorganiser ou les supprimer. Il est également possible d'ajouter des séparateurs entre les questions.

Chaque question doit avoir une instruction et un type au minimum.

image:components/surveys/question_form.png[]


.Ajouter un formulaire de question
|===
|Champ |Type |Description

|Relevé
|Obligatoire
|La question elle-même. Par exemple, "Quelle est votre catégorie d'âge?"

|Description
|Facultatif
|Explication de la question posée.

|Mandatory
|Facultatif
|Vérifiez si cette question est requise pour répondre à la réponse.

|Limite de caractères
|Facultatif
|Combien de caractères a comme maxime la réponse à cette question. Laisser à 0 si aucune limite. Compatible avec les types de questions à réponse courte et longue.

|Type
|Obligatoire
|Une des réponses suivantes : réponse courte, réponse longue, option simple, option multiple, tri des fichiers, matrice (option unique)
ou Matrice (option multiple). Voir xref:_question_types[Types de questions] pour plus d'informations.
|===

Selon le type de question, il est possible d'ajouter des validations aux réponses, comme si la question est obligatoire (les participants
devront fournir une réponse pour soumettre le formulaire) ou si la réponse est limitée à un certain nombre de caractères au maximum en
réponses courtes et longues.

== Modèles

For the cases where administrators need to define multiple surveys that are mostly the same but used in different contexts,
it's possible to define a template. Quand il y en a un pour une enquête, alors il demandera de sélectionner le modèle et de créer
l'enquête basée sur celui-ci ou dans l'autre main s'il n'y a pas besoin d'utiliser un modèle, alors il est possible de passer la sélection du modèle
.

image:components/surveys/edit_questionnaire.png[Choisir le formulaire de modèle]

== Exporter les réponses

Il est possible d'exporter les réponses des participants à l'enquête dans différents formats : CSV, JSON, XLSX (Excel) ou PDF.

Note that the platform doesn't handle the answers processing nor presenting results or summary to the users, that need to be
done externally.
