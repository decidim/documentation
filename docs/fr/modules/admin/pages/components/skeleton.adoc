Pour configurer le composant Skeleton :

. Se connecter en tant qu'administrateur
. Aller au panneau d'administration
. Dans la barre latérale principale, cliquez sur le bouton de l'espace dont vous voulez configurer la fonctionnalité.
Par exemple, il peut s'agir de "Concertations", d'"Assemblées" ou de "Conférences".
. Aller dans les fonctionnalités
. Cliquez sur le bouton "Ajouter une fonctionnalité"
. Cliquez sur "Skeleton"
. Remplissez le formulaire xref:_add_component[Ajouter une fonctionnalité]

== Ajouter une fonctionnalité

image:components/skeleton/component.png[Ajouter un formulaire de composant]


.Ajouter un composant : formulaire de squelette
|===
|Champ |Type |Description

|Nom
|Obligatoire
|Quel est le titre de cette fonctionnalité. Par exemple, "Skeletons"

|Rang d'affichage
|Facultatif
|Quel ordre aura-t-il en relation avec les autres squelettes. Avoir un nombre inférieur signifie un rang d'affichage plus élevé.
Par exemple, si vous avez deux squelettes, "Skeleton a" avec le poids "10" et "Skeleton b" avec le poids "0", puis "Skeleton b" sera d'abord lors de la commande.
|===


.Ajouter un composant : Formulaire de squelette - Paramètres globaux
|===
|Champ |Type |Description

|Portées activées
|Facultatif
|Cochez cette case si vous voulez que le filtrage des portées dans ce composant.

|Secteur
|Facultatif
|Ce composant appartient à xref:admin:scopes.adoc[Scope].

|Portée générale
|Facultatif
|

|Commentaires activés
|Facultatif
|Si vous voulez avoir des commentaires dans les rencontres.

|Longueur maximale des commentaires
|Facultatif
|Quelle est la limite de caractères que les participants auront quand ils feront des commentaires. Laisser 0 pour la valeur par défaut.

|Les autorisations d'actions peuvent être définies pour chaque squelette
|Facultatif
|Si vous voulez être en mesure de définir les permissions pour chaque squelette. La plupart du temps, vous voudrez laisser cette option désactivée.

|Annonce
|Facultatif
|Une annonce générale qui sera visible sur la page d'accueil des squelettes généraux.
|===

xref:admin:spaces/processes.adoc[Processus participatif], vous pouvez également définir différents comportements par étape.
