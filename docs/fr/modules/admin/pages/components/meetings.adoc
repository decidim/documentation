= Réunions

Les réunions sont le lieu où les gens se réunissent pour discuter ou informer sur un sujet donné. Toutes les réunions ont un emplacement
(où la réunion aura lieu) et la date et l'heure de début et de fin (quand la réunion aura lieu).

Quelques exemples d'utilisation de ce composant sont :

* https://www.decidim.barcelona/processes/PAM2020/f/3734/[Procédures participatiu del Programa d'Actuació Municipal (PAM) 2020-2023]
dans https://www.decidim.barcelona/[Decidim Barcelona]
* https://lejourdapres.parlement-ouvert.fr/processes/ateliers/f/14/[Les ateliers] in https://lejourdapres.parlement-ouvert.fr/[Le jour d'après]

== Types de fichiers

En ce qui concerne le *emplacement*, selon la configuration du composant, vous pouvez avoir:

* Réunions en personne : où vous vous réunissez à un endroit donné
* Réunions en ligne : où vous vous réunissez en utilisant un service externe (par exemple Jitsi Meet)

Selon le *auteur* (qui est la personne qui fait l'appel) :

* Réunions officielles : réunions créées par l'organisation (créées par un administrateur via le panneau)
* Réunions de citoyens : réunions créées par un utilisateur (un utilisateur ou un groupe d'utilisateurs).

== Ajouter le composant

image:components/meetings/component.png[Ajouter un composant de réunions]

Pour ajouter le composant, vous devez :

. Se connecter en tant qu'administrateur
. Aller au panneau d'administration
. Dans la barre latérale principale, cliquez sur le bouton de l'espace dont vous voulez configurer la fonctionnalité.
Par exemple, il peut s'agir de "Processus", d'"Assembles", ou de "Conférences"
. Aller dans les fonctionnalités
. Cliquez sur le bouton "Ajouter une fonctionnalité"
. Cliquez sur "Réunions"
. Remplissez le formulaire xref:_add_component[Ajouter une fonctionnalité]

== Créer une nouvelle réunion

=== Réunions de citoyens

Les réunions peuvent être créées par les participants si le paramètre est "Les participants peuvent créer des réunions" est vérifié.

If a participant belongs to a xref:admin:participants/groups.adoc[user group], then they will be able to create meetings as that group also.

image:components/meetings/new_meeting_form_frontend01.png[Créer un nouveau formulaire de réunion (frontend)]
image:components/meetings/new_meeting_form_frontend02.png[Créer un nouveau formulaire de réunion (frontend)]


.Créer une réunion - Formulaire du frontend
|===
|Champ |Type |Description

|Titre
|Obligatoire
|Quel est le titre de cette réunion.

|Description
|Obligatoire
|Une description de ce qui sera discuté lors de cette réunion, comme les sujets.

|Type
|Obligatoire
|Choisissez une option entre "En personne", "En ligne" ou "Booth"

|Adresses
|Requis si le type de réunion est "En personne" ou "Booth"
|Adresse : utilisée par le géocodeur pour trouver l'emplacement

|Localisation
|Obligatoire
|Emplacement: message adressé aux utilisateurs impliquant le point de rencontre à

|Astuces de localisation
|Facultatif
|Indices de localisation : informations complémentaires. Exemple: le plancher du bâtiment

|URL de la réunion en ligne
|Facultatif
|Quelle URL aura lieu la réunion.

|Afficher l'iframe intégré pour cette URL
|Facultatif
|Si oui ou non l'iframe pour cette URL de vidéoconférence. Seules quelques services permettent l'intégration (c.-à-d. YouTube, Twitch...)

|Heure de début
|Obligatoire
|Quel jour et quelle heure la réunion va commencer. Format attendu : jj/mm/aaaa hh:ii

|Heure de fin
|Obligatoire
|Quel jour et quelle heure la réunion va commencer. Format attendu : jj/mm/aaaa hh:ii

|Catégorie
|Facultatif
|Quelle catégorie a la réunion. Utilisé pour le filtrage dans la liste des réunions.

|Type d'inscription
|Obligatoire
|Choisissez une option entre "Inscription désactivée", "Sur cette plateforme", ou "Sur une plateforme différente"

|Emplacements disponibles pour cette réunion
|Requis si "Type d'enregistrement" est "Sur cette plateforme"
|Combien de places sont disponibles pour cette réunion ? Laisser à 0 si vous avez un nombre illimité d'emplacements disponibles

|Conditions d'inscription
|Requis si "Type d'enregistrement" est "Sur cette plateforme"
|Quels sont les termes des services que les participants doivent accepter pour s'inscrire ou participer à la réunion. Spécifique aux "Réunions de citoyens"

|URL d'enregistrement
|Requis si "Type d'enregistrement" est "Sur une plateforme différente"
|Doit être une URL. Lien vers le service externe que vous utilisez pour vous inscrire.

|Créer une réunion en tant que
|Requis si le participant appartient à un groupe
|With which identity they want to create this meeting: as their user or as a group that they are reprensenting?
|===

Après avoir créé la réunion, les participants peuvent également éditer et xref:components/meetings/close.adoc[close] le.

== Fonctionnalités de réunions

Il existe différents types de fonctionnalités qui peuvent être activées lors de réunions, telles que:

* xref:admin:admin:components/meetings/registrations.adoc[Registrations]: pour gérer comment particpant peut s'inscrire pour assister à la réunion.
* xref:admin:components/meetings/agenda.adoc[Agenda]: pour avoir vu les sujets qui seront discutés dans la réunion par minutes.
* xref:admin:admin:components/meetings/polls.adoc[Polls]: pour un vote rapide pendant une réunion en ligne.
* xref:admin:components/meetings/close.adoc[Close]: pour ajouter le rapport final sur ce qui a été discuté lors de la réunion.

== Réunions en ligne

Selon le moment et la configuration de la réunion, il peut y avoir différents messages qui seront affichés aux participants.

. Si l'URL de la réunion en ligne est définie, il y aura un message qui dit "Lien disponible bientôt"
image:components/meetings/online_meeting_available_soon.png[Réunion en ligne disponible bientôt]
. Si l'URL de la réunion en ligne est définie, et quelques minutes avant le début de la réunion, le mailage dira "Le lien pour rejoindre
la réunion sera disponible quelques minutes avant de commencer"
image:components/meetings/online_meeting_available_avant. ng[Réunion en ligne disponible avant le début]
. Si l'URL de la réunion en ligne est définie, et que l'heure de début de la réunion est arrivée, alors il y aura un message qui dit
que « la réunion se déroule en ce moment », avec un lien pour rejoindre la réunion.
image:components/meetings/online_meeting_happening.png[Réunion en ligne disponible avant le début]
