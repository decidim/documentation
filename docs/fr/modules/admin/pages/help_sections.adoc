= Sections d'aide

La première fois qu'un visiteur se rend sur une page Espace où il verra une boîte d'information sur ce qu'est cet espace.

Voici comment la boîte d'information est affichée aux participants et aux visiteurs :

image:help_sections_frontend.png[Sections d'aide : frontend]

Ils peuvent masquer cette case en cliquant sur le bouton de fermeture [X]. Ceci est mémorisé par l'application. Ils peuvent à nouveau ouvrir cette boîte en cliquant dans [Aide: ?].

image:help_sections_frontend_hide.png[Sections d'aide : cacher]

Comme c'est quelque chose qui dépend de votre installation, un administrateur peut personnaliser ces *sections d'aide*, en les adaptant à vos besoins.

image:help_sections_backend.png[Sections d'aide : backend]

== Désactiver

Vous pouvez désactiver ces boîtes d'information en laissant tout le contenu vide pour chaque langue :

image:help_sections_disable_backend.png[Désactiver la section d'aide dans l'administrateur]

image:help_sections_disable_frontend.png[Section d'aide désactivée]
