= Groupes d'utilisateurs

Un groupe d'utilisateurs est un groupe de participants. Selon l'installation et le contexte de l'organisation, il pourrait être désactivé. Ceci est activé ou désactivé dans le tableau de bord de l'administration, dans Paramètres -> Configuration -> Modifier l'organisation -> Activer les groupes.

== Création

Cette action est faite par **un participant**. They need to go to their profile and in the sidebar there's a button that says "Create group":

== Adhésion

Une fois qu'un groupe a été créé, il est possible d'inviter des participants à devenir membres du groupe. Une fois qu'un participant a accepté de faire partie de ce groupe, il peut devenir administrateur.

Les actions qui peuvent être effectuées par un participant dans le groupe d'utilisateurs sont:

* Modifier le profil du groupe
* Gérer les membres
* Gérer les administrateurs
* Invite participant
* Quitter le groupe

image:user_group_invite_participant.png[Groupes d'utilisateurs : inviter un participant]

== Vérifications de groupe

image:admin_user_group_verification.png[panneau d'administration: vérification des groupes d'utilisateurs]

Cette action est effectuée par **un administrateur**. Un groupe peut être:
* En attente
* Vérifié
* Rejeté

Cela peut être fait avec les boutons de la barre latérale :

image:admin_user_group_verification_actions.png[Panneau d'administration: actions de vérification des groupes d'utilisateurs]

Lorsqu'un groupe d'utilisateurs est en attente, il peut être vérifié ou rejeté. Une fois vérifié, il peut être rejeté et une fois rejeté, il peut être vérifié.

Si vous voulez vérifier plusieurs groupes d'utilisateurs en même temps, vous pouvez le faire avec l'option "Vérifier via CSV":

image:admin_user_group_verification_csv.png[panneau d'administration: vérification de groupe d'utilisateurs CSV]

....
Téléchargez votre fichier CSV. Il doit avoir les courriels officiels des groupes de votre organisation dans la première colonne du fichier, sans en-têtes. Seuls les groupes qui ont confirmé leur adresse e-mail et qui ont un e-mail apparaissant dans le fichier CSV seront validés.
....

Une fois qu'un groupe est vérifié, cela est visible publiquement dans son pseudo dans la plateforme et il y a un message dans son profil : « Ce groupe est publiquement vérifié, son nom a été vérifié pour correspondre à son vrai nom".

image:user_group_verified.png[Groupe d'utilisateurs : icône vérifiée]
