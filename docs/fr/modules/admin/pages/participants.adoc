= Participants

Parfois, en tant qu'administrateur, vous aurez besoin de faire certaines tâches avec les participants, parmi eux:

* Donner des permissions aux autres administrateurs pour qu'ils puissent gérer le contenu de la plateforme
* Vérifier les groupes d'utilisateurs (organisations ou collectives)
* Pour vérifier les participants
* Reconnaître qu'un participant a un statut spécial dans la plateforme, avec les Officialisations
* Pour authentifier qu'une personne a le droit de voter, avec des autorisations
* Pour contacter un participant

Vous pouvez accéder à cette section dans la barre latérale principale du panneau d'administration.

image:participants_menu.png[Menu des participants]
