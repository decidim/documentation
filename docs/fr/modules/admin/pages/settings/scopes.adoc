= Secteurs

== En bref

Les champs d'application sont l'ensemble des territoires ou des sujets qu'une Organisation possède. Un secteur peut avoir des secteurs enfants.

Par exemple, dans le cas de la ville de Barcelone, les périmètres correspondent à ses quartiers, et les enfants d'un quartier
sont ses quartiers.
Les secteurs peuvent également avoir des types, qui peuventt être configurés, par exemple, en secteurs thématiques et territoriaux.

La plupart des fonctionnalités et des espaces de Decidim vous permettent de configurer des Secteurs d'une manière ou d'une autre.

=== Content filtering

La plupart des espaces et des fonctionnalité permettent à unx administrateur·ice ou à unx participant·e·x de les associer à un secteur.
Cela permet de filtrer par secteurs lors de leur exploration.

image::settings/scopes_filter_assemblies.png[Assemblies scopes filtering]

image::settings/scopes_filter_processes.png[Processes scopes filtering]

Quelques exemples :

* Avec le module Suivi, il est possible de filtrer les Réalisations
* Les Assemblées et les Processus peuvent avoir des Secteurs. Il est ainsi posiible defiltrer plusieurs assemblées dans la page principale de la liste (/assemblées ou /processus). Celles-ci peuvent être masquées avec le "Activer les filtres d'espace participatif" dans xref:admin:settings/configuration.adoc[configuration].
* Le filtrage dans la barre latérale est également disponible dans certains composants, où vous pouvez contrôler si ces filtres sont affichés avec la case à cocher "Scopes activés" dans les paramètres. Il active également le sélecteur de portée dans le formulaire de création de ressource.

Vous pouvez également configurer un espace participatif de sorte que le filtrage ne concerne qu'une seule portée et ses portées enfants. Par exemple, imaginons que votre organisation ait 3 secteurs différents pour 3 villes, chacune ayant des secteurs enfants pour les quartiers urbains.
Dans un espace participatif qui ne concerne qu'une seule des villes, vous pouvez seulement sélectionner cette portée et ses enfants afin que les utilisateurs ne voient pas les portées des autres villes dans les options de filtre.
