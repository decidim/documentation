= Mes intérêts

Dans cette section, les participants peuvent choisir les intérêts sur lesquels ils doivent recevoir plus de renseignements.

Par défaut, ce qu'ils voient ici est une liste de tous les xref:admin:scopes.adoc[Scopes] de l'organisation. Ces sélections
peuvent être utilisées par les administrateurs lors de la segmentation de xref:admin:newsletters.adoc[Newsletters].

image:features/my_account/my_interests.png[Mes intérêts]

Pour aller à cette section :

. Se connecter en tant que participant
. Cliquez dans le nom du participant dans l'en-tête
. Cliquez dans "Mon compte"
. Cliquez dans "Mes intérêts" dans la barre latérale
