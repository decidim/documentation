= Commentaires

== En bref

Les commentaires sont des messages publics qui permettent aux participant·e·x·s de partager des informations ou des opinions à propos d'une proposition, un débat, une réunion, une initiative, etc.

NOTE: Les commentaires doivent être activés par les administrateur·ices, sinon les participant·e·x·s ne sont pas en mesure de commenter. Pour savoir comment activer les commentaires dans une fonctionnalité, se référer à l'article xref:features:components.adoc[Fonctionnalités].

image::features/comments/nested_comment.png[Comments example]

== Configuration

=== Créer un commentaire

. Accéder au contenu que vous souhaitez commenter
. Aller au bas de la page
. Remplir le champ "Ajouter un commentaire" et laisser votre commentaire

image::features/comments/form.png[Comments form]

Les commentaires permettent les actions suivantes :

.Actions de commentaire
[cols="10h,~,~,~"]
|===
|Type |Description |Syntaxe |Exemple

|Mention
|Mentionner unx utilisateur·ice ou un groupe d'utilisateur·ices. Iels recevront une notification pour la mention.
|@pseudonyme
|@carmelia_hudson

|Hashtag
|Les hashtags sont redirigés sur la page de recherche générale xref:admin:features/search.adoc[page de recherche]

|Les hashtags sont redirigés sur la page de recherche générale xref:admin:features/search.adoc[page de recherche]

=== Actions

Les participant·e·x·s peuvent interagir avec les commentaires de différentes manières.

* Tout le monde peut les trier et afficher et masquer le fil de réponses.
* Les participant·e·x·s peuvent également répondre aux commentaires, leur donner un vote positivement ou négativement, les signaler ou obtenir le lien vers le commentaire.
* Les auteur·ices de commentaires peuvent également modifier et supprimer leurs propres commentaires.

Certaines actions sont accessibles directement sur le commentaire, alors que d'autres sont accessibles dans le menu en cliquant sur les trois points à côté d'un commentaire.

image::features/comments/actions.png[Comments actions]

==== Trier

Les participant·e·x·s peuvent trier les commentaires selon :
* La meilleure note : les commentaires avec le plus de votes positifs apparaissent en premier dans la liste
* La date : les commentaires les plus récents apparaissent en premier.
* Ancienneté : les commentaires plus anciens apparaissent en premier.
* Plus discuté : les commentaires avec avec le plus de réponses apparaissent en premier.

image::features/comments/order_by.png[Order comments]

Il est également possible de masquer les réponses pour ne pas afficher le fil de commentaires en entier.

==== Répondre

En cliquant sur le bouton « Répondre » sous un commentaire, les participant·e·x·s peuvent répondre à d'autres participant·e·x·s et avoir des discussions publiques.
Les commentaires peuvent être imbriqués jusqu'à quatre niveaux. Au quatrième niveau, le bouton "Répondre" n'est plus disponible.

image::features/comments/anidation_levels.png[Nested comments]

==== Vote positif / négatif

Les participant·e·x·s peuvent soutenir les commentaires en cliquant sur l'icône "Pouce vers le haut" en bas à droite de chaque commentaire.
Il leur permet de participer et de donner leur avis, sans devoir répondre à un commentaire.

==== Signaler

Veuillez lire l'article xref:admin:moderations/reported_content.adoc[Contenu signalé] pour en savoir plus sur le contenu du rapport.

==== Obtenir le lien

En cliquant sur l'élément "Obtenir un lien", les participant·e·x·s sont redirigé·e·x·s vers l'URL dédiée au commentaire.
Iels peuvent ensuite partager ce lien avec d'autres personnes, qui les mène directement à un commentaire.
Un message est affiché pour avertir lae visiteur·euse qu'iel voit un seul commentaire, avec un lien pour voir tous les autres commentaires.

image::features/comments/single_comment.png[Edited comment]

==== Modifier

Les participant·e·x·s peuvent modifier leurs commentaires. Une mention « Modifié » apparaît sur leur commentaire pour indiquer aux autres participant·e·x·s
que ce contenu a été modifié.

Les commentaires ne contiennent pas l'historique des versions modifiées.

image::features/comments/edited_comment.png[Edited comment]

==== Supprimer

Une fois supprimé, un commentaire n'est plus visible, et un message indique la date à laquelle il a été supprimé.

image::features/comments/deleted_comment.png[Deleted comment]
