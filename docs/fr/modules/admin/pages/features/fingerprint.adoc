= Empreinte digitale

Bien que la plate-forme doive afficher la version xref:admin:features/versions. doc[Versions] pour presque tous les contenus, il serait
encore possible de manipuler le contenu en éditant directement la base de données.

Étant donné l'atténuation de ce risque, la plate-forme montre une empreinte digitale pour certains domaines importants, par exemple un organisme de proposition et un titre.

image:features/fingerprint/modal.png[Vérifier le modal]

Son but est de fournir un moyen de donner un « reçu » informel à un participant pour qu'il puisse détecter des manipulations. Une empreinte digitale est
une représentation hachée du contenu. Il est utile de s'assurer que le contenu n'a pas été altéré, car une seule modification
donnerait une valeur totalement différente. Il est calculé à l'aide d'un algorithme de hachage SHA256. Afin de le répliquer
vous-même, vous pouvez utiliser un http://www.md5calc.com/sha256[calculateur MD5 en ligne] et copier-coller les données source.

== Vérifier l'empreinte digitale

. Aller au contenu que vous voulez vérifier l'empreinte digitale
. Cliquez sur le lien "Vérifier l'empreinte digitale" dans la barre latérale
image:features/fingerprint/sidebar.png[Vérifier le lien d'empreinte dans la barre latérale]
. Suivez les instructions modales

image:features/fingerprint/md5calc.png[capture d'écran MD5calc.com]

Il est possible de vérifier l'empreinte digitale avec d'autres outils, comme l'outil en ligne de commande sha256sum.

echo -n '{"body":{"en":"<p><strong>**Is your feature request related to a problem?
