= Statistiques

Decidim fournit des statistiques générales sur l'ensemble de la plate-forme et différents espaces participatifs peuvent également fournir des statistiques relatives à cet espace participatif seulement. Ce sont des numéros génériques qui indiquent l'activité du site Web et peuvent également encourager d'autres personnes à rejoindre la plateforme comme elles le voient populaire.
