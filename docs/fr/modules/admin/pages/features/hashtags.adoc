= Hashtags

Les hashtags sont un moyen de catégoriser le contenu globalement sur la plate-forme et de le rendre plus facile à rechercher à travers ces catégorisations. Il permet à différents contenus connexes d'être facilement découverts sous le même sujet. Des fonctionnalités similaires sont souvent utilisées sur d'autres plates-formes de médias sociaux.

Les hashtags peuvent être définis pour différents enregistrements au sein de la plate-forme, tels que les espaces participatifs. Ils peuvent également être générés pour le contenu créé par les participants afin de faciliter la découverte du contenu. Certains composants peuvent également permettre de définir des hashtags suggérés ou des hashtags spécifiques pour tous les enregistrements soumis par les participants.
