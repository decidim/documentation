= Notifications

Dans cette section, les participants peuvent voir les notifications que le système leur a envoyées. Par exemple, si le participant suit un espace participatif ou une proposition, ils reçoivent des notifications connexes sur les actions qui se produisent dans ces sections de la plate-forme.

Cette section est accessible par l'icône de la cloche dans la barre d'en-tête de la plate-forme. L'icône de cloche montre en surbrillance quand il y a des notifications et un assombrissement quand il n'y a pas de nouvelles notifications pour l'utilisateur en ce moment.
