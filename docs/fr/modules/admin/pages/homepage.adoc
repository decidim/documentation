= Page d'accueil

include::partial$under-construction.adoc[]

Vous pouvez contrôler comment c'est la page d'accueil de votre organisation. Pour ce faire, vous avez la section Paramètres -> Page d'accueil à travers le panneau d'administration :

image::admin_homepage.png[Decidim Admin Homepage]

---

== Comment cela fonctionne

Cela signifie que chaque section de la page d'accueil est appelée **bloc de contenu**.

Par exemple, c'est le bloc de contenu *Comment participer* :

image::homepage_how_to_participate.png[How to participate example]

Pour gérer ces contenus, vous devez faire glisser et déposer le contenu entre les deux colonnes, sur la gauche sont les actifs et à droite sont les blocs de contenu inactifs.
