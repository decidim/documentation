= Fonctionnalités

== En bref

Comme expliqué dans la page d'introduction xref:admin:index.adoc[, pour comprendre comment Decidim fonctionne, il faut distinguer les *espaces* des *fonctionnalités*.
Les espaces participatifs sont des canaux auxquels les citoyen·ne·x·s peuvent participer pour la prise de décisions publiques, alors que les fonctionnalités participatives sont des mécanismes qui permettent une interaction entre des utilisateur·ices de la plateforme et les différents espaces participatifs.

Toutes les fonctionnalités peuvent être activées dans chacun des espace, par exemple vous pouvez activer trois fonctionnalités Propositions dans une même concertation, ou avoir toutes les fonctionnalités
actives dans un espace d'assemblée.

include::partial$components_list.adoc[]

=== How to find it?

Pour configurer les fonctionnalités, cliquer sur "Fonctionnalités" dans un espace participatif.

image::spaces/components/components.png[Components of space]

Ensuite, il est possible de gérer les fonctionnalités déjà ajoutées, les configurer et en ajouter de nouvelles, etc.

== Configuration

=== Gérer les fonctionnalités

Toutes les fonctionnalités se trouvent dans la liste dans le panneau d'administration, comprenant :

* *Nom de la fonctionnalité* : titre de la fonctionnalité, donné lors de la création ou de la modification.
* *Type de fonctionnalité* : type de la fonctionnalité.
* *Secteur des fonctionnalités* : dans un même espace, les fonctionnalités peuvent avoir des secteurs différents.

=== Créer une fonctionnalité

Pour configurer une nouvelle fonctionnalité, cliquer sur *Ajouter une fonctionnalité* en haut à droite de l'écran et sélectionner le type de fonctionnalité souhaité.

image::spaces/components/components_new_dropdown.png[Add a component in a space]

=== Actions

.Actions des fonctionnalités dans la liste des fonctionnalités
[cols="10h,20h,~"]
|===
|Icône |Nom |Définition

|image:icons/action_edit.png[Icône Gérer]
|Gérer
|Gérer toutes les ressources à l'intérieur d'une fonctionnalité. Par exemple, toutes les propositions d'une fonctionnalité de proposition, les rencontres
dans une fonctionnalité de rencontre, etc.

|image:icons/action_share.png[Icône Partager]
|Partager
|Partager de manière privée avant de publier la fonctionnalité. Utile pour obtenir des avis d'autres personnes de votre organisation.

|image:icons/action_configure.png[Icône Configurer]
|Configurer
|Pour configurer un composant avec des règles spécifiques, par exemple, dans le cas de réunions :
sont des commentaires activés, les participants peuvent créer des réunions ou pas, etc.

|[Icône de publication]
|Publier
|Publier un composant. Cela signifie que le composant est alors visible au public.

|[Dépublier l'icône]
|Dépublier
|Dépublier un composant. Cela signifie que le composant est alors invisible au public.

|image:icons/action_preview.png[Icône d'aperçu]
|Aperçu
|Pour prévisualiser l'espace avant qu'il ne soit publié.

|image:icons/action_permissions.png[Icône Autorisations]
|Autorisations
|Pour configurer quel xref:customize:authorizations.adoc[Authorization] est nécessaire pour effectuer certaines actions dans
ce composant. Par exemple, dans le cas des propositions, dont la vérification est nécessaire pour créer une nouvelle proposition ou
pour apporter un soutien.

|image:icons/action_delete.png[Supprimer l'icône]
|Supprimer
|Supprimer ce composant. If there are content inside, most of the components don't let you delete them so it doesn't break
relations with other resources. Dans ces cas, il est recommandé de dépublier simplement le composant.
|===
