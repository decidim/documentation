= Moderação

Moderações dentro de um espaço trabalham como xref:global_moderations.adoc[Moderações globais].

A principal diferença é que, se você quiser, você pode convidar Moderadores deste espaço
específico e eles só terão acesso aos relatórios feitos para
conteúdo deste espaço.

Moderadores são um tipo de administradores de espaço. Veja-se, por exemplo, para xref:spaces/processes/admins.adoc[participatory processes admins].
