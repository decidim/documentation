= Componentes

$components_listparcial .adoc[]

Para configurar componentes, clique em *Componentes* no submenu de espaço. Uma lista aparecerá mostrando os componentes
que já foram configurados para o espaço.

image::spaces/components.png[Components of space]

Para configurar um novo componente, clique em *Adicionar componente* da parte superior direita da tela e selecione o tipo de componente
que você deseja configurar a partir do menu suspenso.

image::spaces/components_new_dropdown.png[Add a component in a space]

== Ações.

|===
|Ícone |Nome: |Definição

|imagem:action_manage.png[Gerenciar ícone]
|Administrar
|Para gerenciar todos os recursos dentro de um componente. Por exemplo, todas as propostas de um componente Propostal, as Reuniões
em um componente de reunião, etc.

|image:action_publish.png[Ícone de publicação]
|Publicar
|Para publicar um componente. Isso significa que o componente ficará visível para o público.

|imag:action_unpublish.png[Remover ícone de publicação]
|Despublicar
|Para cancelar a publicação de um componente. Isso significa que o componente ficará invisível para o público.

|image:action_configure.png[Configurar ícone]
|Configurar
|Para configurar um componente com as regras específicas. Depende do tipo de componente. Por exemplo, no caso das Reuniões:
estão habilitados, os participantes podem criar reuniões, etc.

|imagem:action_permissions.png[Ícone de permissões]
|Permissões
|Para configurar qual xref:Personalize o :authorizations.adoc[Authorization] será necessário para fazer certas ações no
este componente. Por exemplo, no caso das propostas, quais Verificação será necessária para criar uma nova proposta ou
para dar suporte.

|imagem:action_share.png[Ícone de compartilhamento]
|Compartilhar
|Para compartilhar em particular antes de publicar este componente. Útil para revisão com outras pessoas dentro de sua organização.

|imagem:action_delete.png[Excluir ícone]
|excluir
|Para excluir este componente. Se houver conteúdo na maioria dos componentes não permitirá que você exclua-os para que não quebre
relações com outros recursos. Nesses casos é recomendável simplesmente cancelar a publicação do componente.
|===
