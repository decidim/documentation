= Versões

O recurso de versões permite que um visitante veja a evolução das diferentes versões de recursos que podem ser editadas,
como propostas ou resultados.

Com as versões é possível ver quem fez a mudança, quando a mudança foi feita e exatamente o que mudou.

imagem:features/versions/side_by_side_escaped.png[Versões nos recursos]

== Veja as versões

. Vá para o conteúdo que você deseja ver a versão de.
. Clique no link "Ver outras versões" na barra lateral
image:features/versions/sidebar.png[Ver outras versões link na barra lateral]
. Clique na versão anterior que você quer ver
imagem:features/versions/list.png[Lista de versões]
. A partir daí, você pode alterar a visualização das diferenças de versão
image:features/versions/unified_unescaped.png[Visão unificada sem escapar]

É possível ver os diffs das versões em dois formatos: lado a lado ou unificado. Caso o conteúdo seja
em HTML então também é possível ver o diff sem escapar e escapar, e veja o código HTML completo.

image:features/versions/side_by_side_unescaped.png[Lado a lado sem escapar]
image:features/versions/unified_escaped.png[Visão unificada escapada]
