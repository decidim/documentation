= Seguidores

A seção seguinte contém uma lista de participantes e grupos que os participantes estão seguindo atualmente. Seguindo outro usuário ou grupo na plataforma, o usuário receberá notificações sobre a atividade feita pelos outros participantes ou grupos da plataforma. Alguns participantes também precisam estar seguindo o outro participante antes de poderem trocar mensagens privadas um com o outro.
