= notificações

Nesta seção, os participantes poderão ver as notificações que o sistema enviou para eles. Por exemplo, se o usuário é seguinte, um espaço participativo ou uma proposta, elas recebem notificações relacionadas sobre as ações que acontecem nessas seções da plataforma.

Esta seção pode ser acessada através do ícone da campainha na barra de cabeçalho da plataforma. O ícone do sino mostra destacado como ativo quando há notificações e escurecimento quando não há novas notificações para o usuário no momento.
