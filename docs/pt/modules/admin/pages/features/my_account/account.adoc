= conta

Nesta seção é possível fazer modificações que serão visíveis nos participantes xref:features/minha_public_profile. doc[perfil público] e também modificar o endereço de e-mail ou a linguagem que a plataforma usará com o usuário.

. Iniciar sessão como participante
. Clique no nome do usuário no cabeçalho
. Clique em "Minha conta"

image:features/minha_conta/account.png[Meu formulário de conta]


.Configurações do usuário - Meu formulário de conta
|===
|Campo |tipo |Descrição:

|Avatar
|Opcional
|Avatar ou foto do participante. Orientação para imagem: Preferencialmente, uma imagem de paisagem que não possui texto.
O serviço cultiva a imagem. Tamanho máximo do arquivo: 5MB

|Seu Nome
|Obrigatório
|O nome do participante.

|Apelido
|Obrigatório
|O apelido do participante.

|Seu e-mail
|Obrigatório
|O e-mail do participante, onde eles receberão notificações, recuperação de senha, etc. Se for alterado, ela precisa ser
confirmada.

|URL pessoal
|Opcional
|Metadados que são exibidos no perfil do participante.

|SOBRE
|Opcional
|Metadados que são exibidos no perfil do participante.

|Localidade
|Obrigatório
|Escolha o idioma que você deseja usar para navegar e receber notificações em Decidim
|===

A partir desta página também é possível alterar a senha do participante.
