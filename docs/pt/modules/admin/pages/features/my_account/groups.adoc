= grupos

Nesta seção, os participantes podem ver a quais grupos eles pertencem.

NOTE: Deseja criar um novo grupo? Vá para página xref:admin:features/my_public_profile.adoc[Meu perfil público].

image:features/my_account/groups.png[Groups]

Para ir para esta turma:

. Iniciar sessão como participante
. Clique no nome do usuário no cabeçalho
. Clique em "Minha conta"
. Clique em "Grupos" na barra lateral

Aqui você pode ver em qual data o grupo foi criado e qual status ele possui (`pendente` ou `verificado`).

Leia mais sobre o xref:admin:participants/groups.adoc[Groups in admin manual].
