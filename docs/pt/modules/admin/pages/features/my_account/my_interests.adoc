= Meus interesses

Nesta seção, os participantes podem escolher quais interesses devem receber mais informações.

Por padrão o que eles veem aqui é uma lista de todas as xref:admin:scopes.adoc[Scopes] da organização. Essas seleções
podem ser usadas pelos administradores ao segmentar para o xref:admin:newsletters.adoc[Newsletters].

image:features/minha_account/meu_interesses.png[Meus interesses]

Para ir para esta turma:

. Iniciar sessão como participante
. Clique no nome do usuário no cabeçalho
. Clique em "Minha conta"
. Clique em "Meus interesses" na barra lateral
