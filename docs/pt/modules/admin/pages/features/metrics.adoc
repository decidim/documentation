= Métricas

NOTE: Você está buscando por como ativar este recurso tecnicamente? Vá para xref:develop:metrics.adoc[Métricas do guia de desenvolvedores]

Com as métricas os participantes podem ver a evolução no tempo de alguns recursos, tais como Propostas, Apoios, Endorseamentos, Seguidores, Participantes, Prospectos Aceitados, Comentários etc. Você pode ver um exemplo do mundo real disso em https://meta.decidim.org/processes/roadmap/all-metrics[processo de Roadmap Metadecidim].

Para que isso funcione, ele precisa ser o primeiro xref:desenvolva: metrics.adoc[configurado tecnicamente] e também habilitado pela configuração no espaço participativo (caixa de seleção 'Mostrar métricas').

Então esta seção será visível na página de destino do espaço.

image:features/metrics/example.png[Exemplo de métricas]

Ao clicar em "Mostrar todas as métricas", os visitantes podem ver outras métricas e baixar esses dados em formato CSV.

image:features/metrics/page.png[Página de métricas]
