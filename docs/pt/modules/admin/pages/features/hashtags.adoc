= Palavras-chave

Hashtags são uma maneira de categorizar o conteúdo globalmente na plataforma e torná-lo mais facilmente pesquisável através dessas categorias. Permite que diferentes conteúdos relacionados sejam facilmente detectáveis sob o mesmo tópico. Funcionalidade semelhante é frequentemente utilizada em outras plataformas de mídia social.

Hashtags podem ser configurados para diferentes registros dentro da plataforma, como espaços participativos. Eles também podem ser gerados para o conteúdo criado pelos participantes para permitir uma descoberta mais fácil do conteúdo. Alguns componentes também podem permitir a configuração de hashtags sugeridas ou hashtags específicas para todos os registros apresentados pelos participantes.
