= notificações

== O menu de notificação

A maioria das ações na plataforma gera notificações para que calças de partículas possam saber quando há coisas novas para assistir.

Isto é acessível a partir do item de menu `Notificações` (image:icon_bell.png[Ícone de notificação]) no cabeçalho, depois que um participante estiver logado.

Para ver as notificações:

. Iniciar sessão como participante
. Clique no ícone de notificações no cabeçalho

Se houver notificações, o participante verá o ícone com uma imagem de cor:icon_bell_on.png[Ícone de notificação com cor]

imagem:features/notifications/notifications.png[Exemplo de página de notificações quando há notificações]

imagem:features/notifications/no_notifications_yet.png[Exemplo de página de notificações quando não há notificações]
