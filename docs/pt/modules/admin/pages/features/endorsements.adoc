= Endossos

Através de endossos, os participantes podem mostrar publicamente que querem apoiar um determinado conteúdo, por exemplo, uma proposta.

image:features/endorsements/list.png[Lista de endossos]

Isso é feito através do botão na barra lateral. Os administradores podem habilitá-los ou desativá-los passo a passo em um determinado processo participativo e também podem definir as permissões com autorizações.

image:features/endorsements/sidebar.png[Botão de endosso na barra lateral]

Quando um usuário pertence a um grupo verificado, ele também pode endossar como esse grupo selecionando a identidade.

image:features/endorsements/modal.png[Selecione janela de identidade]

Por padrão, a lista de endossos está recolhida. Para ver totalmente os visitantes também precisam clicar no link "(ver mais)".

image:features/endorsements/full_list.png[Lista completa de endoss]
