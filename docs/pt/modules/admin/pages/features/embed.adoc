= Incorporar

Às vezes, você quer incorporar algum conteúdo para uma página externa. Para isso, você pode usar o recurso `Embuti`.

imag:features/embed/exemplo.png[Um cartão de proposta embutido em outra página]

== Como incorporar

. Navegue para o conteúdo que você deseja incorporar.
. Clique no link `Embed` na barra lateral. image:features/embed/link.png[]
image:features/embed/sidebar.png[]
. Copie o código do modal.
image:features/embed/modal.png[]
. Cole esse código na página externa onde você deseja incorporá-lo. The CMS or platform that you're using needs to supports
changing HTML code.

Um exemplo deste código é:

[source,html]
----
<script src="https://meta.decidim.org/processes/roadmap/f/122/proposals/16243/embed.js"></script>
<noscript><iframe src="https://meta.decidim.org/processes/roadmap/f/122/proposals/16243/embed.html" frameborder="0" scrolling="vertical"></iframe></noscript>
----
