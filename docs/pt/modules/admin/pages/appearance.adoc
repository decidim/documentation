= Aparência

Nesta página você pode configurar a aparência da sua instância do Decidim.

Por favor, tenha em mente que isso seria incompatível com algumas das mudanças que seus implementadores poderiam alterar na sua instalação geral. Por exemplo, se houve mudanças no xref:customize:styles.adoc[Styles] isso não poderia funcionar.

* **Mostra estatísticas**: se você deseja exibir ou não as seções de estatísticas da página inicial.

---

* **Descrição**: Qual é a descrição deste site. Usado para metatags para incorporações de Google e Twitter. Também usado pelo ContentBlock "SubHero" na página inicial.

---

NOTE: Essas configurações legadas de área que serão removidas na próxima versão. https://github.com/decidim/decidim/pull/6284[See PR].

* **Chame para Ação botão do caminho**: você pode substituir onde o botão Chamar para Ação no link da página inicial. Use caminhos parciais, não URLs completas aqui. Aceita letras, números, traços e barras e deve começar com uma letra. O botão Chamar para Ação é exibido na página inicial entre o texto de boas-vindas e a descrição. Exemplo: https://meta.decidim.org/conferences/decidimfest2020/
* **Texto do botão Chamar para Ação**: Você pode substituir o texto do botão Chamar para Ação na página inicial para cada idioma disponível na sua organização. Se não for definido, o valor padrão será usado. O botão Chamar para Ação é exibido na página inicial entre o texto de boas-vindas e a descrição.
