= Áreas

$deprecatedparcial .adoc[]

As áreas são todos os sectores que uma organização pode ter.

Eles são bem parecidos com o xref:admin:scopes. documento[scopes], o que significa que eles são uma maneira de permitir uma melhor navegação e filtragem nos espaços e componentes.

Não recomendamos usá-los, como provavelmente no futuro serão removidos.

Você pode ler mais informações sobre a história das Áreas neste https://github.com/decidim/decidim/issues/3540#issuecomment-427324532[comentário GitHub].
