= Participantes

Às vezes, como administrador, você precisará fazer certas tarefas com os participantes, entre elas:

* Para dar permissões a outros administradores para que eles possam gerenciar o conteúdo da plataforma
* Verificar grupos de usuários (organizações ou coletivos)
* Para verificar os participantes
* Para reconhecer que um participante tem um status especial na plataforma, com Oficializações
* Para autenticar que a pessoa tem o direito de votar, com Autorizações
* Para contatar um usuário

Você pode acessar esta seção na barra lateral do painel de administração.

imag:participants_menu.png[Menu dos participantes]
