= Seções de ajuda

Na primeira vez que um visitante vai a qualquer página de espaço, ele verá uma caixa de informações sobre o que é esse espaço.

É assim que a caixa de informações é mostrada aos participantes e visitantes:

image:help_sections_frontend.png[Seções de ajuda: frontend]

Eles podem esconder essa caixa clicando no botão fechar [X]. Isso é lembrado pelo aplicativo. Eles podem abrir esta caixa novamente clicando na [Ajuda: ?].

image:help_sections_frontend_hide.png[Seções de ajuda: esconder]

Como isso depende da sua instalação, um administrador pode personalizar essas *seções de ajuda*, adaptando-as às suas necessidades.

imag:help_sections_backend.png[Seção de ajuda: backend]

== Desligado

Você pode desativar essas caixas de informações deixando o conteúdo vazio para cada idioma:

image:help_sections_disable_backend.png[Desativar seção de ajuda no admin]

image:help_sections_disable_frontend.png[Seção de ajuda desativada]
