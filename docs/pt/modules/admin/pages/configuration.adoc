= Configuração

Nesta página você pode configurar configurações gerais a partir do Decidim.

image::admin_configuration.png[Decidim Admin Configuration]

Estes são:

* **Nome**. Obrigatório. O nome que a plataforma tem. Visível no título, e-mails, etc.
* **Social**. Manipuladores sociais para diferentes redes sociais. Visível no rodapé em cada página. Isto é:
** Twitter
** Siga-nos
** Instagram
** Youtube
** GitHub

image::settings_configuration_social.png[Social networks configuration in Decidim]

* **Local padrão**. Obrigatório.
* **Fuso horário**. Obrigatório. Em que fuso horário é sua organização. Usado por coisas, como calendários, nas Reuniões.
* **Prefixo de referência**. Obrigatório.
* **Ative insígnias**. Se você quer ou não que seus participantes tenham medalhas como um mecanismo de gamificação, por exemplo, para criar propostas ou fazer comentários.
* **Habilitar grupos**.  Se você quiser ou não que seus participantes tenham a possibilidade de criar xref:participants/groups.adoc[Grupos de Usuários]. Úteis como, por exemplo, para associações ou outros coletivos.
* **Habilitar o editor de texto rico para participantes**.  Se você quer ou não que seus participantes tenham ou não a possibilidade de ter um editor https://en.wikipedia.org/wiki/WYSIWYG[O que você vê é o que você obtém (editor WYSIWYG)]. Em algumas áreas de texto, os participantes poderão inserir algumas tags HTML usando o editor de texto rico.
* **Enviar notificação de boas-vindas**. Se você quer ou não que os seus participantes recebam uma notificação quando criarem a conta pela primeira vez. Se ativado, você poderá personalizar esta notificação.
** **Personalizar notificação de boas-vindas**.
** **Assunto notificação das boas-vindas**.
** **Bem-vindo corpo da notificação**.

.Notificação de boas-vindas
====
Olá {\{name}}, obrigado por se juntar a {\{organization}} e ser bem-vindo!

Se você quer ter uma ideia rápida do que pode fazer aqui, dê uma olhada na seção de Ajuda.
Assim que tiver lido você terá a sua primeira medalha. Aqui está uma lista de todos os emblemas que podem obter ao participar em {\{organization}}

Por último, mas não menos importante, junte-se a outras pessoas, compartilhe com elas a experiência de estar envolvido e participar em {\{organization}}. Faça propostas, comentários, debate, pensar em como contribuir para o bem comum, fornecer argumentos para convencer, ouvir e ler para se convencer, expressar as suas ideias de forma concreta e directa, responder com paciência e decisão. defenda suas ideias e mantenha a mente aberta para colaborar e juntar as ideias de outras pessoas.
====
