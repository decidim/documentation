= Página

$underparcial -construção.adoc[]

Você pode controlar como é a página principal da sua organização. Para fazer isso você tem a seção Configurações -> Página inicial através do painel de administração:

image::admin_homepage.png[Decidim Admin Homepage]

---

== Como isto funciona

Isso significa que todas as seções da Homepage são chamadas de **bloco de conteúdo**.

Por exemplo, este é o bloco de conteúdo *Como participar*:

image::homepage_how_to_participate.png[How to participate example]

Para gerenciar esses conteúdos você precisa arrastar e soltar os conteúdos entre as duas colunas, à esquerda estão ativos e à direita estão blocos de conteúdo inativos.

Como exemplo, aqui você pode ver como sua página vai aparecer com apenas o bloco de conteúdo *Imagem do Herói*:
