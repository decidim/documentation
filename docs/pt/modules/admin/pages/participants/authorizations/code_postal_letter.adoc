= Código por autorização de carta postal

This authorization allows a participant to request for a verification code to be sent to its address, to confirm that she
lives or works in this place. She'll need to then fill the code in the platform.

O processo é:

. Os usuários solicitam que um código de verificação seja enviado para o endereço.
. Um administrador envia a carta para seu endereço com o código de verificação.
. Um administrador marca a carta como enviada.
. Depois de marcar a carta como enviada, o usuário poderá introduzir o código.
. If this code matchs, then she gets verified.

== 1. Um usuário solicitou o código de verificação

By going to the authorization section in its profile, or by clicking on the action button if this permission is requested,
a participant can see the form for filling in her full address to request the verification code.

image:authorizations_code_postal_letter_request.png[Código por solicitação de carta postal por participante]

If she tries to edit it, she'll see this message:

image:authorizations_code_postal_letter_edit.png[Editar pedido de carta postal]

Isso deve-se ao facto de a carta poder estar a ser enviada. Se isso precisar ser corrigido, então o participante precisa de
para entrar em contato com a organização.

== 2. Um administrador revisou este pedido e enviou a carta

No painel de administração, o administrador pode rever a solicitação indo para o "Código por carta postal" na seção "Participantes".

image:authorizations_code_postal_letter_ongoing.png[Código pelo painel de letras postais em andamento no administrador]

Here she can see the verification code and can send it to the participant by mail. After the code is sent she can mark it
as sent with the icon image:action_mark_as_sent.png[Mark as sent]. Também mostrará quando a carta foi enviada.

== 3. Um usuário preenche o código de verificação

After the participant has received the code, she can go to it's account settings and click in the "Code by postal letter"
verfication method.

image:authorizations_code_postal_letter_verify.png[Código por carta postal em andamento na conta do participante]

Then she'll see the form for confirming the code.

image:authorizations_code_postal_letter_confirm.png[Código pelo formulário de confirmação da letra postal]

== 4. O código de verificação corresponde ou não

Se o código de verificação corresponder, então o usuário verá a mensagem "Parabéns. Você foi verificado com sucesso.

Por outro lado, se o código de verificação não corresponder, então o usuário verá a mensagem "Seu código
de verificação não corresponde ao nosso. Por favor, verifique novamente a carta que lhe enviamos."

Após a verificação, como outras verificações, eles poderão vê-lo nas configurações da conta.

image:authorizations_code_postal_letter_verificado.png[Verificado pelo código pela carta postal]
