= Administradores

Na página de listagem do administrador você pode ver todos os administradores da plataforma:

image:admins.png[Admins list]

Aqui você pode:

* convidar novos administradores
* revogar permissões de administradores
* ver quando foi a última vez que um administrador fez login

For inviting a new administrator, you need to go to the button "New user" and fill
the form with the admin username, email and which role will she have:

* Administrador: permitir acesso total à plataforma
* Gerenciador de participantes: dar permissão para apenas fazer xref:admin:participants/impersonations.adoc[Impersonations]

image:admins_invite.png[Participante de convite como formulário de administrador]

Você pode convidar um usuário já registrado ou não registrado.
