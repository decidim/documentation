= Questionário

O componente de pesquisa permite que as pessoas respondam a questionários. This is useful when an organization wants to receive private
feedback, although it's possible to publish the answers manually as well. Permite definir um conjunto de perguntas com vários tipos de respostas.

Deste ponto de partida, poderia haver outras configurações, tais como:

* se a resposta for limitada a um período de tempo
* quais tipos de resposta devem ter as perguntas, como pequenas (uma linha), longas (várias linhas), únicas ou múltiplas opções,
ordenando através de uma lista, etc.
* se houver uma validação de respostas como quantos caracteres no máximo devem ter uma resposta
* se houver um número máximo de opções para selecionar em questões de várias opções

Alguns exemplos de onde este componente foi usado:

* https://consultation.quebec.ca/processes/donneesquebec/f/82/[Data Quebec: participe de sua melhoria! (Donne├es Que├bec : participez ayear joelhparece!). em consultas no Queárea, bec]
* https://meta.decidim.org/conferences/decidimfest2020/f/1403/?locale=en[Pesquisa de Avaliação da DecidimFest2020]

image:components/surveys/example01.png[Exemplo de uma pesquisa]

Para configurar o componente da Survey:

. Iniciar sessão como administrador
. Ir ao painel de administração
. Na barra lateral principal, clique no botão para o espaço para o qual você deseja configurar o componente.
Por exemplo, pode ser "Processos", "Assemblies" ou "Conferências".
. Ir para componentes
. Clique no botão "Adicionar componente"
. Clique em "Pesquisar"
. Preencha o formulário xref:_add_component[Add component]

Assim que uma pesquisa já for respondida por alguns usuários, não é possível modificar suas perguntas, como isso afetaria a integridade
das respostas. Se for necessário modificar as perguntas, então é necessário criar uma nova pesquisa de pesquisa e cancelar a publicação do original.

== Novo formulário de pesquisa

Ao criar uma nova pesquisa, você precisará preencher o formulário com os seguintes campos:

image:components/surveys/edit_form.png[Editar formulário de pesquisa]

NOTE: Vocês têm pesquisas repetitivas? Por exemplo, o mesmo formulário de feedback para cada processo? Você pode ter uma pesquisa que
é copiado e é usado como um diagrama para que você não precise configurar manualmente a mesma pesquisa toda vez. Aprenda mais
sobre xref:_templates[Templates].


.Novo formulário de pesquisa
|===
|Campo |tipo |Descrição:

|Título
|Obrigatório
|Qual é o título deste inquérito. Por exemplo, "Feedback"

|Descrição:
|Opcional
|Qual é a descrição deste inquérito.

|Termos de serviço
|Obrigatório
|As condições jurídicas que os participantes têm de aceitar para responderem ao inquérito.
|===

No final deste formulário há um botão que permite a você "Adicionar pergunta".

image:components/surveys/add_question_button.png[]

Você pode adicionar várias perguntas por pesquisa, reordenar ou excluí-las. Também é possível adicionar separadores entre perguntas.

Cada questão precisa ter um comando e um tipo como um mínimo.

image:components/surveys/question_form.png[]


.Adicionar formulário de pergunta
|===
|Campo |tipo |Descrição:

|Instrução
|Obrigatório
|A pergunta propriamente dita. Por exemplo, "Qual é a sua categoria idade?"

|Descrição:
|Opcional
|Explicação da pergunta que está a ser feita.

|Mandatory
|Opcional
|Verifique se esta pergunta é necessária para responder para enviar a resposta.

|Limite de caracteres
|Opcional
|Quantos caracteres tem como máxima a resposta a esta questão. Deixe para 0 se não houver limite. Compatível com tipos de perguntas curtas e respostas longas.

|tipo
|Obrigatório
|Um dos seguintes: Resposta curta, resposta longa, opção única, opção múltipla, Ordenação, Arquivos, Matriz (opção Casa)
ou Matriz (Múltipla opção). Veja xref:_question_types[Question types] para mais informações.
|===

Dependendo do tipo de questão, é possível adicionar validações às respostas, como se a pergunta é obrigatória (os participantes
precisariam dar uma resposta a fim de enviar o formulário) ou se a resposta é limitada a um determinado número de caracteres como máximo de
respostas curtas e longas.

== Tipos de questões

Uma pesquisa pode ter várias perguntas com diferentes tipos, como:

- Resposta curta
- Resposta longa
- Opção única
- Opção múltipla
- Classificação
- arquivos
- Matriz (opção única)
- Matriz (Múltipla opção)

== Modelos

Para os casos em que os administradores precisam definir várias pesquisas que são principalmente as mesmas, mas usadas em contextos diferentes, U
é possível definir um modelo. Quando houver uma definida para uma pesquisa, então ele vai pedir para selecionar o Modelo e criar
a pesquisa baseada nesta ou na outra mão se não houver necessidade de usar um modelo, então é possível pular a seleção de modelo
.

image:components/surveys/edit_questionnaire.png[Escolher formulário de template]

== Exportar respostas

É possível exportar as respostas dos participantes da pesquisa para diferentes formatos: CSV, JSON, XLSX (Excel) ou PDF.

Observe que a plataforma não manipula o processamento de respostas nem apresenta resultados ou resumo aos usuários, que precisam ser
feito externamente.
