= Encontros

As reuniões são onde as pessoas se reúnem para discutir ou informar sobre um determinado tópico. Todas as reuniões têm um determinado local
(onde a reunião acontecerá) e data de início e fim e hora (quando a reunião acontecerá).

Alguns exemplos de onde este componente foi usado são:

* https://www.decidim.barcelona/processes/PAM2020/f/3734/[Proceda participatiu del Programa d'Actuacioč Municipal (PAM) 2020-2023]
em https://www.decidim.barcelona/[Decidim Barcelona]
* https://lejourdapres.parlement-ouvert.fr/processes/ateliers/f/14/[Les ateliers] in https://lejourdapres.parlement-ouvert.fr/[Le jour d'après]

== Tipo

Em relação à *localização*, dependendo da configuração do componente, você pode ter:

* Reuniões presenciais: onde você se reúne em um determinado local
* Reuniões on-line: onde você se reúne usando um serviço externo (por exemplo, Jitsi Meet)

Dependendo do *autor* (quem é a pessoa que está fazendo a chamada):

* Reuniões oficiais: reuniões criadas pela organização (criada por um administrador através do painel)
* Reuniões de cidadãos: reuniões criadas por um participante de usuário (um usuário ou um grupo).

== Adicione o componente

image:components/meetings/component.png[Adicionar um componente de reuniões]

Para adicionar o componente, você precisa:

. Iniciar sessão como administrador
. Ir ao painel de administração
. Na barra lateral principal, clique no botão para o espaço para o qual você deseja configurar o componente.
Por exemplo, pode ser "Processos", "Assemblies", ou "Conferências"
. Ir para componentes
. Clique no botão "Adicionar componente"
. Clique em "Reuniões"
. Preencha o formulário xref:_add_component[Add component]

== Criar uma nova reunião

=== Reuniões de cidadãos

As reuniões podem ser criadas pelos participantes se a configuração for "Os participantes podem criar reuniões" estiver marcada.

If a participant belongs to a xref:admin:participants/groups.adoc[user group], then she'll be able to create meetings as that group also.

image:components/meetings/new_meeting_form_frontend01.png[Crie uma nova forma de reunião (frontend)]
imagem:components/meetings/new_meeting_form_frontend02.png[Crie uma nova forma de reunião (frontend)]


.Criar reunião - formulário Frontend
|===
|Campo |tipo |Descrição:

|Título
|Obrigatório
|Qual é o título para esta reunião.

|Descrição:
|Obrigatório
|Uma descrição daquilo que será discutido nesta reunião, tal como os tópicos.

|tipo
|Obrigatório
|Escolha uma opção entre "Em pessoa", "Online" ou "Booth"

|Endereço
|Obrigatório se o tipo de reunião é "Em pessoa" ou "Cabo"
|Endereço: usado pelo Geocodificador para encontrar a localização

|Local:
|Obrigatório
|Localização: mensagem direcionada aos usuários que imprimem o local para

|Dicas de localização
|Opcional
|Dicas de localização: informações adicionais Exemplo: o piso do edifício

|URL da reunião on-line
|Opcional
|Qual URL será a reunião realizada.

|Mostrar iframe incorporado para esta URL
|Opcional
|Se deve ou não incorporar o iframe para esta URL de videoconferência. Apenas alguns serviços permitem a incorporação (ou seja, YouTube, Twitch...)

|Horário de Início
|Obrigatório
|Que dia e hora a reunião começará. Formato esperado: dd/mm/yyyy hh:ii

|Hora de término
|Obrigatório
|Que dia e hora a reunião começará. Formato esperado: dd/mm/yyyy hh:ii

|categoria
|Opcional
|Qual categoria tem a reunião. Usado para filtragem na lista de reuniões.

|Tipo de registro
|Obrigatório
|Escolha uma opção entre "Registro desativado", "Nesta plataforma" ou "Em uma plataforma diferente"

|Slots disponíveis para esta reunião
|Necessário se "Tipo de registro" estiver "Nessa plataforma"
|Quantas faixas horárias estão disponíveis para esta reunião? Deixe-o para 0 se você tiver slots ilimitados disponíveis

|Termos de registro
|Necessário se "Tipo de registro" estiver "Nessa plataforma"
|Que termos os participantes nos serviços devem aceitar para se inscrever ou participar da reunião. Específico para "Reuniões de cidadãos"

|URL de Registro
|Necessário se "Tipo de registro" estiver "Em uma plataforma diferente"
|Deve ser uma URL. Link para continuar com o serviço externo que você está usando para registros.

|Criar reunião como
|Necessário se o usuário pertence a um grupo
|With which identity she wants to create this meeting: as her user or as a group that she's reprensenting?
|===

Após a criação da reunião, os participantes também poderão editar e xref:components/meetings/close.adoc[close] it.

== Características das reuniões

Existem diferentes tipos de características que podem ser habilitadas em reuniões, tais como:

* xref:admin:components/meetings/registrations.adoc[Registrations]: para gerenciar quão partícula pode se registrar para participar da reunião.
* xref:admin:components/meetings/agenda.adoc[Agenda]: para ver os tópicos que serão discutidos na reunião por minutos.
* xref:admin:components/meetings/polls.adoc[Polls]: para uma votação rápida durante uma reunião on-line.
* xref:admin:components/meetings/close.adoc[Close]: para adicionar o relatório final sobre o que foi discutido na reunião.

== Reuniões online

Dependendo do momento e da configuração da reunião, pode haver mensagens diferentes que serão mostradas aos participantes.

. Se a "URL de reunião online" não for definida, haverá uma mensagem que diz "Link disponível em breve"
image:components/meetings/online_meeting_available_soon.png[Reunião online disponível em breve]
. Se a "URL de reunião online" for definida, e alguns minutos antes do início da reunião, o tipo de mensagem dirá "O link para se juntar a
a reunião estará disponível alguns minutos antes do início inicial"
image:components/meetings/online_meeting_available_before. ng[Reunião Online disponível antes de iniciar]
. Se a "URL de reunião Online" for definida, e o horário de início da reunião chegar, então haverá uma mensagem que diz
que "a reunião está acontecendo agora", com um link para participar da reunião.
image:components/reuniões/online_meeting_happening.png[Reunião online disponível antes de começar]
