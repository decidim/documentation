= Inscrições

Através de inscrições você pode ter controle de capacidade de participação para uma reunião. With this feature for instance you can
limit how many people could attend to the meeting, or you can know before the start of a meeting if you need to find a bigger
room to have the meeting.

Ao ativar esta funcionalidade, os participantes irão adicionar um botão para que possam expressar seus desejos de ir à reunião. Depending in how
this feature is configured, then:

. É possível definir quantos slots estão disponíveis para controlar a capacidade máxima desta reunião
. um xref:_registration_form[custom registration form] para perguntar informações aos participantes pode ser configurado
. Os administradores podem fazer xref:_invitations[invitations] para outros participantes ou pessoas que não estão registradas na plataforma
. é possível controlar a presença da reunião por meio do xref:_registration_code[códigos de registro]

image:components/meetings/registos/frontend_join_meeting.png[Participe de um botão da barra lateral de reunião]

Assim que os participantes confirmarem participar de uma reunião, eles são perguntados se estão descansando um grupo e se querem mostrar publicamente que estão participando.

image:components/meetings/registos/frontend_confirm.png[Participe de uma confirmação de reunião modal]

== Habilitar inscrições para uma reunião

Para habilitar inscrições para uma reunião:

. Iniciar sessão como administrador
. Ir ao painel de administração
. Na barra lateral principal, clique no botão para o espaço para o qual você deseja configurar o componente.
Por exemplo, pode ser "Processos", "Assemblies", ou "Conferências"
. Clique em "Reuniões"
. Pesquise a reunião que você deseja permitir inscrições para
. Clique no botão "Editar" imagem:action_edit.png[Botão Editar]
. Altere o campo "Tipo de Registro" para "Nesta plataforma"
. Definir quantos slots estão disponíveis em "Slots disponíveis para esta reunião"
. Clique no botão "Atualizar"
. Clique no botão "Registros" image:action_registrations.png[Botão de registros]
. Verifique a caixa de seleção "Registrações habilitadas"
. Preencha o formulário

== Formulário de registro

Esse recurso permite que você defina um formulário personalizado como o componente xref:admin:components/surveys.adoc[Surveys] para pedir informações aos participantes
.

== Exportar tudo

É possível exportar registros em vários formatos: CSV, JSON e XLSX (Excel).

Os dados exportados terão estes campos:

* ID: O ID de registo
* código: xref:_registration_code[registration code] (se esta funcionalidade estiver ativada)
* usuário/nome: o nome do usuário
* usuário/email: o e-mail do usuário
* user/user_group: the group of the user if she has selected that's representing a group when registering

== Convites

Esse recurso permite convidar participantes para uma reunião. Estes poderiam estar registrados ou participantes não-existentes
na plataforma.

image:components/meetings/registrations/invite_attendee.png[Convidar participante para o cadastro em uma reunião]

== Código de registro

Esse recurso permite verificar se o participante está registrado na reunião. She needs to provide her code, that gets
entered in this form and it's checked against the database.

image:components/meetings/registrations/backend_w_registration_code.png[Formulário de registro em uma reunião]

image:components/meetings/registrations/frontend_confirmed_w_code.png[Código de registro em um frontend de reunião]

Pode receber dois tipos de respostas:

* Código de registro validado com sucesso.
* Este código de registro é inválido.
