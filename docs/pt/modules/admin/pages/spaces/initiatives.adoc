= Iniciativas

Uma iniciativa é um tipo especial de processo participativo que pode ser promovido por qualquer pessoa (independentemente de outros canais ou espaços de participação) através da coleta de assinaturas (online e presente) para a organização realizar uma ação específica (modificar um regulamento) iniciar um projeto, mudar o nome de um departamento ou uma rua, etc.).

Os promotores de uma iniciativa podem definir os seus objectivos, recolher apoio, debate, divulgue-a e defina pontos de reunião onde as assinaturas podem ser recolhidas dos participantes ou debates abertos a outros participantes.

Exemplos: Uma iniciativa pode coletar assinaturas para solicitar uma consulta entre todas as pessoas de uma organização, ou para criar uma assembleia ou para pedir um processo de aumento do orçamento para um território ou área da organização. Durante o processo de recolha de assinaturas, mais pessoas podem aumentar essa procura e levá-la por diante na organização.

As iniciativas devem ser separadas dos outros espaços de participação, porque podem ser usadas como ferramenta participativa ou mecanismo promovido pelos participantes. Por outras palavras, as iniciativas são mecanismos de democracia semi-directa, através dos quais os participantes podem promover uma certa acção de interesse comum à organização, coletando um número específico de assinaturas. Neste caso, O que a organização tem de fazer é permitir a promoção destas iniciativas e oferecer o necessário apoio técnico e aconselhamento às pessoas envolvidas. O papel do administrador da plataforma, portanto, é um pouco diferente do dos outros espaços de participação.

Em primeiro lugar, terá de configurar as várias formas de iniciativas. Isto pode ser especificado num regulamento (como uma lei municipal normativa ou estado), especificar o número de assinaturas necessárias para o processamento dos vários tipos de iniciativas. Por exemplo, uma iniciativa para incorporar um ou vários pontos na agenda do Conselho Municipal requer, evidentemente, menos assinaturas do que outra iniciativa para promover uma consulta vinculativa.

== 0. Configuração inicial

Como as iniciativas funcionam depende de duas coisas: como o módulo de iniciativa é configurado através do xref:admin:initiatives_initializer. documento[initializer] (em código) e como o tipo de iniciativa é configurado no painel de administração.

Em relação a iniciativas de tipo, **um administrador** precisa definir um. Para que as iniciativas funcionem numa organização tem de haver pelo menos um tipo de iniciativa criado e configurado com pelo menos um âmbito de tipo de iniciativa. Se houver apenas um tipo o participante não terá a possibilidade de escolher o tipo de iniciativa, esta etapa será ignorada no assistente de criação de iniciativa.

Alguns exemplos reais da cidade de Barcelona são:

* Para adicionar um item às agendas do Conselho Municipal ou Distritos
* Para executar um processo participativo
* Para criar uma nova montagem
* Para aprovar ou modificar um regulamento
* Solicitar a realização de uma consulta cidadã
* Solicitar assembleias (conselhos de vizinhança ou audiências públicas)

== 2. Enviar iniciativa para validação técnica

Essa ação é feita pelo **autor**.

Depois de ser revisado pelo autor, ele pode ser enviado para "Validação técnica", mas depende da configuração do tipo de iniciativa, na opção "Habilitar o comitê" e "Mínimo de membros do comitê" estão configuradas.

=== Comitê do promotor

Um tipo de iniciativa pode, opcionalmente, ser apoiado por um comité de promotores, com um número mínimo de membros do comité. Uma vez que o usuário tenha criado a iniciativa e antes de poder ser enviado para validação técnica, ele precisa convidar os membros do comitê para promovê-la.

Quando o usuário tiver criado a iniciativa, eles receberão um link para compartilhar com possíveis membros do comitê, o que vai parecer algo como `/initiatives/.../committee_requests/new`

Quando um possível membro do comité abre o link, pode clicar num botão que lhes permite solicitar que façam parte do comitê. O autor da iniciativa precisa então aprovar cada pedido. O autor pode aprová-los clicando no botão "Editar" da sua iniciativa na parte inferior da forma que pode aprovar ou rejeitar membros do comitê.

imagem:initiative_commitee_members_send_to_technical_false.png[Comitê promotor iniciativo: editar tela]

A iniciativa não pode ser enviada para validação técnica enquanto não cumprir o número mínimo de membros do comité. Você pode encontrar o link do convite no formulário de edição.

imagem:initiative_edit_commitee_members.png[Comitê de promotores iniciativo: edite tela]

Compartilhe o link de convite com as pessoas que você gostaria de ter em seu comitê.

image:initiative_commitee_members_ask.png[Comitê promotor iniciativo: edite tela]

As pessoas convidadas com a ligação poderão ler a iniciativa e solicitar a participação do comité.

image:initiative_commitee_members_sent.png[Comitê promotor iniciativo: edite tela]

O pedido é enviado e o autor pode então aceitá-lo ou recusá-lo no formulário de edição da iniciativa.

image:initiative_commitee_members_approve.png[Comitê de promotor iniciativo: edite tela]

imagem:initiative_commitee_members_send_to_technical_true.png[Comitê promotor iniciativo: editar tela]

Uma vez que pessoas suficientes se juntem ao comitê de promotores, o autor de iniciativa pode enviá-lo para
validação técnica.

== Status de iniciativa

Para melhor entender todo o status, este é um resumo:

|===
|SItuação |Explicação

|Criado
|A iniciativa foi criada, mas ainda não é pública para todos os visitantes nem para todos os participantes.

|Validação técnica
|A iniciativa tem de ser revista por um administrador. Daqui pode ser "descartado" ou "publicado"

|Expirado
|A iniciativa não foi revisada por um administrador e não foi aprovada, e o tempo máximo para validação passou.

|Descartado
|A iniciativa foi revisada por um administrador e foi descartada, por isso não foi publicada.

|Publicado
|A iniciativa foi revisada por um administrador e foi aprovada, então foi publicada.

|Rejeitados
|O período para a lembrança das assinaturas terminou e não havia assinaturas suficientes.

|Aceitou
|O período de recordação das assinaturas terminou e as assinaturas foram suficientes.
|===

[plantuml]
@startuml
:Criado;
:Técnica;
se (passou o tempo máximo de validação?) then (sim)
  #pink:Expired;
  kill;
elseif (validado?) então (não)
  #pink:Discarde;
  kill;
else (sim)
  #palegreen:Published;
  if (assinaturas suficientes?) então (não)
    #pink:Rejeitado
    (não há assinaturas suficientes);
    matar;
  else (sim)
    #palegreen:Aceito
    (assinaturas suficientes);
    para;
  endif;
endif
@enduml

Por último, estas são todas as configurações relevantes em todos os momentos das iniciativas, o ciclo de vida:

[plantuml]
@startuml
(*) --> "Create a new initiative"
if "Has only one type?" then
--> [Yes] "Fill initiative form"
else
--> [No] "Select initiative type"
--> "Fill initiative form"
Endif
partition Created {
  if "Is the User a UserGroup?" then
  --> [Yes] "Send to Technical Validation"
  else
  --> [No] Collect the minimum number of committee members (2 by default)
  --> "Send to Technical Validation"
  Endif
}
partition Validating {
  if "Has passed the maximum time for validation (60 days by default)?" then
    --> [Yes] "Expired"
  else
    --> [No] if "Is accepted by an administrator?" then
      --> [No] "Discarded"
      else
      --> [Yes] "Publish"
      endIf
  endIf
}
partition Published {
  --> "Signature process"
  if "Has passed the configured time window for validation (60 days by default)?"
    --> [Yes] "Expirado"
  else
    --> [No] Exportar PDF para assinaturas
    --> Verificar assinaturas com assinaturas offline para duplicatas (se a Iniciativa os possui)
    --> se "A iniciativa obtém o número de assinaturas necessárias? então
      --> [No] Rejeitou
    else
      --> [Yes] Aceitou
    endIf
  endIf
}
--> (*)
@enduml
