= Parceiros

Os parceiros são os patrocinadores ou apoiadores de uma conferência. Eles estão listados na página inicial da conferência.

imagem:espaços/conferências/partners_frontend.png[Parceiros de conferências (frontend)]

== Criar um novo parceiro

imagem:espaçaces/conferências/partners.png[Parceiros de conferências]

Para criar um novo parceiro de uma conferência:

. Entrar como administrador
. Ir para a seção de conferências na barra lateral
. Clique na ação Editar da conferência
. Clique no link Parceiros na barra lateral
. Clique no botão "Novo parceiro"
. Preencha o formulário

imagem:espaçaces/conferências/new_partner.png[Formulário de parceiros de conferências]
