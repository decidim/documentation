= Inscrições

Como administrador de uma conferência, você pode gerenciar os registros para a conferência a partir da plataforma.

Por fazer isso, você tem estas seções de administrador:

. xref:admin:spaces/conferences/registrations/types.adoc[**Registrations Types**] permite que você defina as maneiras de registrar os participantes
terá. Por exemplo, se há uma série de preços dependendo de se os participantes são estudantes ou trabalhadores.
. xref:admin:spaces/conferences/registrations/users.adoc[**User Registrations**] permite que você confirme os pedidos de participação na conferência.
. xref:admin:spaces/conferences/registrations/invites.adoc[**Convites**] permite que você convide participantes para a conferência.
. xref:admin:spaces/conferences/registrations/certificates.adoc[**Certificados de Participação**] permite que você configure e envie certificados
de presença no formato PDF para as pessoas que foram para a conferência.
