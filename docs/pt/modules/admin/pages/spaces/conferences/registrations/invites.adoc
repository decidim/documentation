= Convites

Os administradores podem convidar participantes para participar da conferência.

imagem:espaços/conferências/convites.png[Convites de usuário de conferências (backend)]

== Fluxo

. Um administrador envia um convite para participar da conferência para um usuário inexistente ou existente
. O usuário aceita o convite

image:spaces/conferências/invite_participant_form.png[Convidar um formulário de participante]


.Formulário do convite
|===
|Campo |tipo |Descrição:

|Tipo de participante
|Obrigatório
|Rodapé esta pessoa convidada é um usuário inexistente ou existente. Já têm uma conta criada na plataforma?

|Nome:
|Necessário se for um usuário inexistente.
|Nome da pessoa convidada.

|e-mail
|Necessário se for um usuário inexistente.
|E-mail da pessoa convidada.

|Usuário
|Necessário se for um participante existente.
|Digite pelo menos três caracteres para pesquisar.

|xref:admin:spaces/conferences/registrations/types.adoc[Tipo de registro]
|Obrigatório
|O que xref:admin:spaces/conferences/registrations/types.adoc[registration type] faz com este participante.
|===
