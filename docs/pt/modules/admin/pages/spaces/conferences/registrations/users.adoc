= Inscrições de usuários

Depois que os participantes se registrarem, eles aparecerão nesta seção.

imagem:spaces/conferências/user_registrations.png[Registros de usuários de conferências (backend)]

Como administrador, você pode:

* Exportar as inscrições
* Confirmar um registro

== Exportação

É possível exportar os registros em vários formatos: CSV, JSON e XLSX (Excel).

== Fluxo

. Um usuário se inscreve na conferência
. She receives a pending registration notification
image:spaces/conferences/user_registration_pending_notification.png[Notification for pending user registration]
. She receives a pending registration email
image:spaces/conferences/user_registration_pending_email.png[Email for pending user registration]
. Um administrador revisa e confirma o registro com o botão imagem:action_check.png[Confirm]
. O participante recebe uma notificação de registro confirmada
imagem:spaces/conferências/user_registration_confirmed_notification.png[Notificação para registro de usuário confirmado]
. She receives a confirmed registration email with an calendar file (.ICS).
image:spaces/conferences/user_registration_confirmed_email.png[E-mail para registro de usuário confirmado]
