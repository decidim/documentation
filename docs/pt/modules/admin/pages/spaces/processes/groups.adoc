= Grupos de processo

Um grupo de processos se mostra útil para subdividir grandes processos participativos em subprocessos de acordo com critérios
por exemplo o xref:admin:scopes. documento[scope] de cada processo.

Como exemplo, você pode ver o Plano de Vizinhanças do Conselho de Barcelona - Pla de Barris] https://www.decidim.barcelona/processes_groups/4[Barcelona City CounborodPlan.
Trata-se de um plano de choque de 150 milhões de euros que visa reduzir as desigualdades dentro das cidades. Existem 10 processos relacionados, um para cada bairro envolvido.

== Novo formulário de grupo de processo

Para criar um novo grupo de processos:

. Entrar como administrador
. Ir para a seção de Processos na barra lateral
. Clique no link dos grupos de processo na barra lateral
. Clique no botão "Novo grupo de processos"
. Preencha o formulário

== Página de destino

Uma das principais características de um grupo de processo é ser capaz de configurar a página de Lnading através de blocos de conteúdo, assim como
a página inicial geral da plataforma. Isto significa que você pode ativar ou desativar as seções diferentes da página inicial e também
configurar algumas dessas seções.

image::processes_group_landing.png[Participatory process group landing page]

* Título, descrição e hashtag
* Metadados
* Botão de imagem, texto e chamam para ação. Configurável.
* Propostas. Você pode configurar como os elementos serão ordenados: pela mais recente ou aleatória.
* Resultados. Você pode configurar como os elementos serão ordenados: pela mais recente ou aleatória.
* Próximos eventos
* estatísticas
* Processos participativos
* Primeiro bloco HTML
* Segundo bloco HTML
* Terceiro bloco HTML
