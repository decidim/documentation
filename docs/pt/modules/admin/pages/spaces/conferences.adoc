= Conferências

Uma conferência é uma coleção de reuniões organizadas num programa, com várias pessoas convidadas como oradores, e outros campos informativos
típicos do grande congresso ou eventos sociais (registro, lista de organizações que apoiam ou patrocinam o evento
, etc.). Uma conferência pode ser um evento relevante para uma organização e seus membros ou entre como parte de um processo
participativo ou siga uma consulta.

Exemplos:

* Uma assembleia geral para uma organização
* A reunião anual de uma cooperativa

Como exemplo do mundo real, você pode ver as conferências anuais Metadecidim:

imagem:espaçaces/conferências/exemplo01.png[Decidim Fest 2020]

== Criar uma nova conferência

Para adicionar uma nova conferência, você precisa:

imagem:espaçaces/conferências/menu.png[menu de conferências]

. Iniciar sessão como administrador
. Ir ao painel de administração
. Na barra lateral principal, clique no botão "Conferências"
. Clique no botão "Criar uma nova conferência"
. Configure a conferência preenchendo o formulário

image:spaces/conferências/new_conference.png[Crie um novo formulário de conferência]


.Criar uma nova conferência
|===
|Campo |tipo |Descrição:

|Título
|Obrigatório
|Qual é o título desta conferência. Por exemplo, "Decidim Fest 2021"

|Lema
|Obrigatório
|Um subtítulo para esta conferência. Por exemplo, "Democracia, Tecnologia e Justiça Global"

|Slug de URL
|Obrigatório
|Os slugs de URL são usados para gerar as URLs que apontam para esta conferência. Apenas aceita letras, números e traços, e
deve começar com uma letra. Exemplo: se seu domínio é 'example.org' e seu slug 'DecidimFest21', então sua URL será
https://example.org/conferences/DecidimFest21

|Palavras-chave
|Opcional
|Hashtag para o Twitter

|Destacado
|Opcional
|Deverá esta conferência ser mais proeminente do que outros? Trata-se, por exemplo, de uma conferência em curso ou de uma conferência que já teve lugar há anos?

|Breve descrição
|Obrigatório
|Uma breve explicação do que é a sua conferência.

|Descrição:
|Obrigatório
|Uma longa explicação do que é a sua conferência.

|Objetivos
|Opcional
|Quais são os objectivos ou metas para esta conferência?

|Local:
|Opcional
|Onde vai ter lugar esta conferência?

|Imagem inicial
|Opcional
|Preferencialmente, uma imagem de paisagem que não tem nenhum texto. The service crops
the imagem. Tamanho máximo do arquivo: 10MB. Extensões de arquivo permitidas: jpeg jpg png

|Imagem do banner
|Opcional
|Preferencialmente, uma imagem de paisagem que não tem nenhum texto. The service crops
the imagem. Tamanho máximo do arquivo: 10MB. Extensões de arquivo permitidas: jpeg jpg png

|Âmbitos ativados
|Opcional
|Verifique se você quer ter filtros de escopos nesta conferência

|Escopo
|Opcional
|Qual xref:admin:scopes.adoc[Scope] a qual esta conferência pertence.

|Mostrar estatísticas
|Opcional
|Verifique se você quiser mostrar a seção de Estatísticas.

|Data de início
|Obrigatório
|Quando começará esta conferência. Formato esperado: dd/mm/aaaa

|Data de término
|Obrigatório
|Quando terminará esta conferência. Formato esperado: dd/mm/aaaa

|Inscrições habilitadas
|Opcional
|Verifique se você deseja lidar com registros na plataforma.

|Slots disponíveis
|Opcional
|Deixe-o em 0 se você tiver slots ilimitados disponíveis.

|Termos de registro
|Obrigatório se "Inscrições habilitadas" estiver marcado
|Quais são os termos de serviço ou condições que um participante deve aceitar para se registar nesta conferência?

|Processos participativos relacionados
|Opcional
|Selecione os processos que estão relacionados a esta conferência. Use a função *ctrl* para selecionar mais de uma opção.

|Assembleias Relacionadas
|Opcional
|Selecione as assembleias que estão relacionadas a esta conferência. Use a função *ctrl* para selecionar mais de uma opção.

|Consultas Relacionadas
|Opcional
|Selecione as consultas relacionadas a esta conferência. Use a função *ctrl* para selecionar mais de uma opção.
|===

== Criando o programa

For creating the program of the conference you need to create a new xref:components/meetings.adoc[Meeting component] with the
dates and times of the different talks, workshops, sessions, etc. After publishing the meetings, it will be visible in the landing page
and there'll be a special navigation for these meetings so they're ordered by date and time.

imagem:espaçaces/conferências/programa_frontend.png[Programa de conferências (frontend)]

imagem:espaçaces/conferências/program_backend.png[Programa de conferências (backend)]

Também se você for reuniões com "Pessoa" com um local, então você terá uma lista de salas de reunião.

imagem:espaços/conferências/programa_venues_frontend.png[salas de conferências (frontend)]
