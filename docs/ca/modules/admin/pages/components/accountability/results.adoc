= Gestió del retiment de comptes

== Entendre els conceptes bàsics

Els resultats són les entitats que constitueixen el component de retiment de comptes. Es poden vincular a propostes, projectes, reunions i se'ls poden assignar estats i dates.

Els administradors també poden crear sub-resultats per detallar els elements necessaris per a la implementació d'un resultat.

== Configuració

=== Crear un resultat

Per començar a crear resultats, feu clic al títol del component a la barra de navegació o a la llista de components, o feu clic a la
image:icons/action_edit.png[Icona de gestió del component] de la llista de components.

image::components/accountability/new_result_button.png[New result button]

A continuació, feu clic al botó "Nou resultat" de la part superior dreta de la pàgina.

image::components/accountability/new_result.png[New result form]

=== Gestionar els resultats

A la llista de resultats del panell d'administració, els administradors poden veure:

* *ID*: número d'identificació d'aquest resultat.
* *Títol*: títol del resultat.
* *Categoria*: categoria del resultat.
* *Àmbit*: àmbit del resultat, si està habilitat a l'espai participatiu.
* *xref:admin:components/accountability/statuses.adoc[Estat]*: estat del resultat.
* *Progrés*: progrés percentual del resultat.
* *Creat*: data de creació del resultat.

Podeu filtrar i ordenar aquesta llista fent clic al botó "Filtre" i a les capçaleres de les columnes.
També podeu cercar resultats per ID i títol a la barra de cerca.
