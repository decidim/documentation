= Private Teilnehmer

== Understand the basics

In manchen Fällen möchten Sie die Teilnahme auf eine bestimmte Gruppe von Teilnehmenden beschränken.
Zum Beispiel ein Raum, der den Mitgliedern einer Kommission in einer grossen Organisation gewidmet ist.
Für diese Fälle können Sie die Funktion für private Teilnehmende verwenden.

NOTE: Die Liste der privaten Teilnehmenden kann nur im Verwaltungspanel eingesehen werden und wird nicht öffentlich angezeigt.

=== How to find it?

NOTE: Private Teilnehmende sind nur in privaten Räumen verfügbar. Um sie zu aktivieren, stellen Sie sicher, dass Sie beim Erstellen oder Bearbeiten Ihres Prozesses oder Ihrer Versammlung das Kontrollkästchen "Privater Raum"
      aktivieren.

Um private Teilnehmende zu erstellen und zu verwalten, klicken Sie in der linken Navigationsleiste des Raums auf den Punkt *Private Teilnehmende*.

image::spaces/private_participants.png[Private participants list]

Dort können Sie die privaten Teilnehmenden verwalten, sie im Batch importieren, neue Teilnehmende manuell hinzufügen usw.

== Konfiguration

=== Eine private teilnehmende Person einladen

Klicken Sie auf die Schaltfläche "Neue private Teilnehmende".

image:spaces/private_participants_new_form.png[Neue private Teilnehmerform]

.Neues partizipatorisches Formular für private Benutzer
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Der Name der neuen privaten teilnehmenden Person.

|E-Mail
|Benötigt
|Die E-Mail-Adresse der neuen privaten teilnehmenden Person.
|===

=== Über CSV importieren

Klicken Sie auf die Schaltfläche "Über CSV importieren".

image::spaces/private_participants_csv_import.png[Import private participants via CSV]

Mit diesem Formular können Sie den Zugriff aller privaten Teilnehmenden auf einmal löschen und einen Massenimport über CSV durchführen.

Die CSV-Datei muss folgender Formatierung entsprechen:

* Die Datei muss zwei Spalten enthalten: E-Mail-Adressen und Namen der Teilnehmenden, die Sie importieren möchten.
* Die Datei sollte keine Kopfzeilen haben. Das bedeutet, dass Sie keine Zeile mit "email, name" hinzufügen müssen
* Sie müssen es vermeiden, ungültige Zeichen wie `<>?%&^*#@()[]=+:;"{}\|` im Namen zu verwenden.
* Das Trennzeichen zwischen den Spalten muss ein Komma sein (",").

=== Einladung

NOTE: Wenn die E-Mail-Adresse bereits mit einem Konto in der Instanz verknüpft ist, erhält die teilnehmende Person keine Einladungs-E-Mail, wird aber dem Raum hinzugefügt.

Wenn eine teilnehmende Person zur Liste der privaten Teilnehmenden hinzugefügt wird, aber noch kein Konto hat, erhält sie eine E-Mail
      mit einem Link zur Annahme der Einladung:

image::spaces/private_participants_email_invite.png[Email invitation of a private participant]

Nachdem sie in der E-Mail auf den Link "Einladung annehmen" geklickt hat, wird sie zur Instanz weitergeleitet und muss die Erstellung
      ihres Kontos abschliessen, indem sie ihren Spitznamen und ihr Passwort festlegt und die Nutzungsbedingungen akzeptiert.

image::spaces/private_participants_user_registration_form.png[User registration form of a private participant]

=== Private Teilnehmende verwalten

Sie finden alle privaten Teilnehmenden in der Liste im Verwaltungspanel mit:

* *Name*: Name der privaten teilnehmenden Person. Falls das Konto bereits existiert, wird er automatisch auf den Benutzernamen des Kontos geändert.
* *E-Mail*: E-Mail-Adresse der teilnehmenden Person.
* *Einladung versendet am*: Tag und Uhrzeit, an dem die Einladungs-E-Mail gesendet wurde (falls die teilnehmende Person noch kein Konto hat).
* *Einladung akzeptiert am*: Tag und Uhrzeit, an dem die Einladungs-E-Mail von der teilnehmenden Person akzeptiert wurde.

Sie können die Liste sortieren, indem Sie auf die Spaltenüberschrift klicken, sie filtern und nach Teilnehmenden anhand ihres Namens oder ihrer E-Mail-Adresse suchen.
