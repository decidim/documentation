= Kategorien

== Die Grundlagen verstehen

Kategorien (und Unterkategorien) werden verwendet, um Ressourcen innerhalb eines Raumes zu klassifizieren.

Ein Admin kann sie definieren, kann beim Erstellen von Ressourcen zugewiesen werden, und dann können die Teilnehmenden die
verschiedenen Ressourcen nach diesen Kategorien filtern. Sie können zum Beispiel bei Vorschlägen, Veranstaltungen und Debatten verwendet werden.

. Admins definieren Kategorien in einem Raum.
. Teilnehmende können Ressourcen erstellen und ihnen eine Kategorie zuweisen.
. Teilnehmende können dann nach Kategorien filtern.

image::spaces/categories_sidebar.png[Filter categories in proposals]

NOTE: Sobald eine Kategorie verwendet wird, kann sie nicht gelöscht werden, da Ressourcen mit ihr verknüpft sind.

Decidim bietet weitere Möglichkeiten zur Klassifizierung von Ressourcen, zum Beispiel xref:admin:settings/scopes.adoc[Themen] und
xref:admin:features/social_features/hashtags.adoc[Hashtags].
Der Hauptunterschied besteht darin, dass Kategorien innerhalb eines bestimmten Raums definiert werden können, Themen für die gesamte Plattform global gelten und Hashtags
von Teilnehmenden festgelegt werden können.

Kategorien können verschachtelt werden, was bedeutet, dass eine Kategorie Unterkategorien haben kann.

=== Wie findet man sie?

Um Kategorien zu konfigurieren, klicken Sie in einem beliebigen partizipativen Raum auf den Punkt *Kategorien*.

image::spaces/categories.png[View categories in a space administration page]

== Konfiguration

=== Neue Kategorie erstellen

Klicken Sie oben rechts auf die Schaltfläche "Neue Kategorie".

image:spaces/categories_new_form.png[Neues Kategorie-Formular erstellen]

.Formular zur Kategorieerstellung
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Was ist der Name für diese Kategorie.

|Reihenfolge
|Optional
|Welche Reihenfolge sie im Verhältnis zu den anderen Kategorien hat. Eine niedrigere Zahl bedeutet eine höhere Priorität. Wenn Sie zum Beispiel zwei Kategorien haben, "Kategorie a" mit der Gewichtung "10" und "Kategorie b" mit der Gewichtung "0", dann steht "Kategorie b" bei der Sortierung an erster Stelle.

|Übergeordnet
|Optional
|Was ist die übergeordnete Kategorie.
|===

=== Kategorien verwalten

Sie finden alle Kategorien in der Liste im Verwaltungspanel mit:

* *Name*: Name der Kategorie, vom Admin bei der Erstellung oder Bearbeitung vergeben.

=== Aktionen

.Kategorienaktionen in der Kategorienliste
[cols="10h,20h,~"]
|===
|Icon |Name |Definition

|image:icons/action_edit.png[Symbol: Bearbeiten]
|Bearbeiten
|Um den Namen, die Reihenfolge und die übergeordnete Kategorie zu bearbeiten.

|image:icons/action_delete.png[Symbol: Löschen]
|Löschen
|Um die Kategorie zu löschen. Eine Kategorie kann nicht gelöscht werden, wenn ihr Ressourcen zugeordnet sind.
|===
