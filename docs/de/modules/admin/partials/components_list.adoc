Die Plattform verfügt derzeit über die folgenden offiziellen Komponenten:

* xref:admin:components/accountability.adoc[*Accountability*]: ermöglicht es, laufende Projekte zu verfolgen.
* xref:admin:components/blog.adoc[*Blog*]: ermöglicht es Admins, Blogbeiträge und Neuigkeiten zu veröffentlichen.
* xref:admin:components/budgets.adoc[*Budgets*]: ermöglicht es Teilnehmenden, für Projekte mit vordefinierten Beträgen abzustimmen, zum Beispiel für ein
partizipatives Budget.
* xref:admin:components/debates.adoc[*Debates*]: erlaubt den Teilnehmern Debatten zu führen.
* xref:admin:components/meetings.adoc[*Meetings*]: persönliche oder Online-Zusammenkünfte, Traktandenliste, Protokolle usw.
* xref:admin:components/pages.adoc[*Page*]: statische Seiten mit mehrsprachiger Unterstützung.
* xref:admin:components/proposals.adoc[*Proposals*]: von Teilnehmenden eingereichte Beiträge.
* xref:admin:components/sortitions.adoc[*Sortitions*]: ermöglicht die zufällige Auswahl von Vorschlägen.
* xref:admin:components/surveys.adoc[*Umfrage*]: zur Durchführung von Umfragen mit verschiedenen Arten von Fragen.

NOTE: Falls Ihre Anforderungen durch keine dieser Komponenten abgedeckt werden,
können Sie über ein xref:develop:modules.adoc[Modul] Ihre eigene Komponente erstellen.
