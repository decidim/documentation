= Moderation

Moderationen innerhalb eines Raumes funktionieren wie xref:global_moderations.adoc[Globale Moderationen].

Der Hauptunterschied besteht darin, dass Sie im Abschnitt
xref:admin:spaces/processes/admins.adoc[Raum-Admins] Moderierende für diesen spezifischen Raum einladen können, sodass sie nur Zugriff auf die Meldungen zu
Inhalten dieses Raums haben.
