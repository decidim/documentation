= Admins des Raums

== Die Grundlagen verstehen

Sie können Nutzenden in den verschiedenen Räumen spezifische Berechtigungen erteilen, sodass diese nur Zugriff auf bestimmte Verwaltungsaktionen haben.
Diese Rollen sind Admins, Moderierende, Mitwirkende und Bewertende.

* *Admins*: Sie können den Raum verwalten und die Raumeinstellungen ändern.
* *Mitwirkende*: Sie können den Raum und seine Komponenten vor der Veröffentlichung sehen und die Raumeinstellungen einsehen.
Sie können nichts bearbeiten.
* *Moderierende*: Sie können die gemeldeten Inhalte des Raums sehen und diese verbergen oder wieder einblenden.
* *Bewertende*: Sie können Vorschläge bewerten, ihnen Antworten geben und ihren Status aktualisieren.

=== Wie findet man sie?

Um die Admins des Raums zu konfigurieren, klicken Sie im entsprechenden Raum auf den Punkt "Prozess-Admins" oder "Versammlungs-Admins".

image::spaces/admins_list.png[Administrators of space]

== Konfiguration

=== Admins verwalten

Sie finden alle Admins in der Liste im Verwaltungspanel mit:

* *Name*: Name des Admin-Kontos.
* *E-Mail*: E-Mail-Adresse des Admin-Kontos.
* *Letztes Anmeldedatum*: letzter Zeitpunkt, zu dem der Admin angemeldet war.
* *Einladung akzeptiert am*: Datum, an dem der Admin die Einladung durch Klicken auf den Link in der Einladungs-E-Mail akzeptiert hat.
* *Rolle*: Rolle des Admins.

=== Einen Raum-Admin hinzufügen

Klicken Sie auf die Schaltfläche *Neuer Raum-Admin* (abhängig von der Art des Raums, in dem Sie sich befinden).

image:spaces/admins_form.png[Formular für neuen Raum-Admin]

.Formular für neuen Raum-Admin
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Der Name des neuen Admins.

|E-Mail
|Benötigt
|Die E-Mail-Adresse des neuen Admins, damit er eine Einladung erhalten kann, falls er noch kein Konto hat.

|Rolle
|Benötigt
|Welche Rolle dieser Admin im Raum haben soll. Kann jede der Rollen Admin, Mitwirkende, Moderierende oder Bewertende sein.
|===

=== Rollen

==== Admins

Ein Raum-Admin kann den Raum verwalten und die Raum-Einstellungen ändern. Sie können auch neue Raum-Admins einladen.
Bei der Verwaltung des Raums sehen sie nur die folgenden Ansichten und Tabs.

image:spaces/admins_role_admin01.png[Admin-Ansicht des Prozesses 01]

image:spaces/admins_role_admin02.png[Admin-Ansicht des Prozesses 02]

==== Mitwirkende

Eine mitwirkende Person im Raum kann eine Vorschau des Raums vor der Veröffentlichung ansehen.

image:spaces/admins_role_collaborator.png[Ansicht der Mitwirkenden des Prozesses]

==== Moderierende

Moderierende können den gemeldeten Inhalt des Raumes überprüfen und ihn ausblenden oder einblenden. Sie können auch
auf die gemeldeten Inhalte im globalen Moderationspanel zugreifen, sehen jedoch keine Inhalte, die aus anderen Räumen gemeldet wurden.

image:spaces/admins_role_moderator.png[Ansicht der Moderierenden des Prozesses]

==== Bewertende

Eine bewertende Person im Raum kann die ihr zugewiesenen Vorschläge des Raums prüfen, indem sie:

* den Status der Vorschläge ändert, indem sie diese annimmt oder ablehnt.
* den Vorschlägen eine Antwort gibt.
* fügen Sie den Vorschlägen einen monetären Wert hinzu, so dass sie mit der Haushaltskomponente abgestimmt werden können.

image:spaces/admins_role_valuator.png[Ansicht der Bewertenden des Prozesses]
