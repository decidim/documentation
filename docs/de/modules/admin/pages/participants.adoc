= Teilnehmende

== Die Grundlagen verstehen

Der Tab Teilnehmende ermöglicht es Ihnen, bestimmte Aufgaben mit Teilnehmenden durchzuführen, unter anderem:

* Zugriffsrechte auf die Plattformverwaltung verwalten
* Teilnehmende kontaktieren
* Den Zugriff von Teilnehmenden auf bestimmte Räume verwalten
* Die Identität bestimmter Teilnehmender bestätigen
* Die Echtheit von Nutzendenorganisationen oder Kollektiven bestätigen

== Konfiguration

Um auf das Konfigurationspanel für Teilnehmende zuzugreifen, gehen Sie zum Verwaltungspanel und klicken Sie in der Verwaltungsnavigationsleiste auf den Punkt "Teilnehmende".

image::participants/participants_menu.png[Participants menu]

Dort sehen Sie zunächst die Liste der Admins der Plattform.

image::participants/participants_sidebar_menu.png[Participants sidebar menu]

== Beispiele

Sie möchten Ihre Kolleginnen und Kollegen hinzufügen, damit sie die Plattform bearbeiten können.
Sie möchten spezifische Abläufe für Teilnehmende festlegen, damit sie an einem bestimmten partizipativen Raum teilnehmen können.
