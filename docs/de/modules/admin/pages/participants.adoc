= Teilnehmer

Manchmal musst du als Administrator bestimmte Aufgaben mit Teilnehmern erledigen, unter anderem:

* Um anderen Administratoren Berechtigungen zu erteilen, damit sie Inhalte der Plattform verwalten können
* Zur Überprüfung von Benutzergruppen (Organisationen oder Kollektiven)
* Zur Bestätigung der Teilnehmer
* Um zu erkennen, dass ein Teilnehmer einen besonderen Status in der Plattform hat, mit Beamten
* Um zu authentifizieren, dass eine Person das Wahlrecht hat, mit Genehmigungen
* Um einen Teilnehmer zu kontaktieren

Sie können auf diesen Bereich über die Hauptseitenleiste des Admin-Panels zugreifen.
