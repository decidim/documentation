== So funktioniert das

Das bedeutet, dass jeder Abschnitt auf der Homepage **Inhaltsblock** genannt wird.

Zum Beispiel ist dies der *Wie man teilnimmt* Inhaltsblock:

image::homepage_how_to_participate.png[How to participate example]

Um diese Inhalte zu verwalten, müssen Sie den Inhalt zwischen den beiden Spalten ziehen links sind die aktiven und rechts die inaktiven Inhaltsblöcke.
