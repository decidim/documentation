= Befürworter

Durch Zustimmungen können die Teilnehmer öffentlich zeigen, dass sie beispielsweise einen bestimmten Inhalt unterstützen wollen, einen Vorschlag.

image:features/endorsements/list.png[Liste der Befürworterungen]

Dies geschieht über die Schaltfläche in der Seitenleiste. Administratoren können diese schrittweise in einem bestimmten partizipatorischen Prozess aktivieren oder deaktivieren und sie können auch Berechtigungen mit Genehmigungen definieren.

image:features/endorsements/sidebar.png[Endorsement button in sidebar]

Wenn ein Teilnehmer einer verifizierten Gruppe angehört, kann er sich auch mit der Auswahl der Identität der Gruppe einverstanden erklären.

image:features/endorsements/modal.png[Identitätsmodus auswählen]

Standardmäßig ist die Liste der Befürworter eingeklappt. Um es vollständig sehen zu können, klicken Sie bitte auf den Link "(siehe mehr)".

image:features/endorsements/full_list.png[Liste der unterstützten]
