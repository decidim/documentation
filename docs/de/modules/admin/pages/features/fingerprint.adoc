= Fingerabdruck

Obwohl die Plattform die xref:admin:features/versionen anzeigen soll. doc[Versions] für fast alle Inhalte, es wäre
noch möglich, den Inhalt durch direkte Bearbeitung der Datenbank zu manipulieren.

Als Eindämmung dieses Risikos zeigt die Plattform einen Fingerabdruck für einige wichtige Bereiche, zum Beispiel ein Vorschlagsorgan und einen Titel.

image:features/fingerprint/modal.png[Fingerabdruckmodus überprüfen]

Sein Ziel ist es, eine Möglichkeit zu geben, eine informelle "Empfang" einem Teilnehmer zu geben, um Manipulation erkennen können. Ein Fingerabdruck ist
eine gehackte Darstellung des Inhalts. Es ist nützlich sicherzustellen, dass der Inhalt nicht manipuliert wurde, da eine einzelne Änderung
zu einem völlig anderen Wert führen würde. Es wird mit einem SHA256-Hashing-Algorithmus berechnet. Um es selbst mit
zu replizieren, können Sie einen http://www.md5calc.com/sha256[MD5 Taschenrechner online] verwenden und die Quelldaten kopieren.

== Fingerabdruck überprüfen

. Gehen Sie zum Inhalt, den Sie den Fingerabdruck überprüfen möchten
. Klicken Sie auf den Link "Fingerabdruck prüfen" in der Seitenleiste
Bild:features/fingerprint/sidebar.png[Fingerabdruck-Link in der Seitenleiste überprüfen]
. Folgen Sie den modalen Anweisungen

image:features/fingerprint/md5calc.png[MD5calc.com screenshot]

Es ist möglich, den Fingerabdruck mit anderen Werkzeugen, wie dem sha256sum Kommandozeilenwerkzeug, zu überprüfen.

[source,bash]
----
echo -n '{"body":{"en":"<p><strong>**Is your feature request related to a problem? Please describe.**</strong></p><p>It would be useful to set a character limit on questionnaire answers to provide guidance for users regarding how long their answers should be.</p><p><br></p><p><strong>**Describe the solution you\'d like**</strong></p><p>To have a number input field next to each question in the admin, labeled \\"Character limit\\", by default set to zero (no limit), which determines the maximum characters the user answers to those questions can have.</p><p><br></p><p><strong> **Describe alternatives you\'ve considered** </strong></p><p>Another possibility could be to define this globally for the questionnaire, setting the character limit for each type of question.</p><p><br></p><p><strong>**Additional context** </strong></p><p>-</p><p><br></p><p><strong> **Could this issue impact on users private data?** </strong></p><p>No</p><p><br></p><p><strong> **Funded by**</strong></p><p>Fundació Bosch i Guimpera</p>"},"title":{"en":"Maximum characters for questionnaire text answers"}}' | sha256sum
----
