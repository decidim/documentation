= Benachrichtigungen

In diesem Abschnitt können die Teilnehmer*innen die Benachrichtigungen sehen, die das System an sie gesendet hat. Zum Beispiel, wenn der*die Teilnehmer*in ein partizipatorischer Raum oder ein Vorschlag, erhalten sie verwandte Benachrichtigungen über die Aktionen, die in diesen Bereichen der Plattform passieren.

Auf diesen Abschnitt kann man über das Glockensymbol in der Kopfzeile der Plattform zugreifen. Das Glockensymbol wird als aktiv markiert, wenn es Benachrichtigungen und Dimmer gibt, wenn es momentan keine neuen Benachrichtigungen für den Benutzer gibt.
