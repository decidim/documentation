= Meine Interessen

In diesem Bereich können die Teilnehmer wählen, über welche Interessen sie mehr Informationen erhalten müssen.

Standardmäßig sehen sie hier eine Liste aller xref:admin:scopes.adoc[Scopes] der Organisation. Diese Auswahlen
können von Administratoren verwendet werden, wenn sie für die xref:admin:newsletters.adoc[Newsletters] segmentiert werden.

image:features/my_account/my_interests.png[Meine Interessen]

Um zu diesem Abschnitt zu gehen:

. Als Teilnehmer anmelden
. Klicken Sie im Namen des Teilnehmers in der Kopfzeile
. Klicken Sie in "Mein Konto"
. Klicken Sie in "Meine Interessen" in der Seitenleiste
