= Unterstützungen

== Die Grundlagen verstehen

Durch Befürwortungen können Teilnehmende öffentlich ihre Unterstützung für bestimmte Inhalte zeigen, wie einen Vorschlag, eine Debatte usw.

NOTE: Befürwortungen werden in der Teilnehmendenoberfläche auch "Gefällt mir" genannt.

image::features/endorsements/sidebar.png[Endorsement button in sidebar]

== Konfiguration

=== Befürwortungen aktivieren

Admins können Befürwortungen je Phase (Schritt) in einem bestimmten Beteiligungsprozess aktivieren sowie Berechtigungen mit Autorisierungen festlegen.

image::features/endorsements/admin.png[Endorsement phase (step) settings]

=== Inhalt befürworten / mit Gefällt mir markieren

Um einen Inhalt zu befürworten, klicken Sie auf die Schaltfläche "Gefällt mir" unterhalb des Inhalts.

image::features/endorsements/list.png[List of endorsements]

Wenn eine teilnehmende Person einer verifizierten Gruppe angehört, kann sie diese Gruppe auch befürworten/mit Gefällt mir markieren, indem sie die Identität auswählt.

image::features/endorsements/modal.png[Select identity modal]

Standardmässig ist die Liste der Unterstützungen eingeklappt. Um alle Befürwortenden zu sehen, müssen Sie auf das Symbol "+ x" klicken.

image:features/endorsements/full_list.png[Vollständige Liste der Unterstützungen]

Teilnehmende können den Inhalt auch mit Gefällt mir nicht markieren, wenn sie ihre Meinung ändern.
