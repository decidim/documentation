= Unterhaltungen

== Die Grundlagen verstehen

Mit Unterhaltungen können Teilnehmende private Nachrichten an eine andere teilnehmende Person, eine Gruppe von Teilnehmenden oder an Benutzergruppen senden.
Nur die Teilnehmenden, die sich in der Unterhaltung befinden, können jede Nachricht sehen.

NOTE: Es ist nicht möglich, eine Unterhaltung zu löschen oder eine Nachricht in einer Unterhaltung zu bearbeiten.

=== Wie findet man sie?

Als angemeldete teilnehmende Person können Sie von zwei Stellen aus auf Ihre Unterhaltungen zugreifen:

. Klicken Sie in der Kopfzeile auf Ihren Avatar und anschliessend auf den Menüpunkt "Unterhaltungen"
. Klicken Sie in der Fusszeile im Abschnitt "Mein Konto" auf den Link "Unterhaltungen"

image::features/conversations/conversations_dropdown.png[Frontend user menu dropdown]

Wenn es Benachrichtigungen gibt, sieht die teilnehmende Person ein kleines Abzeichen neben ihrem Avatar sowie im Dropdown-Menü.

== Konfiguration

=== Eine Unterhaltung starten

Eine teilnehmende Person kann eine Unterhaltung mit jeder auf der Plattform registrierten teilnehmenden Person oder Gruppe starten.

image::features/conversations/conversations.png[Conversations list]

Es gibt zwei Möglichkeiten, eine Unterhaltung zu starten.

==== Über das Profil einer teilnehmenden Person

. Gehen Sie zum Profil der teilnehmenden Person, mit der Sie eine Unterhaltung starten möchten
. Klicken Sie auf die Schaltfläche "Nachricht"
. Schreiben Sie Ihre Nachricht

image:features/conversations/profile.png[Profil einer teilnehmenden Person]

image:features/conversations/start_a_conversation_form.png[Formular zum Starten einer Unterhaltung]

==== Über die Unterhaltungsseite

image::features/conversations/conversation.png[Example of a conversation]

. Klicken Sie in der Kopfzeile auf Ihren Avatar
. Klicken Sie auf "Unterhaltungen"
. Klicken Sie auf die Schaltfläche "Neue Unterhaltung"
. Suchen Sie nach den Teilnehmenden oder der Gruppe, mit denen Sie eine Unterhaltung starten möchten
. Schreiben Sie Ihre Nachricht

NOTE: Sie können eine Unterhaltung mit mehreren Teilnehmenden starten, mit einer Begrenzung auf 9 Teilnehmende.

image::features/conversations/new_conversation_modal.png[New conversation modal]

=== Gruppenunterhaltungen

Genau wie mit Teilnehmenden ist es auch möglich, Unterhaltungen mit Gruppen zu führen.

NOTE: Um mehr über Benutzergruppen zu erfahren, lesen Sie den Artikel xref:admin:features/participant_actions/group_profile.adoc[Gruppenerstellung].
