= Kommentare

== Understand the basics

Kommentare sind öffentliche Nachrichten, mit denen Teilnehmende Informationen oder Meinungen zu einem Vorschlag, einer Debatte, einer Veranstaltung, einer Initiative usw. teilen können.

NOTE: Kommentare müssen von Admins aktiviert werden, andernfalls können Teilnehmende nicht kommentieren. Um zu erfahren, wie Sie Kommentare für eine Komponente aktivieren, lesen Sie bitte den Artikel xref:features:components.adoc[Komponenten].

image::features/comments/nested_comment.png[Comments example]

== Konfiguration

=== Kommentar erstellen

. Gehen Sie zu dem Inhalt, den Sie kommentieren möchten
. Zum Ende der Seite gehen
. Füllen Sie das Feld "Kommentar hinzufügen" aus und hinterlassen Sie Ihren Kommentar

image::features/comments/form.png[Comments form]

=== Aktionen

Teilnehmende können auf verschiedene Arten mit Kommentaren interagieren.

* Jede Person kann sie sortieren sowie Antwortthreads ein- und ausblenden.
* Teilnehmende können ausserdem auf Kommentare antworten, sie positiv oder negativ bewerten, sie melden oder den Link zum Kommentar abrufen.
* Autor:innen von Kommentaren können ihre eigenen Kommentare auch bearbeiten und löschen.

Sie können auf einige Aktionen direkt über den Kommentar zugreifen, auf andere über das Drei-Punkte-Menü neben einem Kommentar.

image::features/comments/actions.png[Comments actions]

==== Sortieren

Teilnehmende können Kommentare sortieren nach:
* Am besten bewertet: Kommentare mit den meisten positiven Bewertungen erscheinen zuerst in der Liste
* Aktuell: die neuesten Kommentare erscheinen zuerst.
* Älteste: ältere Kommentare erscheinen zuerst.
* Meist diskutiert: Kommentare mit den meisten verschachtelten Kommentaren erscheinen zuerst.

image::features/comments/order_by.png[Order comments]

Sie können Antworten auch ausblenden, wenn sie einen ganzen Kommentarthread nicht anzeigen möchten.

==== Antwort

Durch Klicken auf die Schaltfläche "Antworten" unter einem Kommentar können Teilnehmende anderen Teilnehmenden antworten und öffentliche Diskussionen führen.
Kommentare können bis zu vier Ebenen verschachtelt werden. Auf der vierten Ebene ist die Schaltfläche "Antworten" nicht mehr verfügbar.

image::features/comments/anidation_levels.png[Nested comments]

==== Positiv/negativ bewerten

Teilnehmende können Kommentare unterstützen, indem sie unten rechts bei jedem Kommentar auf das Symbol "Daumen hoch" klicken.
So können sie sich beteiligen und ihre Meinung äussern, ohne notwendigerweise auf einen Kommentar antworten zu müssen.

==== Melden

Bitte lesen Sie den Artikel xref:admin:moderations/reported_content.adoc[Gemeldete Inhalte], um mehr über das Melden von Inhalten zu erfahren.

==== Link abrufen

Durch Klicken auf den Eintrag "Link abrufen" werden Teilnehmende zur eigenen URL des Kommentars weitergeleitet.
Sie können diesen Link dann mit anderen teilen, und er führt sie direkt zu diesem einen Kommentar.
Es wird eine Meldung angezeigt, die die besuchende Person darauf hinweist, dass nur ein einzelner Kommentar angezeigt wird, mit einem Link, um alle anderen Kommentare zu sehen.

image::features/comments/single_comment.png[Edited comment]

==== Bearbeiten

Teilnehmende können ihre Kommentare bearbeiten, und nachdem sie dies getan haben, erscheint der Hinweis "Bearbeitet" bei ihrem Kommentar, um anderen
Teilnehmenden anzuzeigen, dass dieser Inhalt bearbeitet wurde.

Kommentare verfügen über keinen Versionsverlauf der vorgenommenen Änderungen.

image::features/comments/edited_comment.png[Edited comment]

==== Löschen

Sobald ein Kommentar gelöscht wurde, ist er nicht mehr sichtbar, und eine Meldung gibt das Datum an, an dem er gelöscht wurde.

image::features/comments/deleted_comment.png[Deleted comment]
