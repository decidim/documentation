= Hashtags

== Die Grundlagen verstehen

Hashtags sind eine Möglichkeit, Inhalte plattformweit zu kategorisieren und sie durch diese Kategorisierungen besser auffindbar zu machen.
So können verschiedene verwandte Inhalte unter demselben Thema auffindbar werden.
Eine ähnliche Funktion wird häufig auf anderen Social-Media-Plattformen verwendet.

Hashtags können für verschiedene Datensätze innerhalb der Plattform eingestellt werden, wie zum Beispiel partizipatorische Räume.
Sie können auch für Inhalte generiert werden, die von den Teilnehmenden erstellt wurden, um die Entdeckung der Inhalte zu erleichtern.
Einige Komponenten können auch die Einstellung empfohlener Hashtags oder spezifischer Hashtags für alle von den Teilnehmenden eingereichten Datensätze ermöglichen.

== Konfiguration

Teilnehmende können Hashtags in ihren Kommentaren, Debatten, Vorschlägen usw. hinzufügen.
Wenn eine teilnehmende Person auf einen Hashtag in einem Kommentar oder einem anderen Inhalt klickt, wird sie zur globalen Suche weitergeleitet.
