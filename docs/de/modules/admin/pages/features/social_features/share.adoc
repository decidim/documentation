= Teilen

== Die Grundlagen verstehen

Teilnehmende können Inhalte auf der Plattform über die Freigabelinks teilen, die auf den verschiedenen Inhaltsseiten verfügbar sind.
Die Freigabelinks ermöglichen das Teilen an verschiedene Social Media Dienste, die über die Konfigurationsdateien für Decidim konfiguriert werden können.

NOTE: Weitere Informationen finden Sie unter xref:customize:social_shares.adoc[Social-Share-Dienste].

== Konfiguration

=== Einen Inhalt teilen

Um einen Inhalt zu teilen, z. B. einen Vorschlag, gehen Sie zur Inhaltsseite und klicken Sie auf den Link "Teilen" rechts neben der Beschreibung.

image::features/share/share_button.png[Share button on resources]

Ein Modal erscheint mit verschiedenen Schaltflächen für unterschiedliche Anbieter sozialer Dienste.
Durch Klicken auf eine Schaltfläche wird die teilnehmende Person zum sozialen Netzwerk weitergeleitet und kann schnell eine Nachricht mit einem Link zur Inhaltsseite veröffentlichen oder versenden.
Teilnehmende können den Link auch unterhalb der Schaltflächen kopieren oder auf den Link bzw. das Symbol "Kopieren" klicken.

image::features/share/share_modal.png[Share modal]
