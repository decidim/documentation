= Newsletter

== Understand the basics

Newsletter können versendet werden, um Teilnehmende über die neuesten Nachrichten auf der Plattform zu informieren: die Lancierung einer neuen Konsultation, einen Hinweis
vor dem Ablauf einer Abstimmungsfrist, die Bekanntgabe eines Ergebnisses, den Fortschritt laufender Projekte usw.
Der Newsletter wird an alle Nutzenden der Website gesendet, die bei der Erstellung ihres Kontos oder später in ihren
xref:admin:features/participant_actions/my_account.adoc[Kontoeinstellungen] das Kästchen "Gelegentlichen Newsletter mit relevanten Informationen erhalten" angekreuzt haben.

image::features/newsletters/newsletter_contact_permission.png[Contact permission in participant registration]

image::features/newsletters/newsletter_participant_notifications_settings.png[Contact permission in participant account]

Einige Beispiele dafür, wann Sie einen Newsletter senden können und sollten:

* Wenn ein neuer Prozess für alle Bürger in einer Stadt interessant sein könnte, dann ist
zum Beispiel ein partizipatorischer Budgetprozess.
* Wenn die Ergebnisse für einen bestimmten Prozess veröffentlicht werden.
* Wenn eine Versammlung ein wichtiges Thema zu besprechen hat.
* Wenn eine neue Abstimmung geplant ist.
* Wenn eine neue Konferenz veröffentlicht wird.
* Usw.

=== How to find it?

Um auf das Newsletter-Panel zuzugreifen, gehen Sie zum Admin-Dashboard und klicken Sie in der Verwaltungsnavigation auf den Eintrag "Newsletter".

image::features/newsletters/newsletter_menu.png[Newsletter administrator menu]

Dort sehen Sie die Liste der bereits von dieser Instanz gesendeten Newsletter. Wenn es sich um eine neue Instanz handelt, sollten Sie in der
Liste keine Newsletter sehen.

image::features/newsletters/newsletter_list.png[Newsletter list]

== Konfiguration

=== Einen Newsletter erstellen

Um mit der Erstellung eines Newsletters zu beginnen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neuer Newsletter".

==== Eine Vorlage auswählen

Zunächst werden Sie gebeten, eine Newsletter-Vorlage auszuwählen, je nachdem, was Sie versenden möchten.
Es werden zwei Vorlagen mit jeweils einer Vorschau angezeigt, die Ihnen helfen, das beste Format für den Inhalt zu bestimmen, den Sie mitteilen möchten.

* Einfach (nur Text): empfohlen für kurze Mitteilungen
* Bild, Text und Handlungsaufforderungs-Schaltfläche: empfohlen für ausführlichere Inhalte

image::features/newsletters/newsletter_templates.png[Newsletter new templates selection]

Klicken Sie auf die Schaltfläche "Diese Vorlage verwenden" unterhalb der Vorlage, die Sie verwenden möchten.

==== Den Newsletter verfassen

Je nachdem, welche Vorlage Sie gewählt haben, müssen Sie ein Formular mit verschiedenen Feldern ausfüllen.

NOTE: Sie können "%\{name}" an beliebiger Stelle im Text oder Betreff verwenden, um automatisch durch den Namen der teilnehmenden Person ersetzt zu werden.

Sobald Sie den Newsletter verfasst haben, klicken Sie auf die Schaltfläche "Speichern und Vorschau anzeigen".

==== Vorschau des Newsletters

Auf der Vorschauseite können Sie das Erscheinungsbild und den Inhalt des Newsletters vor dem Versand überprüfen.
Solange Sie den Newsletter nicht versendet haben, können Sie ihn jederzeit bearbeiten und seine Vorschau überprüfen.

image::features/newsletters/newsletter_preview_basic_example.png[Newsletter new template basic form preview]

==== Eine Test-E-Mail senden

Wenn Sie den Newsletter direkt in Ihrem Postfach überprüfen möchten, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Mir eine Test-E-Mail senden".
Sie erhalten den Newsletter direkt an die für Ihr Teilnehmendenkonto registrierte E-Mail-Adresse.

==== Empfänger auswählen

Wenn Sie nur über einen bestimmten Raum oder ein bestimmtes Quartier informieren möchten, können Sie auswählen, an welche Teilnehmenden Sie den Newsletter senden.
Klicken Sie dazu auf die Schaltfläche "Empfänger:innen für den Versand auswählen".

NOTE: Wenn Sie Ihren Newsletter nicht an ein bestimmtes Segment senden möchten, wählen Sie "An alle Nutzenden senden"

Dort können Sie wählen, ob der Newsletter gesendet werden soll an:

* Alle bestätigten Nutzenden
* Alle bestätigten Nutzenden, die an einem der ausgewählten Beteiligungsräume in der Liste teilgenommen haben
* Alle bestätigten Nutzenden, die einem der ausgewählten Beteiligungsräume in der Liste folgen
* Alle Teilnehmenden, die in ihren Einstellungen unter "Meine Interessen" in ihrem Konto ein Thema ausgewählt haben.

NOTE: Auch wenn eine teilnehmende Person ein bestätigtes Konto hat und einem Raum folgt, sendet das System ihr keine Newsletter-E-Mail, wenn sie
dies nicht in ihren xref:admin:features/participant_actions/my_account#_notifications_settings.adoc[Benachrichtigungseinstellungen] akzeptiert hat.

image::features/newsletters/newsletter_select_recipients.png[Newsletter select recipients]

Wenn Sie "An Teilnehmende senden" oder "An Follower senden" eines bestimmten Raums auswählen,
können Sie anschliessend festlegen, welche Räume relevant sind.

image::features/newsletters/newsletter_select_recipients_spaces.png[Newsletter select recipients spaces]

==== Den Newsletter liefern

Wenn Sie schliesslich auf die Schaltfläche "Newsletter versenden" klicken, wird der Newsletter an alle ausgewählten Empfänger:innen gesendet.
Vor dem Versand erscheint ein Pop-up, um sicherzustellen, dass Sie alles überprüft haben und zum Versand bereit sind.

image::features/newsletters/newsletter_deliver_modal.png[Newsletter deliver modal]

NOTE: Sobald ein Newsletter gesendet wurde, kann dies nicht rückgängig gemacht oder bearbeitet werden. Wenn Sie mehrere Sprachen aktiviert haben,
achten Sie darauf, alle Sprachversionen vor dem Versand sorgfältig zu überprüfen.

=== Newsletter verwalten

Auf der Newsletter-Seite finden Sie alle Newsletter mit:

* *Betreff*: Betreff des Newsletters, führt zur Newsletter-Vorschau.
* *Erstellt am*: Datum der Erstellung des Newsletters.
* *Gesendet am*: Datum des Versands des Newsletters.
* *Gesendet an*: das Segment, an das der Newsletter gesendet wurde.
* *Fortschritt*: die Anzahl der Teilnehmenden, an die der Newsletter bereits gesendet wurde, im Verhältnis zur Gesamtzahl der Empfänger:innen.
