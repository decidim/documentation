= Suchmaschine

== Die Grundlagen verstehen

*Die Suchmaschine* ermöglicht es Teilnehmenden, Suchen über alle indexierbaren Inhalte der Plattform durchzuführen,
sowohl allgemein als auch spezifisch, indem sie innerhalb eines bestimmten Beteiligungsprozesses oder dessen Komponenten
(Vorschläge, Ergebnisse usw.) über erweiterte Suchen suchen.

=== Wie findet man sie?

Die Suchmaschine ist in der Kopfzeile der Instanz neben dem Logo Ihrer Plattform zugänglich.

image::features/search/search_input.png[Search input in frontend navigation bar]

In der Suchleiste können Sie ein Wort eingeben oder einfach eine leere Suche durchführen, um zur Suchergebnisseite zu gelangen.

image::features/search/search_page.png[Search results page example]

Die Suchmaschine sucht den eingegebenen Begriff in allen Titeln und Beschreibungen der Ressourcen.

Sie können die Suche auch filtern, indem Sie auf die Ressourcentypen auf der linken Seite klicken.
