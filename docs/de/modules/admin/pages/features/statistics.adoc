= Statistiken

Decidim liefert allgemeine Statistiken über die gesamte Plattform und verschiedene Beteiligungsräume können auch Statistiken über diesen partizipatorischen Raum liefern. Dies sind generische Zahlen, die die Aktivität der Website angeben und können auch andere Menschen ermutigen, der Plattform beizutreten, wie sie es für beliebt halten.
