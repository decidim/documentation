= Mein öffentliches Profil

== Die Grundlagen verstehen

Jede teilnehmende Person hat ein öffentliches Profil, das Details zu ihr und ihrer Aktivität auf der Instanz anzeigt.
Diese Profilseite ist für alle Teilnehmenden und Besuchenden zugänglich.

=== Wie findet man sie?

Um das öffentliche Profil einer teilnehmenden Person zu sehen, klicken Sie direkt auf ihren Avatar oder ihren Benutzernamen im Teilnehmenden-Tooltip.

image::features/my_profile/profile_pop_up.png[Participant tool-tip]

Als angemeldete teilnehmende Person können Sie von zwei Stellen aus auf Ihr öffentliches Profil zugreifen:

. Klicken Sie in der Kopfzeile auf Ihren Avatar und anschliessend auf den Menüpunkt "Mein öffentliches Profil"
. Klicken Sie in der Fusszeile im Abschnitt "Mein Konto" auf den Link "Mein öffentliches Profil"

image::features/my_profile/profile_dropdown.png[Frontend user menu dropdown]

=== Profil-Tabs

Dort finden Sie verschiedene Tabs.

NOTE: Möglicherweise sehen Sie die Tabs Abzeichen und Gruppen nicht, wenn Sie sie nicht im
      xref:admin:settings/configuration.adoc[Konfigurationspanel] aktiviert haben.

==== Aktivität

Dieser Tab zeigt die gesamte Aktivität der teilnehmenden Person an, beginnend mit den neuesten Inhalten.

image::features/my_profile/profile_activity.png[Public profile activity tab]

==== Abzeichen

Die Abzeichen des öffentlichen Profils zeigen, welche Abzeichen die teilnehmende Person angesammelt hat und wie hoch ihr aktueller Stand für jedes Abzeichen ist.

Weitere Informationen zu Abzeichen finden Sie auf der Seite xref:admin:features/social_features/badges.adoc[Funktion Abzeichen].

image::features/my_profile/profile_badges.png[Public profile badges tab]

==== Folgt

Im Folgenden finden Sie eine Liste der Teilnehmenden und Gruppen, denen die teilnehmende Person derzeit folgt.
Indem sie einer anderen teilnehmenden Person oder einer Gruppe auf der Plattform folgt, erhält die teilnehmende Person Benachrichtigungen über die Aktivitäten,
      die diese Teilnehmenden oder Gruppen auf der Plattform durchführen. Einige Teilnehmende benötigen möglicherweise auch, dass sie einer
      teilnehmenden Person folgen müssen, bevor sie private Nachrichten miteinander austauschen können.

image::features/my_profile/profile_follows.png[Public profile follows tab]

==== Follower

Der Abschnitt Follower enthält eine Liste von Teilnehmenden und Gruppen, die der teilnehmenden Person folgen.

image::features/my_profile/profile_followers.png[Public profile followers tab]

==== Gruppen

Der Abschnitt Gruppen enthält alle Gruppen, zu denen die teilnehmende Person gehört.

image::features/my_profile/profile_groups.png[Public profile groups tab]

== Konfiguration

=== Auf dem Profil einer anderen teilnehmenden Person

Angemeldete Teilnehmende können auf der öffentlichen Profilseite einer anderen teilnehmenden Person zwei Aktionen durchführen:

. Ihr eine Nachricht senden
. Ihr folgen
. Sie melden

=== Auf dem eigenen Profil

Angemeldete Teilnehmende können auf ihrer öffentlichen Profilseite zwei Aktionen durchführen:

. Ihr Profil bearbeiten: Beim Klicken auf diese Schaltfläche werden sie zu ihrem xref:admin:features/participant_actions/my_account.adoc[Konto] weitergeleitet.
. Eine Gruppe erstellen: Beim Klicken auf diese Schaltfläche werden sie zum xref:admin:features/participant_actions/group_profile.adoc[Formular zur Gruppenerstellung] weitergeleitet.

NOTE: Die Option zur Gruppenerstellung ist nur verfügbar, wenn Gruppen für die Organisation aktiviert sind.
