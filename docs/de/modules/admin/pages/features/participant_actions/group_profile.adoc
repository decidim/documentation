= Gruppenprofile

== Die Grundlagen verstehen

Als teilnehmende Person möchten Sie vielleicht eine Benutzergruppe für Ihren Verein, Ihr Unternehmen, Ihren Club usw. erstellen.
Wenn ein Admin bestätigt, dass Sie berechtigt sind, diese Gruppe zu vertreten, können Sie in der Instanz im
Namen der Gruppe teilnehmen.

NOTE: Die Option zur Gruppenerstellung ist nur verfügbar, wenn Gruppen für die Organisation aktiviert sind.
Sie können einen Admin der Plattform darum bitten, oder es im Panel xref:admin:settings/configuration.adoc[Konfiguration] aktivieren.

== Konfiguration

=== Eine Gruppe erstellen

Um eine Gruppe zu erstellen, klicken Sie in Ihrem öffentlichen Profil auf die Schaltfläche "Gruppe erstellen".

image::features/my_profile/profile_create_group.png[Public profile group creation form]

.Formular zur Gruppenerstellung
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Name der Organisation, des Vereins, des Kollektivs, der Gruppe usw.

|Spitzname
|Benötigt
|Spitzname der Organisation, des Vereins, des Kollektivs, der Gruppe usw. Verwenden Sie keine Leerzeichen oder Akzente.

|E-Mail
|Benötigt
|E-Mail Ihrer Organisation, Vereinigung, Kollektiv, Gruppe, etc.

|Avatar
|Optional
|Avatar Ihrer Organisation, der als Benutzeravatar angezeigt wird. Kann ein Logo, ein Bild usw. sein.

|Über
|Optional
|Weitere Informationen über Ihre Organisation. Dies wird öffentlich auf der Profilseite der Benutzergruppe angezeigt.

|Dokumentennummer
|Optional
|Füllen Sie dieses Feld aus, wenn ein Admin die Echtheit Ihrer Benutzergruppe verifizieren soll.

|Telefon
|Optional
|Füllen Sie dieses Feld aus, wenn ein Admin jemanden in Ihrer Organisation anrufen können soll, um
die Echtheit der Benutzergruppe zu verifizieren.
|===

Die Benutzergruppe ist auf der Plattform sichtbar, sobald Sie sie erstellen. Nach der Erstellung werden Sie auf die
Profilseite der Benutzergruppe weitergeleitet.

Die Profilseiten von Benutzergruppen zeigen:

* Mitglieder: Mitglieder der Gruppe und wer die Admins sind.
* Abzeichen: Abzeichen der Benutzergruppe.
* Follower: Teilnehmende können Benutzergruppen auch folgen.

=== Eine Gruppe verwalten

Nach der Bildung einer Gruppe ist es möglich, Teilnehmende einzuladen, Mitglieder der Gruppe zu werden.
Nachdem eine teilnehmende Person der Aufnahme in diese Gruppe zugestimmt hat, kann sie Admin werden.

Die Aktionen, die ein Admin einer Benutzergruppe durchführen kann, sind:

* Gruppenprofil bearbeiten
* Mitglieder verwalten
* Admins verwalten
* Teilnehmende einladen
* Gruppe verlassen

image::features/my_profile/profile_manage_group.png[Public profile group drop down menu]

==== Mitglieder verwalten

Auf dieser Seite können Sie Beitrittsanfragen von Teilnehmenden zu Ihrer Gruppe annehmen oder ablehnen, aber auch Gruppenmitglieder zu Admins befördern
oder sie aus der Gruppe entfernen.

image::features/my_profile/user_group_manage_participant.png[User groups: manage participants]

==== Admins verwalten

Auf dieser Seite können Sie nur die Admin-Rechte in der Gruppe entziehen, wodurch die teilnehmende Person jedoch nicht aus der Gruppe entfernt wird.

image::features/my_profile/user_group_manage_admins.png[User groups: manage admins]

==== Teilnehmende einladen

Um eine teilnehmende Person einzuladen, muss sie ein Konto auf der Plattform haben.
Sie können sie über ihren Spitznamen einladen.

image::features/my_profile/user_group_invite_participant.png[User groups: invite a participant]

Anschliessend erhält sie eine Einladung, der Gruppe beizutreten. Sie kann diese annehmen oder ablehnen.

==== Unterhaltungen

Sie können auch Gespräche als Gruppe führen.

image::features/my_profile/user_group_conversation.png[User group: conversations]

=== Als Gruppe teilnehmen

NOTE: Damit Admins einer Benutzergruppe als Gruppe teilnehmen können, muss ein Admin der Instanz die Gruppe verifiziert haben.

Der Vorteil, wenn ein Admin die Benutzergruppe verifiziert, besteht darin, dass Sie dann als Gruppe an der Plattform teilnehmen
und Debatten, Vorschläge, Veranstaltungen, Kommentare usw. erstellen können.

Admins der Benutzergruppe können zum Beispiel im Namen ihrer Gruppe kommentieren.

image::features/my_profile/user_group_make_comment.png[User group: make a comment]

Sie können auch wählen, eine Debatte oder einen Vorschlag im Namen ihrer Gruppe und/oder in ihrem eigenen Namen zu unterstützen.

image::features/my_profile/user_group_endorse.png[User group: endorse]
