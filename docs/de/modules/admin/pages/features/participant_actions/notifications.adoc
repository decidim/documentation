= Benachrichtigungen

== Die Grundlagen verstehen

Benachrichtigungen ermöglichen es Teilnehmenden, über die neuesten Nachrichten der Plattform, Räume, Inhalte, Teilnehmende, denen sie folgen, usw. auf dem Laufenden zu bleiben.
Die meisten Aktionen auf der Plattform lösen Benachrichtigungen aus.

Teilnehmende können ihre Benachrichtigungseinstellungen in ihrem xref:admin:features/participant_actions/my_account.adoc[Konto] verwalten.

=== Wie findet man sie?

Als angemeldete teilnehmende Person können Sie an zwei Stellen auf Ihre Benachrichtigungen zugreifen:

. Klicken Sie auf Ihren Avatar in der Kopfzeile und anschliessend auf den Menüpunkt "Benachrichtigungen"
. Klicken Sie auf den Link "Benachrichtigungen" in der Fusszeile, im Abschnitt "Mein Konto"

image::features/notifications/notifications_dropdown.png[Frontend user menu dropdown]

Wenn es Benachrichtigungen gibt, sieht die teilnehmende Person ein kleines Abzeichen neben ihrem Avatar sowie im Dropdown-Menü.

image:features/notifications/notifications.png[Beispiel der Benachrichtigungsseite wenn Benachrichtigungen vorhanden sind]

Wenn keine Benachrichtigungen vorliegen oder die teilnehmende Person alle Benachrichtigungen als gelesen markiert hat, wird eine Meldung angezeigt, dass keine neuen Benachrichtigungen vorliegen.

image:features/notifications/no_notifications_yet.png[Beispiel der Benachrichtigungsseite, wenn keine Benachrichtigungen vorhanden sind]

=== Benachrichtigungsliste

Unten ist eine erschöpfende Liste von Aktionen, die Benachrichtigungen an Teilnehmende auslösen. Die Teilnehmenden sind in drei Kategorien unterteilt: betroffene Nutzende, Follower und Admins.

NOTE: Betroffene Nutzende sind abhängig vom Benachrichtigungskontext. Zum Beispiel könnte es sich um die Autorenschaft eines moderierten Inhalts handeln, dass eine nutzende Person ein Abzeichen erhält, dass eine nutzende Person erwähnt wurde usw., je nach Interaktion der nutzenden Person mit den Räumen und anderen Nutzenden auf der Plattform.
