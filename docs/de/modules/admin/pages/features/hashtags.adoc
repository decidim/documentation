= Hashtags

Hashtags sind eine Möglichkeit, Inhalte global auf der Plattform zu kategorisieren und sie durch diese Kategorien leichter durchsuchen zu können. Es ermöglicht verschiedene verwandte Inhalte leicht unter dem gleichen Thema zu entdecken. Ähnliche Funktionalität wird oft in anderen Social Media Plattformen verwendet.

Hashtags können für verschiedene Datensätze innerhalb der Plattform eingestellt werden, wie zum Beispiel partizipatorische Räume. Sie können auch für Inhalte generiert werden, die von den Teilnehmern erstellt wurden, um die Entdeckung der Inhalte zu erleichtern. Einige Komponenten können auch die Einstellung empfohlener Hashtags oder spezifischer Hashtags für alle von den Teilnehmern eingereichten Datensätze ermöglichen.
