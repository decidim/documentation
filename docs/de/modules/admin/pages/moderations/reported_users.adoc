= Gemeldete Teilnehmende

== Die Grundlagen verstehen

Es gibt Fälle, in denen Teilnehmende gegen die Nutzungsbedingungen der
      Plattform verstossen könnten. Daher ist es nützlich, die Möglichkeit zu haben, Teilnehmende zu melden und zu blockieren.
Sie können Teilnehmende über den xref:participants/participants.adoc[Abschnitt Teilnehmende
      im Verwaltungspanel] oder über den Abschnitt "Gemeldete Teilnehmende" blockieren.

== Konfiguration

=== Eine teilnehmende Person melden

Jede angemeldete teilnehmende Person kann eine andere teilnehmende Person über die Schaltfläche "Melden" im
      Profil der teilnehmenden Person melden.

image::moderations/moderations_reported_participant_flag.png[Report flag in participant profile]

Nachdem eine teilnehmende Person auf diese Aktion geklickt hat, muss sie einen Grund für diese Meldung angeben:

image::moderations/reported_participant_modal_user.png[Give reason for reporting a participant modal]

Wenn ein Admin oder eine moderierende Person eine teilnehmende Person meldet, stehen ihnen zusätzliche Optionen zur Verfügung, mit denen sie
      die Person direkt blockieren und alle ihre Inhalte verbergen können. Sie müssen eine Begründung für die Blockierung dieser teilnehmenden Person angeben.

image::moderations/reported_participant_modal_admin.png[Give reason for reporting a participant modal administrators]

=== Gemeldete Teilnehmende verwalten

Gemeldete Teilnehmende sind im Abschnitt "Gemeldete Teilnehmende" des globalen Moderationspanels sichtbar.

image::moderations/moderations_backend_list_users.png[Global moderations panel for users]

Sie finden alle gemeldeten Teilnehmenden in der Liste der gemeldeten Teilnehmenden im Verwaltungspanel mit:

* *Name*: Name der teilnehmenden Person, mit einem Link zu ihrem Profil.
* *Spitzname*: Spitzname der teilnehmenden Person, mit einem Link zu ihrem Profil.
* *Grund*: Warum die teilnehmende Person gemeldet wird. Falls die teilnehmende Person, die die Meldung gemacht hat, zusätzliche
      Informationen angegeben hat, können Sie diese durch Hovern anzeigen.
* *Gemeldet am*: Wann sie ursprünglich gemeldet wurden.
* *Anzahl Meldungen*: Anzahl der Meldungen von verschiedenen Nutzenden.
* *Aktionen*: Sie können bei der teilnehmenden Person die *Meldung zurückweisen* oder sie *blockieren*.

=== Eine teilnehmende Person blockieren

Wenn bei einem Inhalt die Meldung versehentlich "zurückgewiesen" wurde, müssen Sie ihn erneut auf der öffentlichen Plattform finden
      und erneut melden, damit Sie ihn moderieren können.

Admins müssen eine Begründung angeben, wenn sie eine teilnehmende Person blockieren möchten.
Sie können auch xref:templates/block_users.adoc[Vorlagen für Nachrichten zum Blockieren von Nutzenden] definieren, um vordefinierte Begründungen zu haben.

image:moderations/moderations_participants_block_user_justification.png[Begründung für Blockierungsaktion]

Wenn eine blockierte teilnehmende Person versucht, sich anzumelden, wird eine Fehlermeldung angezeigt:

image:moderations/moderations_participants_block_user_alert.png[Nachricht für blockierte Teilnehmende]

Die Namen blockierter Teilnehmender werden zu "Blockierte teilnehmende Person." geändert
