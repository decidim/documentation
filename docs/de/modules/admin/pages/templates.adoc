= Vorlagen

== Die Grundlagen verstehen

Der Tab Vorlagen ermöglicht es Ihnen, Vorlagen zu erstellen und Zeit bei der Verwaltung Ihrer Instanz zu sparen.
Sie können Vorlagen für drei verschiedene Elemente erstellen:

* *Fragebögen*: zur Erstellung von Vorlagenumfragen in der xref:admin:components/surveys.adoc[Umfrage-Komponente]
* *Nachrichten zum Blockieren von Nutzenden*: zur Erstellung von Vorlagenbegründungen für das Blockieren von xref:admin:moderations/reported_users.adoc[gemeldeten Teilnehmenden]
* *Vorschlagsantworten*: zur Erstellung von Vorlagen für xref:admin:components/proposals/answers.adoc[Antworten auf Vorschläge]

Einmal erstellt, stehen diese Vorlagen allen Admins zur Verfügung und helfen ihnen, die Instanz effizienter zu verwalten.

== Konfiguration

Um auf das Konfigurationspanel für Vorlagen zuzugreifen, gehen Sie zum Verwaltungspanel und klicken Sie in der Verwaltungsnavigationsleiste auf den Punkt "Vorlagen".

image::templates/templates_menu.png[Pages: Access templates panel]

Dort können Sie mit dem Erstellen und Verwalten beginnen:

* xref:admin:templates/questionnaires.adoc[Fragebogenvorlagen]
* xref:admin:templates/block_users.adoc[Nachrichten für gesperrte Nutzende]
* xref:admin:templates/proposal_answers.adoc[Vorschlagsantworten]

image::templates/templates_questionnaires_list.png[Backend: templates panel]

== Beispiele

Am Ende jedes durchgeführten Beteiligungsprozesses möchten Sie das Feedback der Teilnehmenden einholen.
Die Erstellung einer Fragebogenvorlage macht die Umfrageerstellung schneller, als die Umfrage und ihre Fragen für jeden Prozess neu zu erstellen.

Auf einigen Plattformen kann es auch Spam-Konten geben, die Sie jedes Mal aus demselben Grund schnell blockieren möchten.
Die Erstellung einer Begründungsvorlage ermöglicht es Ihnen, diese Begründung beim Blockieren eines Spam-Kontos schnell auszuwählen, anstatt sie jedes Mal
erneut zu schreiben.

Dasselbe gilt für Vorschlagsantworten: Manchmal möchten Sie dieselbe Antwort auf viele verschiedene Vorschläge geben. Die Erstellung einer Vorschlagsantwort-Vorlage ermöglicht es Ihnen und den Prozess-Admins, Vorschläge effizienter zu verwalten.
