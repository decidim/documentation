= Autorisierung über die Zählung der Organisation

== Die Grundlagen verstehen

Die Berechtigung Zählung der Organisation ermöglicht es Admins, eine Liste mit E-Mail-Adressen von Teilnehmenden hochzuladen, damit diese
Liste bestimmte Aktionen auf der Plattform durchführen kann, wie zum Beispiel das Erstellen eines Vorschlags in einem bestimmten Raum usw.

== Konfiguration

Der Prozess lautet wie folgt:

. Admins laden eine CSV-Datei mit den E-Mail-Adressen der verifizierten Teilnehmenden hoch
. Teilnehmende gehen zu ihrem Konto und beantragen die Verifizierung
. Nur Teilnehmende mit einer E-Mail in dieser CSV-Datei können verifiziert werden

NOTE: Ist Ihnen diese Berechtigung zu einfach und benötigen Sie weitere Funktionen im Zusammenhang mit CSV-Zensus-Importen?
Alle CSV- oder dateibasierten Berechtigungen finden Sie auf der https://decidim.org/modules/[Modulseite].

=== 1. CSV-Upload

Im Verwaltungspanel können Sie eine CSV-Datei hochladen, indem Sie im Abschnitt "Teilnehmende" auf "Zählung der Organisation" klicken.

image::participants/authorizations_organization_census.png[Organization's census in administrator panel]

Nachdem die CSV-Datei importiert wurde, kann der Admin sehen, wie viele Teilnehmende importiert wurden. Sie können auch diese
importierte Zählung löschen.

image::participants/authorizations_organization_census_imported.png[Imported CSV]

=== 2. Anfrage der teilnehmenden Person

Indem eine teilnehmende Person zum Autorisierungsbereich in ihrem Profil geht oder auf die Schaltfläche "Aktion" klickt, falls diese Berechtigung angefordert wird, kann sie eine Überprüfung beantragen.

image::participants/authorizations_organization_census_account.png[Organization's census in participant's accounts]

=== 3. Verifizierung der teilnehmenden Person

Nach der Überprüfung können sie es wie bei anderen Überprüfungen in ihren Kontoeinstellungen sehen.

image::participants/authorizations_organization_census_verified.png[Verified by organization's census]
