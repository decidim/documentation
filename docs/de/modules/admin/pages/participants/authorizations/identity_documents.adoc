= Autorisierung durch Identitätsdokumente

== Die Grundlagen verstehen

Diese Berechtigung ermöglicht es einer teilnehmenden Person, ihre Identitätsdokumente auf die Plattform hochzuladen und ihr Konto verifizieren zu lassen.
Diese Dokumente hängen von der Organisation ab, es könnte sich um einen Führerschein, einen Pass, eine nationale Identitätskarte,
      einen Vereinsausweis usw. handeln.

NOTE: Wenn Sie keine Daten sammeln möchten, sollten Sie dies im xref:configure:system.adoc[Systempanel] deaktivieren.

Diese Dokumente werden von einem Admin geprüft, der sie akzeptieren oder ablehnen kann. Dieser Prozess kann
      auf zwei Arten durchgeführt werden:

* *Online*: Die teilnehmende Person wird gebeten, die Dokumente hochzuladen, und der Admin prüft diese Dokumente.
* *Offline*: Die teilnehmende Person wird gebeten, einige Daten einzugeben, und muss dann persönlich an einen physischen Ort gehen,
      um ihre Dokumente vorzuzeigen.

== Konfiguration

Klicken Sie auf die Schaltfläche "Konfigurieren", um die Berechtigung zu konfigurieren.

=== Online-Verifizierung

Der Prozess ist:

. Teilnehmende tragen ihren Dokumententyp und ihre Nummer ein und laden eine Kopie ihres Dokuments hoch.
. Ein Admin füllt die im hochgeladenen Bild enthaltenen Informationen aus.
. Die Informationen sollten dem entsprechen, was die teilnehmende Person ausgefüllt hat.
. Wenn der Admin die Informationen nicht sehen kann oder sie nicht verifizieren kann, kann er die Anfrage ablehnen, und
      die teilnehmende Person kann das Problem beheben.

==== 1. Erstellung der Teilnehmenden-Berechtigung

Indem eine teilnehmende Person zum Autorisierungsbereich in ihrem Profil geht oder auf die Schaltfläche "Aktion" klickt, falls diese Berechtigung angefordert wird, kann sie das Formular zum Hochladen einer Kopie ihres Dokuments sehen. Sie müssen auch ihren Dokumententyp und ihre Nummer eingeben.

image::participants/authorizations_id_document_online.png[ID document authorization online form]

NOTE: Sie können die Optionen für die Dokumenttypen ändern, indem Sie xref:customize:code.adoc[den Code anpassen oder überschreiben].

==== 2. Dokumentenprüfung durch den Admin

Nachdem dieses Dokument hochgeladen wurde, kann ein Admin es prüfen, indem er im Verwaltungspanel
      zum Abschnitt Identitätsdokumente geht.

image::participants/authorizations_id_document_online_pending.png[ID document authorization pending online verification]

Nach dem Klicken auf den Verifizierungs-ID-Link oder auf das Dokument muss der Admin das Bild prüfen und
      die Dokumentennummer in das Feld eintragen. Diese Nummer muss mit der von der teilnehmenden Person angegebenen übereinstimmen.

image:participants/authorizations_id_document_online_confirm.png[Formular zur Online-Bestätigung der ID-Dokumenten-Berechtigung]

==== 3. Entscheidung des Admins

Ein Admin kann zwei Aktionen durchführen:

* Verifizieren: Das System prüft, ob die vom Admin und von der teilnehmenden Person eingegebenen Dokumentennummern übereinstimmen.
* Ablehnen: Die teilnehmende Person muss ihre Berechtigung bearbeiten, wenn sie verifiziert werden möchte.

Wird die Anfrage abgelehnt, kann die teilnehmende Person andere Bilder oder Dokumente angeben.

image::participants/authorizations_id_document_online_rejected.png[ID document authorization rejected online verification]

Sobald eine teilnehmende Person verifiziert ist, werden ihre Dokumente aus der Liste gelöscht.

=== Offline-Verifizierung

Der Prozess ist:

. Teilnehmende tragen ihren Dokumententyp und ihre Nummer ein.
. Teilnehmende befolgen die ihnen zur Verfügung gestellten Anweisungen. Zum Beispiel, wenn sie an einen bestimmten Ort in einer
bestimmten Zeit gehen müssen, um ihre Dokumente anzuzeigen.
. Ein Admin besucht das "Offline-Überprüfung" Panel und füllt die in den physischen Dokumenten enthaltenen Informationen aus.
. Die Informationen sollten dem entsprechen, was die teilnehmende Person ausgefüllt hat.
. Wenn der Admin die Informationen nicht sehen kann oder sie nicht verifizieren kann, kann er die Anfrage ablehnen, und
      die teilnehmende Person kann es dann beheben.

Damit diese Berechtigung funktioniert, muss ein Admin sie zunächst im Verwaltungspanel konfigurieren, mit Anweisungen, die erklären,
      was die teilnehmende Person tun muss, um den Verifizierungsprozess abzuschliessen.

image:participants/authorizations_id_document_configuration_offline.png[Konfiguration der ID-Dokumenten-Berechtigung: Offline-Anweisungen]

==== 1. Erstellung der Teilnehmenden-Berechtigung

Indem eine teilnehmende Person zum Autorisierungsbereich in ihrem Profil geht oder auf die Schaltfläche "Aktion" klickt, falls diese Berechtigung angefordert wird, kann sie das Formular zum Ausfüllen ihres Dokumenttyps und ihrer Nummer sehen.

image:participants/authorizations_id_document_offline_request.png[Offline-Formular der ID-Dokumenten-Berechtigung]

==== 2. Dokumentenprüfung durch den Admin

Im Verwaltungspanel kann der Admin die Anfrage prüfen, indem er auf die Schaltfläche "Offline-Verifizierung" klickt.

image::participants/authorizations_id_document_offline_button.png[ID document authorization offline button in administration]

Anschliessend müssen sie einige von der teilnehmenden Person angegebene Daten eintragen und das physisch vorgelegte Dokument prüfen.

image::participants/authorizations_id_document_offline_confirm.png[ID document authorization offline confirmation form in administration]

.Offline-Formular der ID-Dokumenten-Berechtigung
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Teilnehmenden-E-Mail
|Benötigt
|E-Mail der registrierten teilnehmenden Person

|Typ des Dokuments
|Benötigt
|Kann sein: Ausweis oder Reisepass

|Dokumentennummer
|Benötigt
|Dokumentennummer der teilnehmenden Person. Zum Beispiel "12345678Z"
|===

==== 3. Entscheidung des Admins

In den Fällen, in denen die Verifizierungen nicht übereinstimmen (das heisst, wenn die von der teilnehmenden Person angegebene E-Mail-Adresse oder Dokumentennummer
      nicht mit der vom Admin eingegebenen übereinstimmt), muss die teilnehmende Person dies in ihrem
      Benutzerkonto bearbeiten.

=== Beides

Es ist auch möglich, diese beiden Überprüfungsmethoden zu aktivieren. In diesem Fall muss die teilnehmende Person auswählen,
      welche Art der Verifizierung sie durchführen möchte.
