= Code per Postbuchstabenautorisierung

This authorization allows a participant to request for a verification code to be sent to its address, to confirm that they
live or work in this place. They will need to then fill the code in the platform.

Der Prozess ist:

. Teilnehmer beantragen einen Bestätigungscode, der an ihre Adresse gesendet werden soll.
. Ein Administrator sendet den Brief an seine Adresse mit dem Bestätigungscode.
. Ein Administrator markiert den Buchstaben als gesendet.
. Sobald Sie den Brief als gesendet markiert haben, kann der Teilnehmer den Code einführen.
. If this code matchs, then they get verified.

== 1. Ein Teilnehmer fordert den Bestätigungscode an

By going to the authorization section in its profile, or by clicking on the action button if this permission is requested,
a participant can see the form for filling in their full address to request the verification code.

image:authorizations_code_postal_letter_request.png[Code per Postbuchstabenanfrage des Teilnehmers]

If they try to edit it, they will see this message:

image:authorizations_code_postal_letter_edit.png[Postbuchstabenanfrage bearbeiten]

Das liegt daran, dass der Brief im Prozess der Versendung sein könnte. Wenn dies korrigiert werden muss, benötigt der Teilnehmer
um sich mit der Organisation in Verbindung zu setzen.

== 2. Ein Administrator überprüft diese Anfrage und sendet den Brief

Im Admin-Panel kann der Administrator die Anfrage unter dem Menüpunkt "Code per Postfach" im Bereich "Teilnehmer" einsehen.

image:authorizations_code_postal_letter_ongoing.png[Code durch Postbuchstaben laufende Panel in admin]

Here they can see the verification code and can send it to the participant by mail. After the code is sent they can mark it
as sent with the icon image:action_mark_as_sent.png[Mark as sent]. Es wird auch angezeigt, wann der Brief gesendet wurde.

== 3. Ein Teilnehmer füllt den Bestätigungscode aus

After the participant has received the code, they can go to their account settings and click in the "Code by postal letter"
verfication method.

image:authorizations_code_postal_letter_verify.png[Code per Postanschrift im Teilnehmer-Konto]

Then they will see the form for confirming the code.

image:authorizations_code_postal_letter_confirm.png[Code per Postschreiben Bestätigungsformular]

== 4. Der Bestätigungscode stimmt mit oder nicht überein

Wenn der Bestätigungscode übereinstimmt, dann wird der Teilnehmer die Nachricht "Herzlichen Glückwunsch". Sie wurden erfolgreich überprüft".

Auf der anderen Seite, wenn der Verifizierungscode nicht übereinstimmt, wird der Teilnehmer die Nachricht "Ihr Verifizierungscode
stimmt nicht mit unserer überein. Bitte überprüfen Sie den Brief, den wir Ihnen geschickt haben."

Nach der Überprüfung können sie es wie bei anderen Überprüfungen in ihren Kontoeinstellungen sehen.

image:authorisations_code_postal_letter_verified.png[Verifiziert durch Code per Brief]
