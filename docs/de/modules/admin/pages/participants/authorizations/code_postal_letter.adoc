= Code per Brief-Autorisierung

== Die Grundlagen verstehen

Diese Berechtigung ermöglicht es einer teilnehmenden Person, einen Verifizierungscode an eine Adresse senden zu lassen, um zu bestätigen, dass sie
      an diesem Ort wohnt oder arbeitet. Anschliessend muss sie den erhaltenen Code auf der Plattform eingeben.

NOTE: Wenn Sie keine Daten sammeln möchten, sollten Sie dies im xref:configure:system.adoc[Systempanel] deaktivieren.

== Konfiguration

Der Prozess ist:

. Die teilnehmende Person beantragt, dass ein Verifizierungscode an eine Adresse gesendet wird.
. Ein Admin sendet den Brief mit dem Bestätigungscode an die Adresse der teilnehmenden Person.
. Ein Admin markiert den Brief als gesendet.
. Sobald Sie den Brief als versendet markieren, kann die teilnehmende Person den Code eingeben.
. Wenn dieser Code übereinstimmt, wird sie verifiziert.

=== 1. Anfrage für Verifizierungscode

Indem sie zum Berechtigungsbereich in ihrem Profil geht oder auf die Aktionsschaltfläche klickt, wenn diese Berechtigung angefordert wird,
      sieht eine teilnehmende Person das Formular, in dem ihre vollständige Adresse abgefragt wird.

image::participants/authorizations_code_postal_letter_request.png[Code by postal letter request by participant]

Wenn sie versucht, sie zu bearbeiten, sieht sie diese Meldung:

image::participants/authorizations_code_postal_letter_edit.png[Edit the postal letter request]

Das liegt daran, dass der Brief im Prozess der Versendung sein könnte. Falls dies korrigiert werden muss, muss die teilnehmende Person
      einen Admin der Plattform kontaktieren.

=== 2. Prüfung durch den Admin

Im Verwaltungspanel kann der Admin die Anfrage prüfen, indem er im Abschnitt "Teilnehmende" zu "Code per Post" geht.

image::participants/authorizations_code_postal_letter_ongoing.png[Code by postal letter ongoing panel in administration]

Hier kann er den Verifizierungscode einsehen und ihn der teilnehmenden Person per Post zusenden. Nachdem der Code versendet wurde, kann er dies mit dem Symbol
      image:icons/action_verify.png[Als versendet markieren] entsprechend markieren. Es wird auch angezeigt, wann der Brief gesendet wurde.

=== 3. Teilnehmende Person bestätigt den Code

Nachdem die teilnehmende Person den Code erhalten hat, kann sie zu ihren Kontoeinstellungen gehen und auf die Verifizierungsmethode
      "Code per Post" klicken.

image::participants/authorizations_code_postal_letter_verify.png[Code by postal letter ongoing in the participant account]

Anschliessend kann sie das Formular mit dem erhaltenen Code ausfüllen.

image::participants/authorizations_code_postal_letter_confirm.png[Code by postal letter confirmation form]

=== 4. Code stimmt überein

Wenn der Verifizierungscode übereinstimmt, sieht die teilnehmende Person die Meldung "Herzlichen Glückwunsch. Sie wurden erfolgreich verifiziert."

Stimmt der Verifizierungscode hingegen nicht überein, sieht die teilnehmende Person eine Fehlermeldung, die sie auffordert, den Code im
      Brief noch einmal zu überprüfen.

Nachdem eine teilnehmende Person verifiziert wurde, kann sie dies, wie bei anderen Verifizierungen, in ihren Kontoeinstellungen sehen.

image::participants/authorizations_code_postal_letter_verified.png[Verified by code by postal letter]
