= Benutzergruppen

== Understand the basics

Benutzergruppen sind Einheiten, die von Teilnehmenden erstellt werden, um eine Struktur, einen Verein, eine Vereinigung usw. zu repräsentieren.
Benutzergruppen können von mehreren Admins verwaltet werden und mehrere Mitglieder haben.
Wenn ein Admin eine Benutzergruppe verifiziert, können alle Admins der Benutzergruppe im Namen der Gruppe teilnehmen.

image::participants/user_group_frontend_show.png[Frontend: show a user group]

== Konfiguration

=== Benutzergruppen aktivieren/deaktivieren

Admins können Benutzergruppen im Panel xref:admin:settings/configuration.adoc[Konfiguration] aktivieren oder deaktivieren.

Wenn aktiviert, können Teilnehmende Gruppen über ihr Profil erstellen und verwalten.
Um mehr darüber zu erfahren, wie Teilnehmende dies tun können, siehe den Artikel xref:admin:features/participant_actions/my_public_profile.adoc[Öffentliches Profil].

=== Benutzergruppen verwalten

Wenn eine teilnehmende Person eine Benutzergruppe erstellt, wird in der Liste der Benutzergruppen im Verwaltungspanel eine Zeile hinzugefügt mit:

* *Name*: Name der Benutzergruppe.
* *Spitzname*: Spitzname der Benutzergruppe.
* *Dokumentennummer*: kann die Identifikationsnummer der Struktur sein, wie z. B. die Identifikationsnummer eines Unternehmens oder Vereins.
* *Telefon*: Telefonnummer der Struktur oder des Admins der Benutzergruppe.
* *Anzahl Teilnehmende*: Anzahl der Mitglieder der Benutzergruppe.
* *Erstellt am*: Erstellungsdatum der Benutzergruppe.
* *Status*: Status der Verifizierung, kann nur ausstehend, verifiziert oder abgelehnt sein.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Benutzergruppen anhand ihrer E-Mail-Adresse, ihres Namens oder Spitznamens suchen.

image::participants/admin_user_group_verification.png[Admin panel: user group verifications]

Eine Benutzergruppe kann drei Status haben:

* Ausstehend: wartet auf eine Antwort eines Admins
* Verifiziert: ein Admin hat die Echtheit dieser Gruppe verifiziert
* Abgelehnt: ein Admin hat entschieden, dass diese Gruppe nicht authentisch oder nicht regelkonform ist

=== Eine Gruppe verifizieren

Um eine Gruppe zu verifizieren, sollte ein Admin überprüfen, dass die Gruppe existiert und berechtigt ist, eine Einheit auf der Plattform zu haben.
Der Admin kann den Admin der Gruppe unter der angegebenen Telefonnummer anrufen oder überprüfen, ob die Dokumentennummer existiert.

Nachdem eine Gruppe verifiziert wurde, ist dies öffentlich an ihrem Spitznamen auf der Plattform sichtbar, und in ihrem Profil erscheint eine Nachricht:
"Diese Gruppe ist öffentlich verifiziert, ihr Name wurde als mit ihrem echten Namen übereinstimmend bestätigt."

image::participants/user_group_verified.png[User group: verified icon]

=== Per CSV verifizieren

Wenn Sie mehrere Benutzergruppen gleichzeitig verifizieren möchten, können Sie dies über die Schaltfläche "Per CSV verifizieren" tun.

image::participants/admin_user_group_verification_csv.png[Admin panel: user group verifications CSV]

Dort können Sie eine CSV-Datei mit einer einzigen Spalte ohne Kopfzeile hochladen, die die E-Mail-Adressen der Benutzergruppen enthält, die Sie verifizieren möchten.
Nur Gruppen, die ihre E-Mail-Adresse bestätigt haben und deren E-Mail-Adresse in der CSV-Datei enthalten ist, werden verifiziert.
