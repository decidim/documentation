= Administratoren

== Understand the basics

Admins sind die Personen, die die Organisation verwalten, die Prozesse erstellen und die Plattform als Ganzes verwalten.
      Es gibt zwei Arten:

* Admins: haben Zugriff auf die gesamte Plattformkonfiguration.
* Teilnehmendenverwaltende: können nur xref:admin:participants/impersonations.adoc[Identitätsübernahmen] von Teilnehmenden verwalten.

image:participants/admins.png[Admin-Liste]

== Konfiguration

=== Einen Admin einladen

Um einen Admin einzuladen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neuer Admin".
Sie können einen bereits registrierten oder nicht registrierten Teilnehmer einladen.

image:participants/admins_invite.png[Formular zum Einladen einer teilnehmenden Person als Admin]

.Formular für neuen Admin
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Name des Admins. Falls die Person bereits ein Konto hat, wird es automatisch für ihren Benutzernamen geändert.

|E-Mail
|Benötigt
|E-Mail-Adresse der einzuladenden teilnehmenden Person. Falls sie kein Konto haben, das mit dieser E-Mail-Adresse verknüpft ist, sollten sie eine Einladungs-
      E-Mail zur Kontoerstellung erhalten. Andernfalls werden sie nicht benachrichtigt.

|Rolle
|Benötigt
|Admin oder Teilnehmendenverwaltende
|===

Wenn ein Admin noch kein Konto hat, sich aber nicht registriert hat, können Sie die Einladung auch erneut senden.

=== Admins verwalten

Sie finden alle Admins in der Admin-Liste im Verwaltungspanel mit:

* *Rolle*: Art der Admin-Rechte, kann nur Admin oder Teilnehmendenverwaltende sein.
* *Name*: Name der teilnehmenden Person.
* *E-Mail*: E-Mail-Adresse der teilnehmenden Person.
* *Einladung versendet am*: Datum und Uhrzeit der Einladungs-E-Mail.
* *Einladung akzeptiert am*: wann sie die Einladungs-E-Mail akzeptiert haben.
* *Letztes Anmeldedatum*: Datum der letzten Anmeldung des Admins.
* *Erstellungsdatum*: Erstellungsdatum des Kontos der teilnehmenden Person.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Admins anhand ihrer E-Mail-Adresse, ihres Namens oder Spitznamens suchen.

=== Admin-Berechtigungen widerrufen

Wenn ein Admin keinen Zugriff mehr benötigt, sollten Sie seine Rechte widerrufen, indem Sie auf die Schaltfläche "Löschen" klicken.
Sie müssen die Löschung der Rechte bestätigen, um diese vollständig zu entfernen.
Das Widerrufen der Admin-Berechtigungen löscht das Konto der teilnehmenden Person nicht.
