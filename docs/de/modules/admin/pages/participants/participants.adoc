= Teilnehmende

== Die Grundlagen verstehen

Teilnehmende sind alle Personen mit einem Konto auf der Plattform, unabhängig davon, ob sie ihre E-Mail-Adresse bestätigt haben oder nicht.
Auf dieser Seite kann ein Admin:

* Teilnehmende blockieren, zum Beispiel weil sie spammen oder gegen die Nutzungsbedingungen verstossen
* Eine teilnehmende Person über private Decidim-Nachrichten kontaktieren
* Teilnehmende offizialisieren
* Die E-Mail-Adresse einer teilnehmenden Person anzeigen

image:participants/participants_participants.png[Teilnehmendenliste]

== Konfiguration

=== Teilnehmende verwalten

Hier finden Sie alle Teilnehmenden, mit:

* *Name*: Name der teilnehmenden Person, mit einem Link zu ihrem Profil.
* *Spitzname*: Spitzname der teilnehmenden Person, mit einem Link zu ihrem Profil.
* *Erstellt am*: Datum der Kontoerstellung der teilnehmenden Person.
* *Status*: ob die teilnehmende Person offizialisiert ist oder nicht.
* *Abzeichen*: das Offizialisierungsabzeichen, das bei der Offizialisierung der teilnehmenden Person vergeben wird.
* *Meldungen*: Anzahl der Meldungen durch verschiedene Nutzende.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Teilnehmenden anhand ihrer E-Mail-Adresse, ihres Namens oder Spitznamens suchen.

=== E-Mail-Adresse anzeigen

Manchmal müssen Admins die E-Mail-Adresse einer nutzenden Person finden. Dazu können sie auf die Option "E-Mail-Adresse anzeigen" klicken.
Es erscheint ein modales Fenster mit dem Namen der teilnehmenden Person und einem ausgeblendeten Feld.

image:participants/participants_show_email.png[Modales Fenster bei E-Mail-Anzeige]

Um die E-Mail-Adresse anzuzeigen, müssen Sie auf die Schaltfläche "Anzeigen" klicken.

image:participants/participants_showed_email.png[Modales Fenster nach Anzeige der E-Mail]

Aus Gründen der Transparenz der Verwaltung wird diese Aktion in den Aktivitätsprotokollen erfasst.

image:participants/participants_showed_email_admin_log.png[Admin-Aktivitätsprotokoll für E-Mail-Anzeige]

=== Kontakt

Um Teilnehmende direkt über die private Nachrichtenfunktion der Plattform zu kontaktieren, klicken Sie auf das Symbol "Kontaktieren".

image::participants/participants_conversation.png[Conversation with a participant]

=== Offizialisieren

Diese Option ist nützlich, um anzuerkennen, dass eine teilnehmende Person einen bestimmten Status auf der
Plattform hat. Zum Beispiel, wenn jemand Bürgermeister:in einer Stadt, Gemeinderät:in oder
Präsident:in eines Vereins ist usw.

image:participants/participants_officialize.png[Eine teilnehmende Person offizialisieren]
