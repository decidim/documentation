= Teilnehmer

Auf dieser Seite kann ein Administrator:

* Teilnehmer blockieren, zum Beispiel, weil sie gegen die Nutzungsbedingungen spammen oder handeln
* Kontaktieren Sie einen Teilnehmer mit Decidim privaten Nachrichten (Unterhaltungen)
* Offizialisiere einen Teilnehmer
* E-Mail ansehen

=== Benutzer sperren

Nachdem Sie auf diese Option klicken, müssen Sie eine Begründung angeben, warum Sie
diesen Teilnehmer blockieren:

image:participants_block_user_justification.png[Blockierte Benutzeraktion]

Sobald ein blockierter Teilnehmer versucht, sich anzumelden, wird eine Fehlermeldung angezeigt:

image:participants_block_user_alert.png[Nachricht für blockierten Benutzer]

Nachdem ein Teilnehmer gesperrt wurde, wird sein Name in "Blockierter Benutzer" geändert.

Siehe mehr unter xref:admin:participants/reported_users.adoc[Gemeldete Benutzer]

=== E-Mail-Adresse anzeigen

Nachdem Sie auf diese Option geklickt haben, wird der Administrator einen Modus sehen. They will have to click in
button "Show email address".

image:participants_show_email.png[Modal in show email]
image:participants_showed_email.png[Modal, nachdem die E-Mail angezeigt wird]

Diese Aktion wird im Admin Acvity Log eingeloggt.

image:participants_showed_email_admin_log.png[Admin Aktivitätsprotokoll für Serien-E-Mail]

=== Kontakt

By clicking on this option, it will open the private messaging (Conversation) for
this participant.

image:participants_conversation.png[Konversation mit einem Teilnehmer].

=== Offiziell

Diese Option ist nützlich, um zu erkennen, dass ein Teilnehmer einen besonderen Status in der
-Plattform hat. Zum Beispiel, wenn jemand der Bürgermeister der Stadt ist, ein Stadtrat oder der
Präsident einer Vereinigung in einem Organisationskontext.

Nach der Offizialisierung eines Teilnehmers können Sie:

- Ändere den offiziellen Text mit "Reofficialize"
- Den offiziellen Status mit "Unoffizialisierung" widerrufen
