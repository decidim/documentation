= Identitätsübernahme von Teilnehmenden

== Die Grundlagen verstehen

Manchmal haben Personen nicht die Zeit, ein Konto zu erstellen, oder verfügen nicht über die Kenntnisse oder Fähigkeiten, um technologische Werkzeuge zu nutzen.
Die Identitätsübernahme ermöglicht es Admins und Teilnehmendenverwaltenden, diesen Personen trotzdem eine Teilnahme zu ermöglichen.

NOTE: Im Code und in der Benutzeroberfläche sind *Identitätsübernahme* und *Verwaltete Teilnehmende* dasselbe.

== Konfiguration

=== Identitätsübernahme aktivieren/deaktivieren

Die Identitätsübernahme ist nur verfügbar, wenn mindestens eine Berechtigung für die Organisation aktiviert ist.
Sie ermöglichen es dem System nämlich, über ein Verifizierungssystem nach einer bereits bestehenden teilnehmenden Person zu suchen und
eine teilnehmende Person ohne die Notwendigkeit einer E-Mail-Adresse zu erstellen.

Um eine Berechtigung zu aktivieren, benötigen Sie Zugriff auf das xref:configure:system.adoc[Systempanel] oder müssen die für Ihre Instanz zuständige entwickelnde Person fragen.

image::participants/participants_impersonations_backend_list_no_auth.png[Administrators Impersonations panel with no authorizations]

Die verschiedenen Berechtigungen bieten unterschiedliche Möglichkeiten:

* Nur Protokolle der Identitätsübernahme einsehen: Wenn Identitätsdokumente, Code per Post und/oder Zählung der Organisation aktiviert sind
* Identität von bestehenden und neuen Nutzenden annehmen: Direkte Verifizierung aktiviert, wie Beispiel-Berechtigung oder andere benutzerdefinierte direkte Berechtigungen.

NOTE: Weitere Informationen dazu, wie Sie Ihre Formularberechtigung programmieren können, finden Sie in der
https://github.com/decidim/decidim/blob/develop/decidim-verifications/README.md[Decidim-verification README].

=== Identitätsübernahmen verwalten

Sie finden alle Teilnehmenden der Plattform mit:

* *Name*: Name der teilnehmenden Person.
* *Status*: ob bei der teilnehmenden Person die Identität übernommen wurde/sie verwaltet wird oder nicht.

Sie können diese Liste filtern, indem Sie auf die Schaltfläche "Filter" klicken, und nach Teilnehmenden anhand ihres Namens suchen.

=== Die Identität einer teilnehmenden Person annehmen

Klicken Sie auf die Schaltfläche "Neue teilnehmende Person verwalten". Anschliessend können Sie die persönlichen Daten eingeben, die mit der Verifizierung abgeglichen werden:

image::participants/participants_impersonations_form.png[Administrators Impersonations form]

Nachdem diese Daten vom System überprüft wurden, wird für die teilnehmende Person eine Sitzung für 30 Minuten geöffnet.
Ein Banner oben auf der Seite erinnert den Admin daran, dass er gerade die Identität der teilnehmenden Person angenommen hat, sowie an die verbleibende Zeit.

image::participants/participants_impersonations_user.png[Impersonated user session]

=== Eine verwaltete teilnehmende Person hochstufen

Admins können verwaltete Teilnehmende hochstufen, um sie einzuladen, ein Konto auf der Plattform zu erstellen.
Klicken Sie auf das Symbol "Hochstufen", um der teilnehmenden Person eine E-Mail-Adresse hinzufügen und sie per E-Mail einladen zu können.
