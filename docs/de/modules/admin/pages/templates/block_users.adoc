= Vorlagen für Blockierungsnachrichten

== Die Grundlagen verstehen

In diesem Abschnitt können Sie Vorlagen für Blockierungsbegründungen erstellen, bearbeiten und löschen, die Sie anschliessend bei der Moderation von Teilnehmenden verwenden können.

== Konfiguration

=== Eine Vorlage für Blockierungsnachrichten erstellen

Um eine neue Vorlage für Blockierungsnachrichten zu erstellen, müssen Sie auf die Schaltfläche "Neue Vorlage" klicken.

image::templates/templates_block_user_backend_form.png[Backend: new template form]

.Formular für neue Vorlage für Blockierungsnachrichten
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Titel dieser Vorlage. Wählen Sie einen klaren Titel, der genau beschreibt, wofür die Nachricht dient, wie zum Beispiel "Spam-Nutzende."

|Beschreibung
|Benötigt
|Blockierungsnachricht, die zur Begründung der Blockierung der teilnehmenden Person verwendet wird.
|===

=== Verwalten

Alle Vorlagen für Blockierungsnachrichten erscheinen in der Vorlagenliste:

* *Vorlage*: Name der Vorlage.
* *Erstellt am*: Erstellungsdatum.

Sie können eine Vorlage jederzeit bearbeiten.

=== Aktionen

.Aktionen
[cols="10h,20h,~"]
|===
|Icon |Name |Definition

|image:icons/action_edit.png[Symbol: Vorlage bearbeiten]
|Bearbeiten
|Um die Blockierungsnachricht zu bearbeiten.

|image:icons/action_duplicate.png[Symbol: Vorlage duplizieren]
|Duplicate
|Um die Vorlage zu duplizieren.

|image:icons/action_delete.png[Symbol: Vorlage löschen]
|Löschen
|Um die Vorlage zu löschen.
|===

=== Die Vorlage verwenden

Um die Vorlage zu verwenden, gehen Sie zum Panel xref:admin:moderations/reported_users.adoc[Gemeldete Teilnehmende] und klicken Sie auf ein Symbol "Nutzende blockieren".
Anschliessend sehen Sie eine Seite, die Ihnen vorschlägt, eine Vorlage für die Begründung der Blockierung dieser teilnehmenden Person auszuwählen.
