= Vorlagen für Vorschlagsantworten

== Die Grundlagen verstehen

In diesem Abschnitt können Sie Vorlagen für Vorschlagsantworten erstellen, bearbeiten und löschen, die Sie anschliessend beim Beantworten von Vorschlägen verwenden können.

== Konfiguration

=== Eine Vorlage für Vorschlagsantworten erstellen

NOTE: Um eine Vorlage für Vorschlagsantworten erstellen zu können, müssen Sie mindestens eine
      xref:admin:components/proposals.adoc[Vorschläge]-Komponente erstellt haben.

Um eine neue Vorlage für Vorschlagsantworten zu erstellen, müssen Sie auf die Schaltfläche "Neue Vorlage" klicken.

image::templates/templates_proposal_answers_choice_component.png[Backend: Proposal component choice for template]

Wählen Sie den partizipativen Raum und die Komponente, für die Sie Vorschlagsantworten erstellen möchten, um das Antwortvorlagenformular zu sehen.

image::templates/templates_proposal_answers_backend_form.png[Backend: new proposal answer template form]

.Formular für neue Vorlage für Vorschlagsantworten
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Titel dieser Antwortvorlage. Wählen Sie einen klaren Titel, der genau beschreibt, wofür die Antwort dient.

|Beschreibung
|Benötigt
|Inhalt der Antwort, die den Vorschlägen gegeben wird, für die Sie diese Vorlage auswählen. Sie können Variablen in Ihrer Antwort verwenden.

|Vorschlagsstatus
|Benötigt
|Standardmässig können Sie zwischen In Bewertung, Akzeptiert oder Abgelehnt wählen.
|===

=== Verwalten

Alle Vorlagen erscheinen in der Liste der Vorlagen für Vorschlagsantworten:

* *Vorlage*: Name der Vorlage für Vorschlagsantworten.
* *Interner Status*: Status, der Vorschlägen bei Verwendung dieser Vorlage zugewiesen wird.
* *Einschränkung hinzufügen*: Vorschläge-Komponente, in der Sie diese Vorlage verwenden können.
* *Erstellt am*: Erstellungsdatum.

Sie können eine Vorlage und ihre Felder jederzeit bearbeiten.

=== Die Vorlage verwenden

Um die Vorlage zu verwenden, gehen Sie zu einer der Vorschläge-Komponenten, für die Sie eine Vorlage für Vorschlagsantworten erstellt haben, und klicken Sie auf ein Symbol "Antworten".
Sie können eine Antwortvorlage auswählen, um das Antwortfeld auszufüllen.
