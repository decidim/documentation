= Fragebogenvorlagen

== Die Grundlagen verstehen

In diesem Abschnitt können Sie Fragebogenvorlagen erstellen, bearbeiten und löschen, die Sie anschliessend in jeder Umfrage-Komponente verwenden können.

== Konfiguration

=== Eine Fragebogenvorlage erstellen

Um eine neue Fragebogenvorlage zu erstellen, müssen Sie auf die Schaltfläche "Neue Vorlage" klicken.

image::templates/templates_questionnaires_backend_form.png[Backend: new template form]

.Formular für neue Vorlage für Blockierungsnachrichten
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Titel dieser Vorlage. Wählen Sie einen klaren Titel, der genau beschreibt, wofür die Umfrage dient, wie zum Beispiel "Feedback-Umfrage."

|Beschreibung
|Benötigt
|Beschreibung, wofür die Vorlage gedacht ist. Diese Beschreibung ist nur im Vorlagenpanel verfügbar, um genau zu beschreiben, wofür
      die Umfrage dient.
|===

Klicken Sie auf die Schaltfläche "Speichern", um mit der Erstellung Ihrer Vorlage für den Fragebogen fortzufahren.

image::templates/templates_questionnaires_backend_survey_form.png[Backend: new survey template form]

Klicken Sie anschliessend auf die Schaltfläche "Bearbeiten". Sie gelangen in den Prozess zur Umfrageerstellung. Klicken Sie auf die Schaltfläche "Überspringen", wenn Sie keine bestehende Vorlage verwenden möchten.

Auf der nächsten Seite können Sie eine Umfrage erstellen. Weitere Informationen finden Sie in der Dokumentation zu xref:admin:components/surveys.adoc[Umfragen].

Klicken Sie auf die Schaltfläche "Speichern", um eine Vorschau Ihrer Umfrage zu sehen.

image::templates/templates_questionnaires_backend_survey_preview.png[Backend: new survey template preview]

Klicken Sie erneut auf die Schaltfläche "Speichern", um Ihre Vorlage zu speichern.

=== Vorlagen verwalten

Alle Vorlagen erscheinen in der Liste der Fragebogenvorlagen:

* *Vorlage*: Name der Vorlage.
* *Fragebogentitel*: Standardname der Umfrage bei Auswahl dieser Vorlage.
* *Anzahl Fragen*: Anzahl der verschiedenen Fragen in der Umfrage.
* *Erstellt am*: Erstellungsdatum.

Sie können eine Vorlage und ihre Fragen jederzeit bearbeiten. Bitte beachten Sie ausserdem, dass Sie beim Erstellen einer Umfrage mit einer Vorlage
      die Fragen für diese spezifische Komponente auch ändern, hinzufügen oder löschen können.

=== Die Vorlage verwenden

Um die Vorlage zu verwenden, erstellen Sie eine xref:admin:components/surveys.adoc[Umfrage]-Komponente in einem partizipativen Raum und bearbeiten Sie sie anschliessend.
Anschliessend sehen Sie eine Seite, die Ihnen vorschlägt, eine Vorlage für diese Umfrage auszuwählen.
