= Seiten und Themen

== Die Grundlagen verstehen

Auf der Registerkarte Seiten können Sie statische Seiten veröffentlichen, zum Beispiel die Nutzungsbedingungen Ihrer Plattform, Erklärungen zur Barrierefreiheit, FAQs usw.
Sie können diese Seiten in verschiedenen Themen organisieren, die wie eine Art Ordner fungieren.

NOTE: Sie suchen, wie Sie Themen und Seiten erstellen können? Siehe xref:pages/pages.adoc[Seiten] und xref:pages/topics.adoc[Themen].

Diese Seiten stehen allen Teilnehmenden über den Abschnitt **Hilfe** in der Kopf- und Fusszeile zur Verfügung.

== Konfiguration

Um auf das Konfigurationspanel für Seiten zuzugreifen, gehen Sie zum Verwaltungspanel und klicken Sie in der Verwaltungsnavigationsleiste auf den Punkt "Seiten".

image::pages/pages_menu.png[Pages: Access pages panel]

Dort können Sie xref:admin:pages/pages.adoc[Seiten] und xref:admin:pages/topics.adoc[Themen] erstellen, aktualisieren oder löschen.
Sie können zunächst nur Seiten erstellen, wenn Sie möchten, da Sie jederzeit Themen erstellen und Seiten darin neu anordnen können.

image::pages/pages_backend_list.png[Backend: list pages]
