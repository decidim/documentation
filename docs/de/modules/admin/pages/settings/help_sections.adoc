= Hilfe-Abschnitte

== Die Grundlagen verstehen

Auf jeder Übersichtsseite und Landingpage eines partizipativen Raums sehen Sie eine Schaltfläche "Hilfe" am rechten Seitenrand.

image::settings/help_sections_frontend_hide.png[Help sections: hide]

Durch Klicken darauf können Besuchende oder Teilnehmende eine Popup-Nachricht sehen, die erklärt, worum es in dem partizipativen Raum geht.

image::settings/help_sections_frontend.png[Help sections: frontend]

Admins können diese *Hilfeabschnitte* anpassen, um sie an die Besonderheiten der Instanz anzupassen.

image::settings/help_sections_backend.png[Help sections: backend]

== Konfiguration

=== Deaktivieren

Sie können diese Informationsboxen ausblenden, indem Sie die Inhalte für alle Sprachen leer lassen.

image::settings/help_sections_disable_backend.png[Disable help section in administration]
