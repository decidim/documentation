= Bereiche

include::partial$deprecated.adoc[]

Bereiche sind alle Sektoren, die eine Organisation haben kann.

Bereiche sind den xref:admin:settings/scopes.adoc[Themen] recht ähnlich, das heisst, sie ermöglichen eine
bessere Navigation und Filterung in den Räumen und Komponenten.

Weitere Informationen zur Geschichte der Bereiche finden Sie in
diesem https://github.com/decidim/decidim/issues/3540#issuecomment-427324532[GitHub-Kommentar].
