= Konfiguration

== Understand the basics

Auf dieser Seite können Sie allgemeine Einstellungen von Decidim konfigurieren, wie den Namen der Instanz, die Willkommensbenachrichtigung, die
allgemeinen Funktionen, die verfügbaren Sprachen usw.

== Konfiguration

=== Organisation bearbeiten

image::settings/admin_configuration.png[Decidim Admin Configuration]

[cols="20h,10h,~,~"]
|===
|Feld |Typ |Beschreibung |Sichtbarkeit

|Name
|Benötigt
|Der Name der Plattform.
|Sichtbar im Plattformtitel, in E-Mails, Benachrichtigungen usw.

|Soziale
|Benötigt
|Soziale Handler für verschiedene soziale Netzwerke. Fügen Sie im Feld nur den benötigten Slug hinzu, nicht die gesamte URL.
|Sichtbar in der Fusszeile auf jeder Seite.

|Standardgebietsschema
|Benötigt
|Standardsprache der Plattform. Wenn Sie weitere Sprachen aktivieren möchten, wenden Sie sich an Ihren technischen Administrator.
|Bei mehreren Sprachen können Teilnehmende ihre bevorzugte Sprache in ihren Kontoeinstellungen auswählen.

|Zeitzone
|Benötigt
|In welcher Zeitzone ist Ihre Organisation.
|Wird an mehreren Stellen verwendet, z. B. im Veranstaltungskalender.

|Referenzpräfix
|Benötigt
|Referenzpräfix, das verwendet wird, um alle Ressourcen der Instanz öffentlich zu identifizieren.
|Sichtbar auf jeder Ressourcenseite, wie einer Versammlung, einer Veranstaltung, einem Vorschlag usw.

|Abzeichen aktivieren
|Checkbox
|Ob Ihre Teilnehmenden bei der Teilnahme Abzeichen als Gamification-Mechanismus erhalten sollen.
|Wenn aktiviert, sind Abzeichen in den Profilen der Teilnehmenden sichtbar, und die Teilnahme löst das Erreichen von Abzeichenstufen aus.

|Gruppen aktivieren
|Checkbox
|Ob Ihre Teilnehmenden die Möglichkeit haben sollen, xref:participants/groups.adoc[Benutzergruppen] zu erstellen.
|Wenn aktiviert, sind Gruppen in den Profilen und Konten der Teilnehmenden sichtbar, und diese können Benutzergruppen erstellen.

|Filter für partizipative Räume aktivieren
|Checkbox
|Ob Sie Filter auf den Übersichtsseiten der partizipativen Räume anzeigen möchten.
|Wenn aktiviert, können Teilnehmende Räume, wie Versammlungen, anhand verschiedener Filter auf der Raumübersicht filtern.

|Maximale Länge der Kommentare
|Benötigt
|Ob Sie die Anzahl der Zeichen in Kommentaren begrenzen möchten. Lassen Sie 0 für den Standardwert (1000).
|Das Limit ist sichtbar, wenn Sie Kommentare in einer partizipativen Komponente aktivieren.

|Rich-Text-Editor für Teilnehmende aktivieren
|Checkbox
|Ob Sie Teilnehmenden einen https://en.wikipedia.org/wiki/WYSIWYG[WYSIWYG-Editor] zur Verfügung stellen möchten.
|In einigen Textfeldern, wie der Vorschlagserstellung, können Teilnehmende mithilfe des Rich-Text-Editors bestimmte HTML-Tags einfügen.

|Willkommensbenachrichtigung senden
|Checkbox
|Ob Teilnehmende eine Benachrichtigung erhalten sollen, wenn sie zum ersten Mal ihr Konto erstellen.
|Wenn Sie nur dies aktivieren, erhalten Teilnehmende die Standardbenachrichtigung.

|Willkommensbenachrichtigung anpassen
|Checkbox
|Ermöglicht es Ihnen, die Benachrichtigung anzupassen, die an Teilnehmende gesendet wird, wenn sie ein Konto erstellen.
|Wenn aktiviert, können Sie die Willkommensbenachrichtigung in den untenstehenden Feldern anpassen.

|Betreff der Willkommensbenachrichtigung
|Benötigt
|Ermöglicht es Ihnen, den Betreff der Willkommensbenachrichtigung anzupassen. Sie können Variablen wie {{name}} oder {{organization}} hinzufügen.
|Feld sichtbar, wenn Sie das Kontrollkästchen "Willkommensbenachrichtigung anpassen" aktivieren.

|Text der Willkommensbenachrichtigung
|Benötigt
|Ermöglicht es Ihnen, den Text der Willkommensbenachrichtigung anzupassen. Sie können Variablen wie {{name}} oder {{organization}} hinzufügen.
|Feld sichtbar, wenn Sie das Kontrollkästchen "Willkommensbenachrichtigung anpassen" aktivieren.

|Text für die Nutzungsbedingungen für Admins
|Benötigt
|Welche Meldung ein Admin beim erstmaligen Zugriff auf das Verwaltungspanel sieht.
|Meldung, die angezeigt wird, wenn ein Admin zum ersten Mal auf das Verwaltungspanel zugreift.
|===

== Beispiele

=== Soziale Netzwerke

Wenn Sie für jedes soziale Netzwerk einen Wert eingeben, werden deren Symbole in der Fusszeile mit einem Link zu Ihrer Kontoseite angezeigt.
Überprüfen Sie, ob alle Links einwandfrei funktionieren.

image::settings/settings_configuration_social.png[Social networks configuration in Decidim]

=== Willkommensbenachrichtigung

Teilnehmende erhalten eine Willkommensbenachrichtigung, wenn sie die Erstellung ihres Kontos abschliessen, in ihrem Benachrichtigungspanel und per E-Mail.

image::settings/settings_configuration_welcome.png[Welcome notification configuration in Decidim]
