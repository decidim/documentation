= Erlaubte externe Domains

== Die Grundlagen verstehen

Als Mittel zum Schutz vor Spam und zur Erhöhung der Sicherheit Ihrer Instanz kann Decidim Links erkennen, die
auf eine externe Webseite führen, und zeigt nach dem Klicken das folgende Warn-Pop-up an:

image::settings/allowed_external_domains_pop-up.png[Pop-up that appears when clicking any external domains on Decidim]

Es warnt Teilnehmende davor, dass sie Ihre Instanz verlassen.

== Konfiguration

=== Eine externe Domain erlauben

Es kann Weiterleitungen zu Websites geben, für die Sie diese Funktion nicht aktiviert haben möchten.
Wenn Ihre Website beispielsweise unter einer URL wie `+decidim.example.org+` bereitgestellt wird und Sie möchten, dass für alle `+example.org+`-URLs
diese Warnmeldung nicht angezeigt wird, können Sie dies konfigurieren, indem Sie Ihre URL – und so viele weitere wie gewünscht – auf der Seite Erlaubte externe Domains hinzufügen.

Um dies zu tun, klicken Sie auf die Schaltfläche "Zur erlaubten Liste hinzufügen" und geben Sie die URL der Website ein, die Sie autorisieren möchten.

image::settings/allowed_external_domains_admin_panel.png[Allowed external domains panel]

Wenn Teilnehmende auf eine URL zu diesen Domains klicken, sehen sie die Warnmeldung nicht.
