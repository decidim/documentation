= Aussehen

== Die Grundlagen verstehen

Auf dieser Seite können Sie das Look-and-Feel Ihrer Decidim-Instanz konfigurieren.

NOTE: Bitte beachten Sie, dass dies mit einigen Änderungen, die Ihre Entwickler:innen an Ihrer allgemeinen Installation vorgenommen haben könnten, nicht kompatibel sein kann.
Wenn beispielsweise Änderungen an den xref:customize:styles.adoc[Styles] vorgenommen wurden, könnten einige Parameter nicht wie erwartet angewendet werden.

== Konfiguration

=== Erscheinungsbild der Startseite bearbeiten

Dieser Abschnitt ermöglicht es, eine allgemeine Beschreibung der Instanz anzugeben und eine Handlungsaufforderungs-Schaltfläche zu konfigurieren, die
Teilnehmenden auf der Startseite angezeigt werden kann, um sie zu einem bestimmten Prozess zu führen, z. B. zu einer Vorschlagskomponente, an der sie teilnehmen können.

image::settings/admin_appearance_homepage_appearance.png[Decidim Admin Appearance edit homepage appearance toggle]

.Umschaltformular für das Erscheinungsbild der Startseite bearbeiten
[cols="20h,10h,~,~"]
|===
|Feld |Typ |Beschreibung |Sichtbarkeit

|Beschreibung
|Optional
|Die Beschreibung dieser Instanz, die für Meta-Tags für Google- und Twitter-Einbettungen verwendet wird.
|Sichtbar in der Fusszeile und im Inhaltsblock "Banner unter dem Hauptbild" auf der Startseite, sofern dieser Block aktiviert ist.

|Pfad der Handlungsaufforderungs-Schaltfläche
|Optional
|Pfad zu der Stelle auf der Plattform, zu der Sie Teilnehmende schnell weiterleiten möchten.
|Sichtbar im Inhaltsblock "Banner-Bild und Handlungsaufforderung" auf der Startseite, sofern dieser Block aktiviert ist.

|Text zum Aktion-Button aufrufen
|Optional
|Der auf der Handlungsaufforderungs-Schaltfläche angezeigte Text.
|Sichtbar im Inhaltsblock "Banner-Bild und Handlungsaufforderung" auf der Startseite, sofern dieser Block aktiviert ist.
|===

NOTE: Um zu verstehen, wie Sie die verschiedenen Inhaltsblöcke der Startseite aktivieren können, lesen Sie den Artikel xref:admin:settings/homepage.adoc[Startseite].

=== Hervorgehobener Inhalts-Banner

Dieser Abschnitt ermöglicht es, ein Banner mit Beschreibung und Handlungsaufforderungs-Schaltfläche zu aktivieren, zum Beispiel um einen bestimmten Raum
auf Ihrer Instanz hervorzuheben, Nutzende zur Kontoerstellung zu ermutigen oder sie zur Anmeldung für eine Veranstaltung aufzufordern. Sie können es je nach
aktuellem Geschehen Ihrer Instanz anpassen und deaktivieren, wenn es nicht benötigt wird.

NOTE: Damit es auf der Startseite erscheint, muss der Inhaltsblock "Hervorgehobenes Inhaltsbanner" auf der xref:admin:settings/homepage.adoc[Startseite] aktiviert sein.

|Wenn aktiviert, erscheint das hervorgehobene Inhaltsbanner auf der Startseite, sofern der Inhaltsblock "Hervorgehobenes Inhaltsbanner" ebenfalls aktiviert ist.

|Benötigt
|Der Titel des Banners.

|Kurze Beschreibung

=== Allgegenwärtiges Banner bearbeiten

Dieser Abschnitt ermöglicht es, ein Banner oben auf Ihrer Instanz zu aktivieren, oberhalb der Kopfzeilen, das jederzeit auf jeder Seite sichtbar ist.
Es kann nützlich sein, um sehr wichtige Informationen anzuzeigen, die alle Teilnehmenden sehen müssen, wie die Ankündigung eines Wartungstermins,
die Verfügbarkeit von Prozessergebnissen, einen wichtigen Hinweis usw.

NOTE: Dieses Banner wird ausschliesslich auf dieser Seite konfiguriert und muss nicht im Abschnitt der Startseite aktiviert werden.

=== Organisationsfarben

Dieser Abschnitt ermöglicht es, Farben für die Organisation auszuwählen.

NOTE: Achten Sie auf mögliche Barrierefreiheitsprobleme, zum Beispiel bei Personen ohne ausgeprägtes Kontrastempfinden.
Sie können den Kontrast Ihrer Wahl mit dem WebAIM Contrast Checker oder ähnlichen Tools überprüfen.

image::settings/admin_appearance_colors.png[Decidim Admin layout appearance toggle]

Sie können konfigurieren:

* Primärfarbe: Wird für den Hintergrund des globalen Menüs, die Hintergründe der Komponentenmenüs usw. verwendet.
* Sekundärfarbe: Wird für Titel-Links, primäre Schaltflächen, die Schriftfarbe der Kopfzeile usw. verwendet.
* Tertiärfarbe: Wird für Titel-Unterstreichungen, die Rahmenfarbe von Karten usw. verwendet.

Im folgenden Screenshot werden die drei verschiedenen Farben angezeigt.

image::settings/appearance_colors.png[Decidim layout appearance colors example]

=== Header-Snippets

NOTE: Möglicherweise sehen Sie dieses Feld nicht. Weitere Informationen zur Aktivierung finden Sie in der Dokumentation zu xref:customize:styles.adoc[Styles].

Mit diesem Feld können Sie Code zum HTML-Head hinzufügen. Der häufigste Anwendungsfall ist die Einbindung von Drittanbieterdiensten, die
zusätzliches JavaScript oder CSS erfordern. Ausserdem können Sie damit zusätzliche Meta-Tags zum HTML hinzufügen.
Beachten Sie, dass dies nur auf öffentlichen Seiten dargestellt wird, nicht in der Administration.
