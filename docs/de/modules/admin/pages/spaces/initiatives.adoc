= Initiativen

== Die Grundlagen verstehen

Eine Initiative ist eine spezifische Art von partizipativem Raum, der von jeder teilnehmenden Person unabhängig
      von anderen Kanälen oder Räumen erstellt werden kann.
Sie funktioniert durch das Sammeln von Online- und/oder Vor-Ort-Unterschriften, damit die Organisation eine bestimmte Massnahme umsetzt, wie
      das Ändern einer Vorschrift, das Initiieren eines Projekts, das Ändern des Namens eines Departements oder einer Strasse usw.

Die Initiierenden einer Initiative können deren Ziele festlegen, Unterstützung sammeln, debattieren, sie verbreiten und Veranstaltungsorte
      festlegen, an denen Unterschriften von den Anwesenden gesammelt oder Debatten für andere Teilnehmende geöffnet werden können.

NOTE: Ein Grossteil des Verhaltens und der Einstellungen von Initiativen ist im
      xref:admin:initiatives_initializer.adoc[Initiative-Initializer] konfigurierbar. Wenden Sie sich an die für Ihre Organisation zuständige entwickelnde Person, falls Sie Zweifel bezüglich der Konfiguration
      Ihrer Organisation haben.

Beispiele für Initiativentypen:

* Um einen Punkt zur Traktandenliste einer Versammlung hinzuzufügen
* Einen Beteiligungsprozess durchführen
* Eine neue Versammlung erstellen
* Eine Verordnung genehmigen oder ändern
* Um zu Versammlungen aufzurufen

Initiativen unterscheiden sich von den anderen Räumen dadurch, dass sie als partizipatives Instrument genutzt werden können, das *von Teilnehmenden* vorangetrieben wird.
Mit anderen Worten sind Initiativen Mechanismen der *semidirekten Demokratie*, durch die Teilnehmende eine bestimmte
      Massnahme von gemeinsamem Interesse vorantreiben können, indem sie eine bestimmte Anzahl von Unterschriften sammeln.

Die Rolle des Admins der Plattform unterscheidet sich daher etwas von der in den anderen Beteiligungsräumen, da
      die Organisation die Teilnehmenden befähigen und ihnen die notwendige technische Unterstützung und Beratung anbieten muss.

=== Wie findet man sie?

Um auf das Initiativen-Panel zuzugreifen, gehen Sie zum Verwaltungspanel und klicken Sie in der Verwaltungs-
      Navigationsleiste auf den Punkt "Initiativen".

image::spaces/initiatives/initiatives_menu.png[Access Initiatives panel]

Dort können Sie mit der Konfiguration des Initiativenraums beginnen, indem Sie:

. xref:admin:spaces/initiatives/types.adoc[Initiativentypen] und Initiativentyp-Themen erstellen
. Bei Bedarf Berechtigungen konfigurieren
. Initiativen von Teilnehmenden verwalten

image::spaces/initiatives/initiatives_list_empty.png[Initiatives panel without initiatives]

NOTE: Zu Beginn ist die Liste leer, und Teilnehmende können keine Initiativen erstellen.
Um die anfängliche Einrichtung des Initiativenraums vorzunehmen, lesen Sie den Artikel xref:admin:spaces/initiatives/types.adoc[Initiativentypen].

=== Lebenszyklus von Initiativen

Initiativen durchlaufen verschiedene Schritte und folgen einem bestimmten Lebenszyklus:

* *Erstellt*: Die Urheberschaft hat die Initiative erstellt, sie ist nur für die Urheberschaft, Mitglieder des Initiativkomitees und Admins sichtbar.
* *Technische Validierung*: Die Initiative ist bereit zur Prüfung durch einen Admin.
* *Veröffentlicht*: Ein Admin hat die Initiative geprüft und veröffentlicht.
* *Abgelaufen*: Falls kein Admin sie vor einem im Initiative-Initializer konfigurierten Zeitpunkt veröffentlicht hat.
* *Verworfen*: Falls die Initiative die Prüfung durch einen Admin nicht bestanden hat.
* *Abgelehnt*: Falls die Initiative im Zeitraum der Unterschriftensammlung nicht genügend Unterschriften erhalten hat.
* *Akzeptiert*: Falls die Initiative im Zeitraum der Unterschriftensammlung genügend Unterschriften erhalten hat.

[plantuml]
@startuml
:Erstellt;
:Technische Validierung;
wenn (die maximale Validierungszeit überschritten?) dann (ja)
  #pink:Abgelaufen;
  kill;
elseif (validiert?) dann (nein)
  #pink:Verworfen;
  Kill;
sonst (ja)
  #palegreen:Veröffentlicht;
  wenn (genug Signaturen?) dann (nein)
    #pink:Ablehnt
    (nicht genug Signaturen);
    Kill;
  else (ja)
    #palegreen:Akzeptiert
    (genug Signaturen);
    stop;
  endif;
endif
@enduml

Schliesslich sind dies alle relevanten Einstellungen zu jedem Zeitpunkt im Lebenszyklus von Initiativen:

[plantuml]
@startuml
      (*) --> "Eine neue Initiative erstellen"
      if "Gibt es nur einen Typ?" then
      --> [Yes] "Initiativformular ausfüllen"
      else
      --> [No] "Initiativtyp auswählen"
      --> "Initiativformular ausfüllen"
      Endif
      partition Erstellt {
        if "Ist die Person eine Benutzergruppe?" then
        --> [Yes] "Zur technischen Validierung senden"
        else
        --> [No] Mindestanzahl an Mitgliedern des Initiativkomitees sammeln
        --> "Zur technischen Validierung senden"
        Endif
      }
      partition Prüfung {
        if "Wurde die maximale Zeit für die Validierung überschritten (standardmässig 60 Tage)?" then
          --> [Yes] "Abgelaufen"
        else
          --> [No] if "Wurde sie von einem Admin akzeptiert?" then
            --> [No] "Verworfen"
            else
            --> [Yes] "Veröffentlichen"
            endIf
        endIf
      }
      partition Veröffentlicht {
        --> "Unterschriftenprozess"
        if "Wurde das konfigurierte Zeitfenster für die Validierung überschritten (standardmässig 60 Tage)?"
    --> [Yes] "Abgelaufen"
  else
    --> [No] PDF in die Unterschriften
    --> Prüfen Sie Unterschriften mit Offline-Unterschriften auf Duplikate (wenn die Initiative sie hat)
    --> wenn "Hat die Initiative die erforderliche Anzahl an Unterschriften erhalten? dann
      --> [No] Ablehnt
    else
      --> [Yes] Akzeptiert
    endIf
  endIf
}
--> (*)
@enduml
