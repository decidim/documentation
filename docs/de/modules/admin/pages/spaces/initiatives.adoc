= Initiativen

Eine Initiative ist eine besondere Art von partizipatorischen Prozess, der von jedem (unabhängig von anderen Kanälen oder Beteiligungsräumen) durch die Sammlung von (online und inpersonalen) Unterschriften für die Organisation zur Durchführung einer spezifischen Aktion gefördert werden kann (Änderung einer Verordnung, initiieren Sie ein Projekt, ändern Sie den Namen einer Abteilung oder Straße, etc.).

Die Befürworter einer Initiative können ihre Ziele definieren, Unterstützung sammeln, debattieren, diskutieren verteilen Sie es und definieren Sie Treffpunkte, an denen Unterschriften von den Teilnehmern oder anderen Teilnehmern offen stehenden Debatten gesammelt werden können.

Beispiele: Eine Initiative kann Unterschriften sammeln, um eine Konsultation aller Menschen einer Organisation zu fordern, oder eine Versammlung zu bilden oder einen Prozess der Budgeterhöhung für ein Gebiet oder Gebiet der Organisation zu fordern. Während des Prozesses der Erfassung von Unterschriften können mehr Menschen diese Nachfrage ergänzen und sie in der Organisation vorantreiben.

Initiativen sollen von den anderen Beteiligungsräumen unterschieden werden, weil sie als partizipatorisches Instrument oder Mechanismus von den Teilnehmern gefördert werden können. Mit anderen Worten: Die Initiativen sind Mechanismen für die halbdirekte Demokratie, durch die die Teilnehmer eine bestimmte Aktion von gemeinsamem Interesse für die Organisation fördern können, durch das Sammeln einer bestimmten Anzahl von Unterschriften. In diesem Fall Was die Organisation zu tun hat, ist die Förderung dieser Initiativen zu ermöglichen und den Betroffenen die notwendige technische Unterstützung und Beratung zu bieten. Die Rolle des Administrators der Plattform unterscheidet sich also etwas von der der anderen Partizipationsräume.

Zunächst müssen Sie die verschiedenen Formen von Initiativen konfigurieren. Dies könnte in einer Verordnung (wie ein kommunales normatives oder staatliches Gesetz) angegeben werden. Angabe der Anzahl der für die Verarbeitung der verschiedenen Arten von Initiativen erforderlichen Signaturen. Zum Beispiel Eine Initiative zur Aufnahme eines oder mehrerer Punkte in die Tagesordnung des Gemeinderats erfordert offensichtlich weniger Unterschriften als eine andere Initiative zur Förderung einer verbindlichen Konsultation.

== 0. Initiative-Setup

Wie Initiativen funktionieren, hängt von zwei Dingen ab: Wie das Modul der Initiative über den xref:admin:initiatives_initializer konfiguriert wird. doc[initializer] (im Code) und wie der Initiationstyp im Administrationsbereich konfiguriert wird.

Was die Art der Initiativen betrifft, so muss **ein Administrator** einen definieren. Damit Initiativen an einer Organisation arbeiten können, muss mindestens ein Initiativtyp erstellt und mit mindestens einem Initiativtyp konfiguriert werden. Wenn es nur einen Typ gibt, wird der Teilnehmer nicht die Möglichkeit haben, den Typ der Initiative auszuwählen, wird dieser Schritt im Assistenten zur Erstellung der Initiative übersprungen.

Einige echte Beispiele aus der Stadt Barcelona:

* Um einen Artikel dem Gemeinderat oder der Bezirks-Agenda hinzuzufügen
* Einen partizipativen Prozess durchführen
* Neue Baugruppe erstellen
* Eine Verordnung genehmigen oder ändern
* Die Durchführung einer Bürgerberatung beantragen
* Versammlungen (Gemeinderäte oder öffentliches Publikum) einberufen

== 2. Initiative zur technischen Validierung senden

Diese Aktion wird vom **Autor **ausgeführt** durchgeführt.

Nachdem es vom Autor überprüft wurde, kann es an "Technische Validierung" gesendet werden, aber es hängt von der Konfiguration des Initiatyps ab, , ob die Optionen "Förderausschuss aktivieren" und "Minimum der Ausschussmitglieder" konfiguriert sind.

=== Promoter-Ausschuss

Ein Initiativtyp kann optional von einem Promoterausschuss mit einer Mindestanzahl an Ausschussmitgliedern unterstützt werden. Sobald der Nutzer die Initiative erstellt hat und bevor sie zur technischen Validierung geschickt werden kann, müssen er die Ausschussmitglieder zur Förderung der Initiative einladen.

Wenn der Benutzer die Initiative erstellt hat, erhält er einen Link, um sie mit möglichen Mitgliedern des Ausschusses zu teilen, was so etwas wie `/initiatives/.../committee_requests/new` aussieht

Wenn ein potenzieller Ausschussmitglied den Link öffnet, kann er auf einen Knopf klicken, der es ihm erlaubt, Mitglied des Ausschusses zu werden. Der Autor der Initiative muss dann jede Anfrage genehmigen. Der Autor kann sie genehmigen, indem er auf den "Edit"-Button ihrer Initiative am unteren Rand des Formulars klickt, das er den Ausschussmitgliedern genehmigen oder ablehnen kann.

image:initiative_commitee_members_send_to_technical_false.png[Initiative-Promotor-Komitee: Bildschirm bearbeiten]

Die Initiative kann nicht an die technische Validierung weitergeleitet werden, solange sie nicht die erforderliche Mindestanzahl an Ausschussmitgliedern erreicht. Den Einladungslink finden Sie im Bearbeitungsformular.

image:initiative_edit_commitee_members.png[Initiative-Promotor-Komitee: Bearbeite Bildschirm]

Teilen Sie den Einladungslink mit den Personen, die Sie in Ihrem Ausschuss haben möchten.

image:initiative_commitee_members_ask.png[Initiative-Promotor-Komitee: Bearbeite Bildschirm]

Die eingeladenen Personen mit diesem Link werden die Initiative lesen und beantragen können, dem Ausschuss beizutreten.

image:initiative_commitee_members_sent.png[Initiative-Promotor-Komitee: Bearbeite Bildschirm]

Der Antrag wird gesendet und der Autor kann ihn dann akzeptieren oder ablehnen in der Initiative bearbeiten Formular.

image:initiative_commitee_members_approve.png[initiativ-promotor-committee: edit screen]

image:initiative_commitee_members_send_to_technical_true.png[Initiative-Promotor-Komitee: Seite bearbeiten]

Sobald genügend Personen dem Promoter-Ausschuss beigetreten sind, kann der Initiator-Autor ihn für die technische Validierung
senden.

== Initiativstatus

Um den Status besser zu verstehen, ist dies eine Zusammenfassung:

|===
|Status |Erklärung

|Erstellt
|Die Initiative wurde ins Leben gerufen, ist aber noch nicht für jeden Besucher oder den Rest der Teilnehmer öffentlich zugänglich.

|Technische Validierung
|Die Initiative muss von einem Administrator überprüft werden. Von hier aus kann es "verworfen" oder "veröffentlicht" werden

|Abgelaufen
|Die Initiative wurde von einem Administrator nicht überprüft und wurde nicht genehmigt, und die Gültigkeitsdauer ist abgelaufen.

|Verworfen
|Die Initiative wurde von einem Administrator überprüft und verworfen, so dass sie nicht veröffentlicht wurde.

|Veröffentlicht
|Die Initiative wurde von einem Administrator überprüft und genehmigt, so dass sie veröffentlicht wurde.

|Abgelehnt
|Der Zeitraum für die Rücknahme der Unterschriften ist abgelaufen und es gab nicht genügend Unterschriften.

|Akzeptiert
|Der Zeitraum für die Rücknahme der Unterschriften ist abgelaufen und es gab genügend Unterschriften.
|===

[plantuml]
@startuml
:Erstellt;
:Technische Validierung;
wenn (die maximale Validierungszeit überschritten?) dann (ja)
  #pink:Abgelaufen;
  kill;
elseif (validiert?) dann (nein)
  #pink:Verworfen;
  Kill;
sonst (ja)
  #palegreen:Veröffentlicht;
  wenn (genug Signaturen?) dann (nein)
    #pink:Ablehnt
    (nicht genug Signaturen);
    Kill;
  else (ja)
    #palegreen:Akzeptiert
    (genug Signaturen);
    stop;
  endif;
endif
@enduml
