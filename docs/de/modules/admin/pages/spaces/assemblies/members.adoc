= Versammlungsmitglieder

== Die Grundlagen verstehen

Versammlungsmitglieder ermöglichen es, alle Teilnehmenden anzuzeigen, die zu einer bestimmten Versammlung gehören, unabhängig davon, ob es sich um Einzelpersonen oder Gruppen handelt.
Dies ist eine spezifische Funktion des Versammlungsraums, die dazu dient, die Transparenz der Versammlungen der Organisation zu verbessern.

== Konfiguration

=== Versammlungsmitglieder verwalten

Um auf die Liste der Versammlungsmitglieder zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Mitglieder".

image::spaces/assemblies/assembly_members_list.png[Assembly members administration list]

=== Aktionen

|===
|Icon |Name |Definition

|image:icons/action_delete.png[Symbol: Löschen]

|Um dieses Mitglied zu löschen.

=== Ein Versammlungsmitglied erstellen

Um ein neues Versammlungsmitglied zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neues Versammlungsmitglied".

image::spaces/assemblies/assembly_members_new_form.png[Assembly members new form]

.Neues Versammlungsmitglied-Formular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Teilnehmertyp
|Benötigt
|Ob dieses Versammlungsmitglied bereits über ein Konto in der Instanz verfügt oder nicht.

|Voller Name
|Erforderlich.
|Feld wird angezeigt, wenn "Nicht teilnehmend" ausgewählt wurde.

|Avatar
|Optional.
|Feld wird angezeigt, wenn "Nicht teilnehmend" ausgewählt wurde.

|Benutzer oder Gruppe
|Erforderlich, wenn es sich um eine bereits teilnehmende Person handelt.
|Geben Sie mindestens drei Zeichen ein, um nach dem Teilnehmendenkonto zu suchen.

|Position
|Benötigt
|Wählen Sie einen von Präsidenten, Vizepräsidenten, Sekretär oder anderen. Falls es etwas anderes ist, können Sie den Positionstitel eingeben.

|Reihenfolge
|Optional
|Welche Reihenfolge das Mitglied im Verhältnis zu den anderen Mitgliedern hat. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Wenn Sie zum Beispiel zwei Mitglieder haben, "Mitglied a" mit der Gewichtung "10" und "Mitglied b" mit der Gewichtung "0", dann steht "Mitglied b" bei der Sortierung an erster Stelle.

|Benennungsdatum
|Benötigt
|Wann diese Person oder Gruppe als Mitglied dieser Versammlung zugewiesen wurde. Erwartetes Format: tt/mm/jjjj.

|Enddatum
|Optional
|Wann diese Person oder Gruppe aufgehört hat, Mitglied dieser Versammlung zu sein. Erwartetes Format: tt/mm/jjjj.

|Geschlecht
|Optional
|Mit welchem Geschlecht identifiziert sich diese Person am meisten.

|Geburtstag
|Optional
|Wann wurde diese Person geboren. Erwartetes Format: tt/mm/jjjj.

|Geburtsort
|Optional
|Wo war diese Person geboren.
|===
