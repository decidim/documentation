= Versammlungstypen

== Die Grundlagen verstehen

In manchen Fällen ist es notwendig, Versammlungen nach mehr als nur übergeordneten und untergeordneten Versammlungen zu organisieren.
Hier können Versammlungstypen nützlich sein und eine zusätzliche Kategorisierungsebene hinzufügen.
Teilnehmende können Versammlungen dann nach den von Ihnen erstellten Versammlungstypen filtern.

NOTE: Versammlungstypen funktionieren ähnlich wie xref:admin:spaces/processes/types.adoc[Prozesstypen].

== Konfiguration

=== Versammlungstypen verwalten

Um auf die Liste der Versammlungstypen zuzugreifen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Verwalten" und anschliessend auf den Menüpunkt "Versammlungstyp".

image::spaces/assemblies/assemblies_types_list.png[Backend assemblies types menu item]

=== Einen Versammlungstyp erstellen

Klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neuer Versammlungstyp".

image::spaces/assemblies/assemblies_types_form.png[Process type creation form]

.Formular für neuen Versammlungstyp: Allgemeine Informationen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Titel des Versammlungstyps.
|===

=== Versammlungstyp zu einer Versammlung hinzufügen

Um Versammlungen mit Versammlungstypen zu verknüpfen, wählen Sie auf der Bearbeitungsseite einer Versammlung den Versammlungstyp im mit Andere bezeichneten Abschnitt aus.

image:spaces/assemblies/assemblies_types_edit_process.png[Auswahl eines Versammlungstyps beim Bearbeiten einer Versammlung]

=== Nach Versammlungstypen filtern

Wenn mindestens ein Versammlungstyp definiert und einer Versammlung zugeordnet ist, wird links in der Versammlungsliste in der
Teilnehmenden-Oberfläche ein Filter angezeigt, der das Filtern von Versammlungen ermöglicht.

image::spaces/assemblies/assemblies_types_filter.png[Assemblies types filter in the assemblies index]
