= Unterzeichnen Sie eine Initiative

== Die Grundlagen verstehen

Initiativen sind dazu gedacht, unterschrieben zu werden, sei es mit Online- oder Präsenz-Unterschriften. Das Ziel der Urheberschaft einer Initiative ist es, ihre Initiative zu fördern
und Unterstützung dafür zu sammeln.

== Konfiguration

=== Unterschriftenprozess

Sobald die Initiative von einem Admin veröffentlicht wurde, wird sie auf der Auflistungsseite der Initiativen sichtbar.

image::spaces/initiatives/initiatives_index_front_with_initiatives.png[Initiatives index in front with initiatives]

Die Initiativseite zeigt eine Schaltfläche "Unterschreiben" und einen Unterschriftenzähler mit dem zu erreichenden Unterschriftenziel und der aktuellen Anzahl an Unterschriften.

image::spaces/initiatives/initiative_show_published.png[Initiative show after it was published]

Autorisierte Teilnehmende müssen nur auf die Schaltfläche "Unterschreiben" klicken, damit ihre Unterschrift berücksichtigt wird.

NOTE: Je nach den Berechtigungen, die Sie für die Unterschrift verlangen, kann der Prozess unterschiedlich sein und zusätzliche Schritte umfassen.

Sobald die teilnehmende Person auf die Schaltfläche geklickt hat, wird die Unterschrift im Unterschriftenzähler erhöht.
Wenn dies für diesen Initiativtyp erlaubt ist, können Teilnehmende ihre Unterschrift auch rückgängig machen, indem sie auf die Schaltfläche "Bereits unterschrieben" klicken.

image::spaces/initiatives/initiative_show_signed.png[Initiative show after it was signed]
