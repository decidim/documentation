= Ausschussmitglieder

== Die Grundlagen verstehen

NOTE: Erläuterungen zum Initiativkomitee finden Sie unter xref:admin:spaces/initiatives/author_manage/committee.adoc[Initiativkomitee].

Ausschussmitglieder können je nach den für die Initiativtypen festgelegten Regeln erforderlich sein.
Teilnehmende können diese über ihr Bearbeitungsformular der Initiative verwalten, aber auch Admins können auf die Liste der
Ausschussmitglieder zugreifen.

== Konfiguration

=== Ausschussmitglieder verwalten

Um auf die Liste der Ausschussmitglieder zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Ausschussmitglieder".

image::spaces/initiatives/initiative_members_admin.png[Initiative committee members list in administration]

Dort kann die Urheberschaft den Einladungslink der Initiative einsehen und kopieren sowie die Liste der Ausschussmitglieder einsehen.
