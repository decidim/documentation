= Eine Initiative beantworten

== Die Grundlagen verstehen

Initiativen sollten irgendwann eine Antwort von Ihrer Organisation erhalten. Dies kann vor Ende der Unterschriftensammlung geschehen,
weil sie bereits von einem Organ Ihrer Struktur angenommen oder abgelehnt wurde, oder weil sie vor Ende der Sammelfrist
die erforderliche Anzahl an Unterschriften erreicht hat.

== Konfiguration

=== Eine Initiative beantworten

Klicken Sie in der Initiativenliste auf das Symbol "Antworten", um eine Initiative zu beantworten.

image::spaces/initiatives/initiative_backend_answer.png[Initiative backend answer]

Auf dieser Seite sehen Sie den Titel, die Beschreibung, das Erstellungsdatum, den Status und die Anzahl der Unterschriften der Initiative sowie die
Antwortfelder.

.Formular für Initiativenantwort
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Antwort
|Optional
|Inhalt der Initiativenantwort, der auf der Initiativenseite sichtbar ist.

|Antwort-URL
|Optional
|Link, der dem Antwortinhalt hinzugefügt wird.

|Beginn der Unterschriftensammlung
|Benötigt
|Datum des Beginns der Unterschriftensammlung.

|Ende der Unterschriftensammlung
|Benötigt
|Datum des Endes der Unterschriftensammlung. Sie können es auf den Vortag legen, wenn Sie die Initiative für neue Unterschriften schliessen möchten.
|===

image::spaces/initiatives/initiative_frontend_answer.png[Initiative frontend answer]

=== Annehmen oder ablehnen

Um die Änderung in der Initiativenliste vorzunehmen, muss der Admin zur Bearbeitungsseite der Initiative gehen und
auf die Schaltfläche klicken, die der Situation der Initiative entspricht.
Sobald die Sammelfrist einer veröffentlichten Initiative abgelaufen ist, gibt es zwei Möglichkeiten:

. Die Initiative hat genügend Unterschriften erhalten: Klicken Sie auf die Schaltfläche "Initiative annehmen"
. Die Initiative hat nicht genügend Unterschriften erhalten: Klicken Sie auf die Schaltfläche "Initiative ablehnen"
