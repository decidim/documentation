= Initiativentypen

== Die Grundlagen verstehen

Initiativentypen bilden das grundlegende Rahmenwerk für Initiativen, da sie es Admins ermöglichen, die verschiedenen Formen festzulegen, die Initiativen
annehmen können, sowie die spezifischen Regeln und die Anzahl der benötigten Unterschriften für jeden Initiativentyp.

Zum Beispiel könnte Ihre Organisation Teilnehmenden erlauben:

* eine neue Regelung vorzuschlagen
* eine Arbeitsgruppe oder einen Ausschuss zu eröffnen
* eine bestehende Regelung zu ändern
* eine ausserordentliche Generalversammlung einzuberufen
* Traktanden zur Tagesordnung eines Stadtrats hinzuzufügen

Im Allgemeinen werden solche Mechanismen in einer internen Regelung festgelegt (z. B. einer Gemeindeverordnung oder einem kantonalen Gesetz), die
die erforderliche Anzahl an Unterschriften bestimmt.

Sie müssen mindestens *einen Initiativentyp* und *einen Geltungsbereich für den Initiativentyp* erstellen, damit Teilnehmende Initiativen veröffentlichen können.
Wenn Sie mehrere Initiativentypen erstellen, können Teilnehmende auswählen, zu welchem Typ ihre Initiative gehört.

== Konfiguration

=== Einen Initiativentyp erstellen

Um einen Initiativentyp zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Verwalten" und anschliessend auf den Menüpunkt "Initiativentypen".

image::spaces/initiatives/initiatives_menu_types.png[Access Initiatives types panel]

Klicken Sie dann auf die Schaltfläche "Neuer Initiativentyp". Sie werden zum Erstellungsformular für Initiativentypen weitergeleitet.

|Optional

|Optional

|Personendaten des Teilnehmers auf Unterschrift sammeln

image::spaces/initiatives/type_form_authorizations.png[Initiative type form authorizations]

Klicken Sie unten im Formular auf die Schaltfläche Erstellen, um Ihren Initiativentyp zu speichern.
Erst danach können Sie den Geltungsbereich für den Initiativentyp erstellen, der für die Erstellung der ersten Initiativen benötigt wird.

==== Einen Geltungsbereich für einen Initiativentyp erstellen

Ein Initiativentyp muss über zugeordnete Geltungsbereiche verfügen, damit Teilnehmende Initiativen erstellen können.
Damit lässt sich nämlich ein Geltungsbereich mit einer Anzahl an Unterschriften verknüpfen, sodass mehrere Unterschriftenschwellen für denselben Initiativentyp möglich sind.

Scrollen Sie im Formular für den Initiativentyp nach unten, um einen neuen Abschnitt namens "Geltungsbereiche für den Initiativentyp" und eine Schaltfläche zu finden.

image::spaces/initiatives/type_form_scopes.png[Initiative type form scopes]

Klicken Sie auf die Schaltfläche "Neuer Geltungsbereich für Initiativentyp", um einen zu erstellen.

image::spaces/initiatives/admin_initiative_type_scope.png[New initiative type form]

.Admin-Formular für neuen Initiativentyp: Thema
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Themen
|Benötigt
|Wählen Sie den Geltungsbereich aus, der zu dieser Anzahl an Unterschriften gehört. Wenn Sie keine spezifische Regel haben, behalten Sie den globalen Geltungsbereich bei.

|Unterschriften erforderlich
|Benötigt
|Die Anzahl der Unterschriften, die die Initiative vor Ablauf der Sammelfrist erreichen muss, um angenommen zu werden.
|===

Sie können mehrere Themen für Initiativentypen hinzufügen, wenn Sie für bestimmte Themen eine spezifische Anzahl an Unterschriften benötigen.
Dies kann zum Beispiel ein Prozentsatz der Einwohnerzahl unterschiedlicher Gebiete sein.

image::spaces/initiatives/type_form_scopes_multiple.png[Initiative type form scopes with three scopes]

=== Initiativentypen verwalten

image::spaces/initiatives/initiatives_types_list.png[Initiatives types list]

Sobald Sie einen oder mehrere Initiativentypen erstellt haben, können Sie sie in der Liste im Verwaltungspanel verwalten, mit:

* *Initiativentypen*: Titel des Initiativentyps.
* *Erstellt am*: Erstellungsdatum des Initiativentyps.

=== Berechtigungen

Sie können die Berechtigungen für einen Initiativentyp konfigurieren, indem Sie auf das Symbol image:icons/action_permissions.png klicken.

image::spaces/initiatives/initiatives_types_permissions.png[Initiatives types permissions edition]

Auf dieser Seite können Sie spezifische xref:admin:participants/authorizations.adoc[Berechtigungen] anfordern, damit Teilnehmende eine Initiative unterzeichnen oder erstellen können.
