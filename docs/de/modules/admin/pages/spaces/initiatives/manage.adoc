= Initiativen verwalten

== Die Grundlagen verstehen

Wenn eine teilnehmende Person eine Initiative erstellt, wird nicht nur eine Ressource wie ein Vorschlag erstellt, sondern ein ganzer Raum,
      den Admins in der Verwaltung verwalten können:

* xref:admin:spaces/initiatives/admin_manage/committee.adoc[Ausschussmitglieder]
* xref:admin:spaces/initiatives/admin_manage/components.adoc[Komponenten]
* xref:admin:spaces/initiatives/admin_manage/attachments.adoc[Anhänge]
* xref:admin:spaces/initiatives/admin_manage/moderations.adoc[Moderationen]
* xref:admin:spaces/initiatives/admin_manage/answer.adoc[Eine Initiative beantworten]

NOTE: Wenn Sie dies nicht konfiguriert haben, werden bei der Erstellung einer Initiative standardmässig die Komponenten Veranstaltungen und Seite
      aktiviert. Bitten Sie die für die Implementierung Ihrer Instanz zuständige Person, diesen Parameter anzupassen, wenn Sie ihn nicht benötigen oder standardmässig andere Komponenten aktiviert haben möchten.

image::spaces/initiatives/initiative_admin_show.png[Admin initiative show page]

== Konfiguration

=== Initiativen verwalten

Nachdem die Initiative von einer teilnehmenden Person zur technischen Validierung eingereicht wurde, kann ein Admin alle Initiativen im Verwaltungspanel einsehen.

image::spaces/initiatives/initiative_admin_list.png[Admin initiatives list]

Sie finden alle Initiativen in dieser Liste mit:

* *ID*: Identifikationsnummer der Initiative.
* *Initiativen*: Titel der Initiative.
* *Unterschriften*: Summe der Online- und Vor-Ort-Unterschriften.
* *Erstellt am*: Erstellungsdatum der Initiative.
* *Veröffentlicht am*: Veröffentlichungsdatum der Initiative.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Initiativen anhand ihres Titels suchen.

image::spaces/initiatives/initiative_list_filters.png[Initiatives list filtered]

=== Eine Initiative bearbeiten

Beim Klicken auf die Schaltfläche "Bearbeiten" oder den Initiativentitel in der Initiativenliste der Verwaltung wird der Admin
      zum Bearbeitungsformular der Initiative weitergeleitet und kann sehen, dass die sekundäre Navigationsleiste auf der linken Seite auch die Verwaltung
      der Komiteemitglieder der Initiative, ihrer Komponenten, Anhänge und gemeldeten Inhalte ermöglicht.

image::spaces/initiatives/initiative_edit_form_admin.png[Initiative edit form in administration]

Im Bearbeitungsformular kann der Admin den Titel, die Beschreibung, das Thema, den Bereich usw. der Initiative prüfen und ändern.
Er kann die Initiative auch zur technischen Validierung einreichen.

=== Initiative veröffentlichen

Sobald eine Initiative zur technischen Validierung eingereicht wurde, kann der Admin entscheiden, sie zu veröffentlichen oder zu verwerfen.
Um eine Initiative in technischer Validierung zu veröffentlichen, gehen Sie zur Bearbeitungsseite der Initiative und klicken Sie auf die Schaltfläche "Veröffentlichen".

=== Signaturen exportieren

Nachdem die Initiative begonnen hat, Unterschriften zu sammeln, können Admins die Unterschriften im Bearbeitungsformular der Initiative im CSV- oder PDF-Format exportieren.
