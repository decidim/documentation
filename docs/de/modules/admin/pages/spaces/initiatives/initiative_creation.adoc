= Initiativenerstellung

== Die Grundlagen verstehen

Sobald Sie die xref:admin:spaces/initiatives/types.adoc[Initiativentypen und -bereiche] konfiguriert haben, sollten Sie in der Lage sein, auf den Initiativenraum in der Benutzeroberfläche zuzugreifen.

image::spaces/initiatives/initiatives_index_front.png[Initiatives index in front without initiatives]

Teilnehmende können nun Initiativen erstellen.
Je nachdem, wie das Initiativenmodul im Initializer oder wie der Initiativentyp konfiguriert ist, kann eine Autorisierung erforderlich sein.

== Konfiguration

Um mit der Erstellung einer Initiative zu beginnen, muss die teilnehmende Person auf die Schaltfläche "Neue Initiative" klicken.
Je nach Konfiguration Ihrer Instanz müssen sie verschiedene Schritte durchlaufen, bevor sie ihre Initiative zur technischen Validierung einreichen können, wo sie von einem Admin
geprüft wird, bevor sie veröffentlicht wird und mit der Unterschriftensammlung beginnt.

=== Wahl des Initiativentyps

Wenn die Instanz mehrere Initiativentypen hat, besteht der erste Schritt in der Wahl des Initiativentyps.

image::spaces/initiatives/initiative_new_step_type.png[Initiative creation: initiative type choice]

Wenn nur ein Initiativentyp konfiguriert ist, wird dieser Schritt automatisch übersprungen.

=== Ähnlichkeitsvergleich

Kann von den Entwickelnden Ihrer Organisation deaktiviert werden.
Überprüft den Rest der Initiativen, ob es ähnliche Initiativen gibt. Falls es solche gibt, zeigt das System sie an, bevor es fortfährt.
Dies ist eine Möglichkeit, Duplikate zu vermeiden und Teilnehmende zu ermutigen, andere ähnliche Initiativen zu unterstützen.

=== Initiativkomitee

Wenn das Initiativkomitee für diesen Initiativentyp aktiviert ist, ermöglicht dieser Schritt Teilnehmenden zu verstehen, was sie tun müssen, bevor sie ihre Initiative zur Veröffentlichung einreichen können.

image::spaces/initiatives/initiative_new_step_committee.png[Initiative creation: initiative promoting committee]

Weitere Informationen finden Sie im Artikel xref:admin:spaces/initiatives/author_manage/committee.adoc[Initiativkomitee].

=== Abschluss

Der Abschlussschritt teilt der teilnehmenden Person die Erstellung der Initiative mit und zeigt ihr je nach Bedarf unterschiedliche Schaltflächen an, falls noch Mitglieder für das Initiativkomitee gefunden werden müssen.

image::spaces/initiatives/initiative_new_step_finish.png[Initiative creation: initiative finish]

Wenn der Initiativentyp nicht mehrere Mitglieder des Initiativkomitees erfordert, können Teilnehmende ihre Initiative direkt zur technischen Validierung einreichen.

NOTE: Die Initiative ist erst dann öffentlich in der Initiativenliste sichtbar, wenn sie von einem Admin geprüft und veröffentlicht wurde.

Auf dieser Seite können Teilnehmende:

* Zur Initiativenliste zurückkehren
* Ihre Initiative bearbeiten
* Zu ihren Initiativen gehen
* Ihre Initiative zur technischen Validierung einreichen
