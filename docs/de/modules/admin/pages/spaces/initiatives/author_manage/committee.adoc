= Initiativkomitee

== Die Grundlagen verstehen

Ein Initiativkomitee ist eine Gruppe von Personen, die die Initiative gemeinsam vorantreiben und fördern. Zum Beispiel könnte es sich um eine kollektive Initiative handeln, die von mehreren Bürger:innen durchgeführt werden muss, um von der Verwaltung akzeptiert zu werden, usw.
Die Regeln für das Initiativkomitee werden von den Admins bei der Verwaltung der Initiativtypen festgelegt. Sie können daher für einige Initiativen optional und für andere obligatorisch sein,
zum Beispiel mit der Notwendigkeit, dass drei Personen eine Initiative tragen müssen.

Für Initiativen, die eine Mindestanzahl an Mitgliedern im Initiativkomitee benötigen, muss die Urheberschaft ihnen einen Link senden, damit sie dem Komitee beitreten können,
bevor die Initiative zur technischen Validierung eingereicht werden kann.

NOTE: Mitglieder des Initiativkomitees können nur hinzugefügt werden, bevor die Initiative zur technischen Validierung eingereicht wird.

== Konfiguration

=== Ein Komiteemitglied einladen

Während des Erstellungsprozesses der Initiative oder später auf der Initiativseite und im Bearbeitungsformular kann die Urheberschaft einen Einladungslink kopieren.
Sie sollten diesen Link an die anderen Initiierenden der Initiative senden.

image::spaces/initiatives/promoter_link_show.png[Promoter's committee link in initiative show]

image::spaces/initiatives/promoter_link_edit.png[Promoter's committee link in initiative edit form]

Beim Öffnen des Links kann das eingeladene Komiteemitglied den Titel und Inhalt der Initiative sehen und beantragen, Mitglied des Initiativkomitees zu werden.

image::spaces/initiatives/promoter_link_page.png[Promoter's committee request page]

Die Urheberschaft einer Initiative kann die Anträge der Komiteemitglieder auf der Bearbeitungsseite der Initiative verwalten.

image::spaces/initiatives/promoter_members_edit.png[Promoter's committee management in initiative edit form]

Alle genehmigten Komiteemitglieder können dann auf die Initiative zugreifen, sie bearbeiten, ihre Mitglieder verwalten und sie zur technischen Validierung einreichen.
Die Initiative kann erst zur technischen Validierung eingereicht werden, wenn sie die erforderliche Mindestanzahl an Komiteemitgliedern erreicht hat.
