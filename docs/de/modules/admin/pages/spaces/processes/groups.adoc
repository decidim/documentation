= Prozessgruppen

== Die Grundlagen verstehen

Eine Prozessgruppe kann nützlich sein, um grosse Beteiligungsprozesse anhand eines Kriteriums in Teilprozesse zu unterteilen.
Ausserdem ermöglicht sie es Admins, eine Instanz mit vielen Prozessen zu organisieren, indem sie diejenigen zusammenfassen, die zu einem
      bestimmten Prozesstyp oder Thema gehören, zum Beispiel jährliche Ausgaben eines partizipativen Budgets, Mobilitätsplanungsprozesse usw.

== Konfiguration

=== Prozessgruppen verwalten

Um zur Verwaltungsseite der Prozessgruppen zu gelangen, klicken Sie auf den Tab "Prozessgruppen" auf der Prozessübersichtsseite.

=== Eine Prozessgruppe erstellen

Um eine neue Prozessgruppe zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neue Prozessgruppe".

=== Inhaltsblöcke der Startseite

Prozessgruppen sind im Wesentlichen Startseiten, die umfangreichere Beteiligungsprozesse zusammenfassen.
Diese Startseite funktioniert mit verschiedenen Inhaltsblöcken, genau wie die allgemeine Startseite der Plattform.
Das bedeutet, dass Sie verschiedene Abschnitte der Startseite aktivieren und einige davon konfigurieren können.

Um die Startseite einer Prozessgruppe zu konfigurieren, klicken Sie beim Bearbeiten der Prozessgruppe oben rechts auf der Seite auf die Schaltfläche "Verwalten"
und anschliessend auf den Menüpunkt "Startseite".

image::spaces/processes/processes_group_landing.png[Participatory process group landing page]

Nachfolgend finden Sie alle Konfigurationsanleitungen für die Inhaltsblöcke sowie Screenshots davon, wie sie auf der Startseite angezeigt werden.

NOTE: Wenn ein Inhaltsblock keinen anzuzeigenden Inhalt hat oder nicht konfiguriert wurde, wird er nicht auf der Startseite angezeigt.

==== Titel und Beschreibung

Der Inhaltsblock Titel und Beschreibung ermöglicht die Anzeige von:

* *Titel*: der Titel der Prozessgruppe.
* *Beschreibung*: die Beschreibung der Prozessgruppe.
* *Anzahl verwandter Prozesse*: die Anzahl der veröffentlichten Beteiligungsprozesse, die zu dieser Prozessgruppe gehören.
* *Geltungsbereich*: der Geltungsbereich der Prozessgruppe.
* *Hashtag*: der Hashtag, der auf das soziale Netzwerk X verweist.
* *Website*: ein Link zur Website.

image::spaces/processes/processes_group_landing_title.png[Participatory process group landing page title and description block]

==== Banner-Bild und Handlungsaufforderung

Der Inhaltsblock Banner-Bild und Handlungsaufforderung ermöglicht die Anzeige von:

* *Titel*: der Titel der Prozessgruppe.
* *ein Hashtag*: der Hashtag, der auf das soziale Netzwerk X verweist.
* *eine Handlungsaufforderungs-Schaltfläche*: aktivieren Sie sie, indem Sie im Inhaltsblock der Startseite auf das Symbol "Bearbeiten" klicken.
* *ein Bild*: laden Sie für diesen Block ein Bild herunter, indem Sie im Inhaltsblock der Startseite auf das Symbol "Bearbeiten" klicken.

image::spaces/processes/processes_group_landing_hero.png[Participatory process group landing page hero block]

==== Vorschläge

Der Inhaltsblock Vorschläge zeigt eine Auswahl von Vorschlägen aus den verschiedenen Beteiligungsprozessen der Prozessgruppe an.
Sie können konfigurieren, ob die Vorschläge nach den neuesten oder zufällig sortiert werden, indem Sie im Inhaltsblock der Startseite auf das Symbol "Bearbeiten" klicken.

image::spaces/processes/processes_group_landing_proposals.png[Participatory process group landing page proposals block]

==== Ergebnisse

Der Inhaltsblock Ergebnisse zeigt eine Auswahl von Ergebnissen aus den verschiedenen Beteiligungsprozessen an.
Sie können konfigurieren, ob die Ergebnisse nach den neuesten oder zufällig sortiert werden, indem Sie im Inhaltsblock der Startseite auf das Symbol "Bearbeiten" klicken.

image::spaces/processes/processes_group_landing_results.png[Participatory process group landing page results block]

==== Anstehende Veranstaltungen

Der Inhaltsblock Bevorstehende Veranstaltungen zeigt eine Auswahl von Veranstaltungen aus den verschiedenen Beteiligungsprozessen an.
Sie können konfigurieren, ob die Ergebnisse nach den neuesten oder zufällig sortiert werden, indem Sie im Inhaltsblock der Startseite auf das Symbol "Bearbeiten" klicken.
Wenn es keine bevorstehenden Veranstaltungen gibt, zeigt dieser Block die vergangenen an.

image::spaces/processes/processes_group_landing_events.png[Participatory process group landing page events block]

Der Inhaltsblock Beteiligungsprozesse zeigt ein Raster von Beteiligungsprozessen auf der Startseite an.
