= Erstellung eines Beteiligungsprozesses

== Die Grundlagen verstehen

Beteiligungsprozesse ermöglichen es Admins, Komponenten in Verbindung mit verschiedenen Beteiligungsphasen zu konfigurieren.
Um mit der Erstellung eines Prozesses zu beginnen, klicken Sie in der Prozessliste oben rechts auf der Seite auf die Schaltfläche "Neuer Prozess".

Das Formular zur Prozesserstellung ist in verschiedene Abschnitte unterteilt, die im Folgenden näher beschrieben werden.

Sobald Sie einen Prozess erstellt haben, sehen Sie im sekundären Navigationspanel alle verfügbaren Prozesskonfigurationen:

* xref:admin:spaces/processes/process_creation.adoc[Über diesen Prozess]: hier können Sie auf alle Felder des Erstellungsformulars zugreifen und sie bearbeiten.
* xref:admin:spaces/processes/landing_page.adoc[Startseite]
* xref:admin:spaces/processes/phases.adoc[Phasen]
* xref:admin:spaces/processes/components.adoc[Komponenten]
* xref:admin:spaces/processes/categories.adoc[Kategorien]
* xref:admin:spaces/processes/attachments.adoc[Anhänge]
* xref:admin:spaces/processes/admins.adoc[Prozess-Admins]
* xref:admin:spaces/processes/private_participants.adoc[Private Teilnehmende]
* xref:admin:spaces/processes/moderations.adoc[Moderationen]

== Konfiguration

=== Allgemeine Informationen

Dieser Abschnitt ermöglicht es, eine allgemeine Beschreibung des Prozesses anzugeben, hauptsächlich einen Titel, eine URL und eine Beschreibung.

image::spaces/processes/processes_new_form_general_info.png[New participatory process form general info section]

.Neues Beteiligungsprozess-Formular: Allgemeine Informationen
[cols="20h,10h,~,~"]
|===
|Feld |Typ |Beschreibung |Sichtbarkeit

|Titel
|Benötigt
|Titel des partizipativen Prozesses. Zum Beispiel "Partizipatives Budget 2020"
|Sichtbar auf der Karte des Prozesses auf der Startseite, in der Prozessübersicht, in der Navigation und im Inhaltsblock "Banner-Bild und Handlungsaufforderung" der Startseite.

|Untertitel
|Benötigt
|Untertitel. Zum Beispiel "Lassen Sie uns unsere Prioritäten gemeinsam festlegen"
|Sichtbar im Inhaltsblock "Banner-Bild und Handlungsaufforderung" der Startseite.

|Reihenfolge
|Benötigt
|Bestimmt die Reihenfolge des Prozesses bei der Anzeige im Prozessverzeichnis oder auf der Startseite.
|Nicht zutreffend

|URL Slug
|Benötigt
|URL-Slugs werden verwendet, um die URLs zu generieren, die auf diesen Prozess verweisen. Akzeptiert nur Buchstaben, Zahlen und Bindestriche und muss
mit einem Buchstaben beginnen.
|Sichtbar in der URL des Beteiligungsprozesses, zum Beispiel https://example.org/processes/participatory-budget-2020.

|Hashtag
|Optional
|Hashtag, der auf das soziale Netzwerk X verweist.
|Sichtbar im Inhaltsblock "Banner-Bild und Handlungsaufforderung" der Startseite.

|Kurze Beschreibung
|Benötigt
|Eine kurze Erklärung, worum es beim Beteiligungsprozess geht.
|Sichtbar im Inhaltsblock "Hauptdaten" der Startseite.

|Beschreibung
|Benötigt
|Eine ausführliche Erklärung, worum es beim Beteiligungsprozess geht.
|Sichtbar im Inhaltsblock "Hauptdaten" der Startseite.

|Mitteilung
|Optional
|Der hier eingegebene Text wird den Nutzenden direkt unterhalb der Prozessinformationen angezeigt.
|Sichtbar im Inhaltsblock "Mitteilung" der Startseite.
|===

|Enddatum
|Optional

=== Metadaten

Dieser Abschnitt ermöglicht es, Metainformationen zum Prozess anzugeben.
Sie kann auf der Startseite über den Inhaltsblock "Metadaten" aktiviert werden.

image::spaces/processes/processes_new_form_metadata.png[New participatory process form metadata section]

.Neues Beteiligungsprozess-Formular: Metadaten
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Promoter-Gruppe
|Optional
|Falls eine bestimmte Gruppe am Ursprung des Prozesses steht, wie z. B. eine städtische Abteilung, ein Vereinsvorstand usw.

|Organisationsbereich
|Optional
|Der Tätigkeitsbereich oder die Kategorie der Organisation, falls relevant.

|Themenmetadaten
|Optional
|Metadaten zum Geltungsbereich des Prozesses, falls relevant.

|Wer beteiligt sich
|Optional
|Wer die berechtigten Teilnehmenden sind, die am Prozess teilnehmen können.

|Was beschlossen wird
|Optional
|Das Thema des Prozesses, also der Gegenstand der Entscheidung.

|Wie wird es beschlossen
|Optional
|Der Entscheidungsprozess.
|===

=== Filter

Dieser Abschnitt bestimmt die im Prozess verfügbaren Filter in den verschiedenen Komponenten.
Filter können anschliessend in jeder Komponente aktiviert und konfiguriert werden.

image::spaces/processes/processes_new_form_filters.png[New participatory process form filters section]

.Neues Beteiligungsprozess-Formular: Filter
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Themen aktiviert
|Optional
|Aktivieren, wenn Sie die Themenfilterung in diesem Prozess verwenden möchten.

|Thema
|Optional
|Zu welchem xref:admin:settings/scopes.adoc[Thema] dieser Prozess gehört.

|Themenfilter-Tiefe
|Optional
|Die Tiefe des Themenfilters einschränken. Dies ist relevant, wenn Sie komplexe Beziehungen bei untergeordneten Themen haben (wie eine Matroschka).
Wenn Sie zum Beispiel verschachtelte Themen Grossmutter -> Mutter -> Kind haben, können Sie mit dieser Einstellung das Thema Mutter auswählen,
      sodass Teilnehmende nur zwischen den Unterthemen Kind filtern können. Dies wäre zum Beispiel der Fall, wenn Sie
      Provinzen -> Städte -> Bezirke haben und der Prozess sich auf eine bestimmte Stadt bezieht.

|Bereich
|Optional
|Zu welchem xref:admin:settings/areas.adoc[Bereich] dieser Prozess gehört.
|===

=== Sichtbarkeit

Dieser Abschnitt ermöglicht es Admins, die Platzierung des Prozesses auf den verschiedenen Seiten sowie dessen Öffentlichkeit zu konfigurieren.

image::spaces/processes/processes_new_form_visibility.png[New participatory process form visibility section]

.Neues Beteiligungsprozess-Formular: Sichtbarkeit
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Prozessgruppe
|Optional
|Ermöglicht das Gruppieren mehrerer Prozesse. Weitere Informationen finden Sie unter xref:admin:spaces/processes/groups.adoc[Prozessgruppen].

|Privater Raum
|Optional
|Aktivieren Sie dies, wenn der Prozess nur für xref:admin:spaces/processes/private_participants.adoc[private Teilnehmende] zugänglich sein soll.

|Beworben
|Optional
|Aktivieren Sie dies, wenn der Prozess mehr Sichtbarkeit in der öffentlichen Prozessliste und im Inhaltsblock "Hervorgehobene Beteiligungsprozesse"
      in der Konfiguration der xref:admin:settings/homepage.adoc[Startseite] haben soll.
|===

=== Ähnliche Prozesse

Dieser Abschnitt ermöglicht es, Beziehungen zwischen Prozessen herzustellen. Dies unterscheidet sich von Prozessgruppen.
Es kann auf der Startseite mit dem Startseiten-Block "Ähnliche Prozesse" aktiviert werden.

image::spaces/processes/processes_new_form_related_processes.png[New participatory process form Related processes section]

.Formular für neuen Beteiligungsprozess: Ähnliche Prozesse
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Ähnliche Prozesse
|Optional
|Wählen Sie andere Beteiligungsprozesse, die mit diesem verwandt sind.
|===

=== Andere

Dieser Abschnitt ist leer, sofern nicht bereits ein Admin xref:admin:spaces/processes/types.adoc[Prozesstypen] erstellt hat.
Falls doch, sollten Sie einen Prozesstyp auswählen können, um den Prozess zu kategorisieren.
Teilnehmende können dann Prozesse im Prozessverzeichnis anhand dieser Typen filtern.
