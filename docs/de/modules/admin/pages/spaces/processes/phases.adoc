= Phasen

== Die Grundlagen verstehen

Ein partizipatorischer Prozess ist eine Abfolge von Phasen, die zeitlich geordnet sind. Je nachdem, in welcher Phase der Prozesszeitachse Sie sich
befinden, können Sie die für jede Phase benötigten Funktionen aktivieren und konfigurieren.

Idealerweise sind die Phasen eines Beteiligungsprozesses immer gleich und werden nicht geändert, damit Teilnehmende die
Regeln und den Zeitrahmen kennen und sich darauf einstellen können, wann es für sie am besten ist, an diesem Prozess teilzunehmen.

Zum Beispiel könnte die Standardstruktur eines Beteiligungsprozesses wie folgt aussehen:

. Präsentation
. Diagnose
. Vorschlagserstellung und Debatte
. Priorisierung von Vorschlägen
. Bewertung von Vorschlägen
. Überwachung

Teilnehmende finden den Link zu den verschiedenen Phasen eines Beteiligungsprozesses im Inhaltsblock "Phase und Dauer" der Startseite,
sofern dieser von einem Admin auf der xref:admin:spaces/processes/landing_page.adoc[Startseite] des Prozesses aktiviert wurde.

image::spaces/processes/process_phases_block.png[Block with processes phases link]

Beim Klicken auf den Link für die aktive Phase sehen sie die vollständige Beschreibung und Erklärung der Phasen in einem Pop-up.

image::spaces/processes/process_phases.png[Process phases explanation]

[NOTE]
Phases can be automatically changed if the scheduled task `decidim_participatory_processes:change_active_step` is configured.
If you want to manage them manually, then the implementer/operator of the installation needs to disable this scheduled task server-side.

== Konfiguration

=== Phasen verwalten

Um auf die Konfiguration der Phasen zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Phasen".

image::spaces/processes/process_phases_list.png[Phases of a participatory process]

=== Aktionen

.Aktionen
[cols="10h,20h,~,~"]
|===
|Icon |Name |Definition |Bedingung

|image:icons/action_edit.png[Symbol: Bearbeiten]
|Bearbeiten
|Diese Phase bearbeiten.
|Immer verfügbar

|image:icons/action_activate.png[Symbol: Aktivieren]
|Aktivieren
|Um diese Phase zur aktiven zu machen.
|Nur für inaktive Phasen verfügbar.

|image:icons/action_delete.png[Symbol: Löschen]
|Löschen
|Diese Phase löschen.
|Immer verfügbar
|===

=== Eine neue Phase erstellen

Um eine neue Phase zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neue Phase".

image::spaces/processes/process_phases_new_form.png[Create a new participatory process phase form]

.Formular zur Erstellung einer Prozessphase
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Der Titel für diese Phase, angezeigt im Phasen-Inhaltsblock und auf den Prozesskarten, wenn die Phase aktiv ist.

|Beschreibung
|Optional
|Eine lange Beschreibung, die erklärt, wofür diese Phase steht.

|Startdatum
|Optional
|Das Startdatum dieser Prozessphase. Erwartetes Format: dd/mm/yyyy

|Enddatum
|Optional
|Das Enddatum dieser Prozessphase. Erwartetes Format: dd/mm/yyyy

|Call-to-Action-Pfad
|Optional
|Veraltet

|Call-to-Action-Text
|Optional
|Veraltet
|===

CAUTION: Die Konfiguration der Handlungsaufforderung über die Phase des Beteiligungsprozesses ist mit dem neuen Design veraltet.
Dies erfolgt nun auf der Startseite über den Inhaltsblock Banner-Bild und Handlungsaufforderung.
