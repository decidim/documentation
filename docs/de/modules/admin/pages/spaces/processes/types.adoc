= Prozessarten

== Die Grundlagen verstehen

In einigen Fällen ist es notwendig, partizipatorische Prozesse mit mehr als nur xref:spaces/processes/groups.adoc[Process Groups] zu organisieren.
Hier können Prozesstypen nützlich sein und eine zusätzliche Kategorisierungsebene hinzufügen.
Teilnehmende können Prozesse dann nach den von Ihnen erstellten Prozesstypen filtern.

NOTE: Prozesstypen funktionieren ähnlich wie xref:admin:spaces/assemblies.adoc#_assemblies_types[Versammlungstypen].

== Konfiguration

=== Prozesstypen verwalten

Um auf die Liste der Prozesstypen zuzugreifen, klicken Sie auf die Schaltfläche "Verwalten" oben rechts auf der Seite und dann auf den Menüpunkt "Prozesstyp".

image::spaces/processes/process_types_list.png[Backend process types menu item]

=== Einen Prozesstyp erstellen

Klicken Sie auf die Schaltfläche "Neuer Prozesstyp" oben rechts auf der Seite.

image:spaces/processes/process_types_form.png[Formular zur Erstellung eines Prozesstyps]

.Neues partizipatorisches Prozesstyp-Formular: Allgemeine Informationen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Titel des partizipatorischen Prozesstyps.
|===

=== Prozesstyp zu einem Prozess hinzufügen

Um Prozesse mit Prozesstypen zu verknüpfen, wählen Sie auf der Bearbeitungsseite eines Prozesses den Prozesstyp im mit Andere bezeichneten Abschnitt aus.

image::spaces/processes/process_types_edit_process.png[Choose a process type when editing a process]

=== Nach Prozesstypen filtern

Wenn mindestens ein Prozesstyp definiert und mit einem Prozess verknüpft ist, wird links neben der Prozessliste
in der Teilnehmendenoberfläche ein Filter angezeigt, der das Filtern von Prozessen ermöglicht.

image::spaces/processes/process_types_filter.png[Process types filter in the processes index]
