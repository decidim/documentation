= Konferenzen

== Die Grundlagen verstehen

Eine Konferenz ist eine Sammlung von Veranstaltungen, die in einem Programm organisiert sind, mit einer Anzahl von Personen, die als Vortragende eingeladen sind, sowie weiteren
      Informationsfeldern, die für grosse Kongresse oder gesellschaftliche Veranstaltungen typisch sind (Anmeldung, Liste der Organisationen, die die
      Veranstaltung unterstützen oder sponsern, usw.) Eine Konferenz kann eine relevante Veranstaltung für eine Organisation und ihre Mitglieder sein oder im Rahmen eines
Beteiligungsprozesses stattfinden oder einer Konsultation folgen.

In Konferenzen werden Veranstaltungskomponenten in Form eines Programms angezeigt, wobei Tage und Uhrzeiten wie in einem Veranstaltungsprogramm aufgelistet werden.

=== Wie findet man sie?

Um auf das Konferenzen-Panel zuzugreifen, gehen Sie zum Verwaltungspanel und klicken Sie in der Verwaltungs-
      Navigationsleiste auf den Punkt "Konferenzen".

image::spaces/conferences/menu.png[Conferences menu]

Dort können Sie alle bestehenden Konferenzen verwalten.

== Konfiguration

=== Konferenzen verwalten

image::spaces/conferences/manage_conferences.png[Conferences list in administration panel]

Sie finden alle Konferenzen in der Liste im Verwaltungspanel mit:

* *Titel*: Titel der Konferenz.
* *Erstellt am*: Erstellungsdatum der Konferenz.
* *Veröffentlicht*: ob die Konferenz veröffentlicht ist oder nicht.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Konferenzen anhand ihres Titels suchen.
