= Medienlinks

== Die Grundlagen verstehen

Konferenzen können einen Abschnitt namens "Medienlinks" haben, der eine Liste von Mediendateien und Links anzeigt,
die mit der Konferenz verknüpft sind. Er wird auf einer bestimmten Seite der Konferenz angezeigt:

* Zugehörige Dokumente und Bilder aus dem Abschnitt xref:admin:spaces/conferences/attachments.adoc[Anhänge].
* Medienlinks aus dem Abschnitt Medienlinks.

image:spaces/conferences/media_links_frontend.png[Medienlinks der Konferenz im Frontend]

=== Wie findet man sie?

Um auf die Konfiguration der Medienlinks zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Medienlinks".

image::spaces/conferences/media_links_backend.png[Conferences media links]

=== Neuen Medienlink erstellen

Um einen neuen Medienlink zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neuer Medienlink".

image::spaces/conferences/new_media_link.png[Create a new conferences media link]

.Neues Medienlink-Formular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Der Titel des Links.

|Link
|Benötigt
|URL des Links.

|Datum
|Benötigt
|Veröffentlichungsdatum des Links.

|Reihenfolge
|Optional
|Welche Reihenfolge er im Verhältnis zu den anderen Links hat. Eine niedrigere Zahl bedeutet eine höhere Priorität. Wenn Sie zum Beispiel zwei Links haben, "Link a" mit der Gewichtung "10" und "Link b" mit der Gewichtung "0", dann steht "Link b" bei der Sortierung an erster Stelle.
|===
