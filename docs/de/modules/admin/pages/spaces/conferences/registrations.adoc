= Anmeldungen

== Die Grundlagen verstehen

Als Admin einer Konferenz können Sie die Anmeldungen für die Konferenz direkt über die Plattform verwalten.

Dazu können Sie diese Verwaltungsabschnitte nutzen:

* xref:admin:spaces/conferences/registrations/types.adoc[**Registrierungstypen**]: um die Anmeldemöglichkeiten festzulegen.
* xref:admin:spaces/conferences/registrations/users.adoc[**Benutzerregistrierung**]: um die Anmeldungen zu bestätigen.
* xref:admin:spaces/conferences/registrations/invites.adoc[**Invites**]: um Teilnehmende zur Konferenz einzuladen.
* xref:admin:spaces/conferences/registrations/certificates.adoc[**Teilnahmebestätigungen**]: um Teilnahmebestätigungen
im PDF-Format an die Teilnehmenden der Konferenz zu konfigurieren und zu versenden.
