= Einladungen

== Die Grundlagen verstehen

Admins können Teilnehmende zur Konferenz einladen.
Sie können bestehende Teilnehmende mit einem Konto auf der Plattform sowie Personen ohne Konto einladen.
Das Einladen einer teilnehmenden Person sendet eine E-Mail an die E-Mail-Adresse des Kontos und ermutigt die Person, sich für die Konferenz anzumelden.

== Konfiguration

=== Einladungen verwalten

Um auf die Konfiguration der Einladungen zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Einladungen".

image::spaces/conferences/invites.png[Conferences user invites in backend]

Sie können die Einladungen filtern und nach Name oder E-Mail der eingeladenen Person suchen.

=== Eine Einladung senden

Um eine teilnehmende Person einzuladen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Teilnehmende einladen".

image::spaces/conferences/invite_participant_form.png[Invite a participant form]
