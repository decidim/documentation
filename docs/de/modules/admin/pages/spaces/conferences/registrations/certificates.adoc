= Teilnahmebestätigung

== Die Grundlagen verstehen

Für manche Veranstaltungen möchten Teilnehmende möglicherweise eine Teilnahmebestätigung erhalten, um ihrem Arbeitgeber zu bestätigen, dass sie teilgenommen haben,
oder um beispielsweise zu bestätigen, dass sie eine Schulung absolviert haben.

Dafür können Admins Teilnahmebestätigungen erstellen.

== Konfiguration

=== Teilnahmebestätigung erstellen

Um auf die Konfiguration der Teilnahmebestätigung zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Teilnahmebestätigung".

image:spaces/conferences/certificates_of_attendance.png[Verwaltung der Teilnahmebestätigung für die Konferenz]

.Anwesenheitszertifikat
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Hauptlogo
|Benötigt
|Logo der Konferenz oder der Organisation, die die Teilnahmebestätigung ausstellt.

|Signatur
|Benötigt
|Bild der Unterschrift der Person, die die Bestätigung unterzeichnet.

|Signaturdatum
|Benötigt
|Datum der Unterschrift. Erwartetes Format: tt/mm/jjjj.

|Signaturname
|Benötigt
|Name der Person, die das Zertifikat signiert.
|===

=== Die Bestätigung senden

Sobald das Formular für die Teilnahmebestätigung ausgefüllt ist, sehen Sie oben rechts eine Schaltfläche "Teilnahmebestätigungen senden".
Mit dieser Schaltfläche können Admins die Bestätigung an alle *bestätigten*
xref:admin:spaces/conferences/registrations/users.adoc[angemeldeten Nutzenden] der Konferenz senden.

image::spaces/conferences/certificates_of_attendance_button.png[Conferences Certificate of Attendance send button]

NOTE: Sobald die Bestätigung gesendet wurde, kann sie nicht erneut gesendet werden.

Die Anwesenheitsbescheinigungen werden den Teilnehmern per E-Mail im PDF-Format zugesandt.

image:spaces/conferences/certificates_of_attendance_pdf.png[Teilnahmebestätigung der Konferenz im Frontend]
