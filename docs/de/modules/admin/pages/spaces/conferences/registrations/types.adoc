= Registrierungsarten

== Die Grundlagen verstehen

Anmeldungen sind eine Besonderheit des Konferenzraums, da sie es Teilnehmenden ermöglichen können, sich für die gesamte Konferenz,
      nur für bestimmte Tage oder zum Beispiel für bestimmte Tracks anzumelden, anstatt sich für jede Veranstaltung einzeln anzumelden.

NOTE: Wenn Sie die Registrierung aktivieren möchten, müssen Sie mindestens einen Registrierungstyp definieren und veröffentlichen.

Admins können diese verschiedenen Arten von "Tickets" im Abschnitt Anmeldungstypen konfigurieren:

. Die Anmeldungstypen definieren
. Anmeldungen aktivieren, sobald sie bereit sind
. Teilnehmende können sich dann anmelden und den passenden Anmeldungstyp wählen

Sobald Anmeldungen aktiviert sind, können Teilnehmende auf eine Schaltfläche klicken, um sich auf der Startseite
      und in der Kopfzeile der Konferenz für die Konferenz anzumelden.

== Konfiguration

=== Anmeldungstypen verwalten

Um auf die Konfiguration der Anmeldungstypen zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Anmeldungstypen".

image::spaces/conferences/registration_types_backend.png[Manage registration types]

=== Aktionen

NOTE: Sobald sich Teilnehmende für einen Anmeldungstyp angemeldet haben, kann dieser weder bearbeitet noch gelöscht werden.

.Aktionen
[cols="10h,20h,~"]
|===
|Icon |Name |Definition

|image:icons/action_edit.png[Symbol: Bearbeiten]
|Bearbeiten
|Um diesen Anmeldungstyp zu bearbeiten.

|image:icons/action_activate.png[Symbol: Vortragende veröffentlichen]
|Veröffentlichen
|Um diesen Anmeldungstyp zu veröffentlichen (wenn er noch nicht veröffentlicht ist)

|image:icons/action_unpublish.png[Symbol: Veröffentlichung von Vortragenden rückgängig machen]
|Zurückziehen
|Um die Veröffentlichung dieses Anmeldungstyps aufzuheben (wenn er veröffentlicht ist)

|image:icons/action_delete.png[Symbol: Löschen]
|Löschen
|Um diesen Anmeldungstyp zu löschen.
|===

=== Neuen Registrierungstyp erstellen

Um einen neuen Anmeldungstyp zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neuer Anmeldungstyp".

image::spaces/conferences/new_registration_type.png[Create a new registration type form]

.Neuen Registrierungstyp erstellen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Der Titel dieses Anmeldungstyps.

|Reihenfolge
|Benötigt
|Welche Reihenfolge er im Verhältnis zu den anderen Typen hat. Eine niedrigere Zahl bedeutet eine höhere Priorität. Wenn Sie zum Beispiel zwei Typen haben, "Tag 1" mit der Gewichtung "10" und "Tag 2" mit der Gewichtung "0", dann steht "Tag 2" bei der Sortierung an erster Stelle.

|Beschreibung
|Benötigt
|Beschreibung für diesen Anmeldungstyp.

|Preis
|Optional
|Legen Sie einen Preis für diesen Registrierungstyp fest. Wenn Sie keinen Preis festlegen, ist er kostenlos.

|Konferenzbesprechungen auswählen
|Optional
|Die Veranstaltungen, zu denen dieser Anmeldungstyp Zugang gewährt.
|===

=== Sich als teilnehmende Person anmelden

Wenn die teilnehmende Person nicht angemeldet ist, kann sie sich beim Klicken auf eine der Schaltflächen "Anmelden" anmelden oder ein Konto erstellen
      und die Anmeldungstypen sehen.

image:spaces/conferences/registration_types_frontend_wo_user.png[Registrierungstyp ohne Benutzerkonto auswählen]

Wenn die teilnehmende Person angemeldet ist, kann sie sich beim Klicken auf eine der Schaltflächen "Anmelden" direkt anmelden.

image::spaces/conferences/registration_types_frontend_w_user.png[Select registration type with user account]

Beim Klicken auf die Schaltfläche Anmelden für einen Anmeldungstyp wird ein Pop-up mit den Anmeldebedingungen
      aus dem Konferenz-Konfigurationsformular angezeigt.

image::spaces/conferences/registration_pop_up.png[Pop up with registration terms]
