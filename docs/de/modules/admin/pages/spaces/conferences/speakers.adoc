= Vortragende

== Die Grundlagen verstehen

Die Vortragenden sind die Personen, die auf der Konferenz sprechen. Sie können mit Veranstaltungen verknüpft werden, sodass Teilnehmende sehen können,
wer bei jedem Programmpunkt sprechen wird.

image::spaces/conferences/speakers_frontend.png[Conferences speakers frontend]

== Konfiguration

=== Vortragende verwalten

Um auf die Konfiguration der Vortragenden zuzugreifen, klicken Sie im sekundären Navigationspanel auf den Punkt "Vortragende".

image:spaces/conferences/speakers.png[Konferenz-Vortragende]

Sie können mithilfe der Suchleiste nach Vortragenden suchen.

=== Aktionen

.Aktionen
[cols="10h,20h,~"]
|===
|Icon |Name |Definition

|image:icons/action_edit.png[Symbol: Vortragende bearbeiten]
|Bearbeiten
|Um diese vortragende Person zu bearbeiten.

|image:icons/action_activate.png[Symbol: Vortragende veröffentlichen]
|Veröffentlichen
|Um diese vortragende Person zu veröffentlichen (wenn sie noch nicht veröffentlicht ist)

|image:icons/action_unpublish.png[Symbol: Veröffentlichung von Vortragenden rückgängig machen]
|Zurückziehen
|Um die Veröffentlichung dieser vortragenden Person aufzuheben (wenn sie veröffentlicht ist)

|image:icons/action_delete.png[Symbol: Vortragende löschen]
|Löschen
|Um diese vortragende Person zu löschen.
|===

=== Neue vortragende Person erstellen

Um eine neue vortragende Person zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neue vortragende Person".

image::spaces/conferences/new_speaker.png[Conferences speakers]

.Neues Formular für Konferenzvortragende
[cols="20h,~,~"]
|===
|Feld |Typ |Beschreibung

|Teilnehmertyp
|Benötigt
|Ob diese vortragende Person keine Teilnehmende oder eine bestehende teilnehmende Person ist. Haben sie bereits ein Konto auf der Plattform erstellt?

|Voller Name
|Erforderlich, wenn es nicht teilnimmt.
|Name der vortragenden Person.

|Benutzer oder Gruppe
|Erforderlich, wenn es sich um eine bereits teilnehmende Person handelt.
|Geben Sie mindestens drei Zeichen für die Suche ein.

|Verwandte Meetings
|Optional
|Die Veranstaltungen, bei denen die vortragende Person spricht oder moderiert.

|Position
|Benötigt
|Metadaten zum Anzeigen zusätzlicher Informationen über die vortragende Person.

|Zugehörigkeit
|Benötigt
|Metadaten zum Anzeigen zusätzlicher Informationen über die vortragende Person.

|Kurze Bio
|Optional
|Metadaten zum Anzeigen zusätzlicher Informationen über die vortragende Person.

|X-Profilname
|Optional
|Metadaten zum Anzeigen zusätzlicher Informationen über die vortragende Person.

|Persönliche URL
|Optional
|Metadaten zum Anzeigen zusätzlicher Informationen über die vortragende Person.

|Avatar
|Optional
|Avatarbild für die vortragende Person. Wird ignoriert, wenn es sich bei der vortragenden Person um eine "Bereits registrierte" teilnehmende Person handelt.
|===
