= Versammlungen

== Die Grundlagen verstehen

Eine Versammlung ist eine Gruppe von Mitgliedern einer Organisation, die regelmässig zusammenkommen, um Entscheidungen über einen bestimmten Bereich oder ein bestimmtes
Thema der Organisation zu treffen.

Versammlungen können Veranstaltungen abhalten, ihre Mitglieder konsultieren und können privat oder für alle offen sein.

Beispiele für Versammlungen sind: eine Generalversammlung, die einmal jährlich zusammentritt, um die Hauptaktionslinien der Organisation sowie ihre
Exekutivorgane per Abstimmung festzulegen, ein Gleichstellungsbeirat, der regelmässig zusammentritt, um Vorschläge zur Verbesserung
der Geschlechterbeziehungen in der Organisation zu erarbeiten, eine Evaluierungskommission, die sich monatlich trifft, um einen Prozess zu überwachen, oder ein Kontrollgremium,
das Vorfälle, Missstände oder Vorschläge zur Verbesserung der Entscheidungsverfahren sammelt.

NOTE: Der Hauptunterschied zwischen xref:admin:spaces/processes.adoc[Beteiligungsprozessen] und Versammlungen ist, dass Versammlungen keine
Phasen haben, was bedeutet, dass sie keine Zeitachsen haben.

=== Wie findet man sie?

Um auf das Versammlungen-Panel zuzugreifen, gehen Sie zum Verwaltungspanel und klicken Sie in der Verwaltungs-
Navigationsleiste auf den Punkt "Versammlungen".

image::spaces/assemblies/assemblies_menu.png[Pages: Access assemblies panel]

Dort können Sie Versammlungen und Versammlungstypen verwalten.

== Konfiguration

=== Versammlungen verwalten

image::spaces/assemblies/assemblies_list.png[Assemblies list]

Auf dieser Seite können Sie Versammlungen und xref:admin:spaces/processes/groups.adoc[Versammlungstypen] verwalten.
Sie finden alle Versammlungen in der Liste im Verwaltungspanel mit:

* *Titel*: Titel der Versammlung.
* *Erstellt am*: Erstellungsdatum der Versammlung.
* *Privat*: ob die Versammlung für alle Teilnehmenden oder nur für bestimmte Teilnehmende geöffnet ist.
* *Veröffentlicht*: ob die Versammlung veröffentlicht ist oder nicht.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Versammlungen anhand ihres Titels suchen.

image::spaces/assemblies/assemblies_list_filter.png[Assemblies list filtered]

=== Eine Versammlung importieren

Um eine Versammlung zu importieren, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Verwalten".

image::spaces/assemblies/import_menu.png[Assemblies import menu]

Sie werden auf die Importseite weitergeleitet, auf der Sie folgende Felder ausfüllen müssen:

* Titel: Der Titel, den Sie der Versammlung geben möchten.
* URL-Kennung: Der „Slug“ für die Versammlung.
* Dokument hinzufügen: Hier müssen Sie die JSON-Datei der Versammlung hochladen, die Sie beim Exportieren per E-Mail erhalten haben.

Anschliessend können Sie auswählen, welche Art von Daten Sie aus der Datei importieren möchten.

* Kategorien importieren: Importiert alle in der Originaldatei vorhandenen Kategorien.
* Anhänge importieren: Importiert die Anhänge der ursprünglichen Versammlung.
* Komponenten importieren: Importiert alle Komponenten und ihre Konfiguration aus der Originaldatei, ohne deren Inhalt zu importieren.
