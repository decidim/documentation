= Erste Schritte in Decidim

== Die Grundlagen verstehen

=== Erstmalig anmelden

Sobald Sie oder Ihre Entwickelnden Decidim erfolgreich installiert und eine Organisation im Systempanel erstellt haben, sollten Sie
      eine E-Mail erhalten, in der Sie gebeten werden, Ihre Kontoerstellung abzuschliessen.
Falls Sie keine Einladungs-E-Mail erhalten haben, bitten Sie die für die Systemverwaltung zuständige Person, Sie als Admin hinzuzufügen.

image::first_steps_invitation_email.png[Administrator invitation email]

Die Einladungs-E-Mail leitet Sie zu einem Formular weiter, in dem Sie die Einrichtung Ihres Kontos mit Spitzname, Name und Passwort abschliessen können.

image::first_steps_account_creation.png[Administrator invitation email]

=== Auf das Verwaltungs-Dashboard zugreifen

Nach der Anmeldung sehen Sie die Plattform als teilnehmende Person, aber dort können Sie die Plattform nicht konfigurieren und verwalten.
Um auf das Verwaltungs-Dashboard bzw. das Verwaltungspanel zuzugreifen, können Sie auf drei verschiedene Elemente klicken:

. Die Schaltfläche "Admin-Dashboard" links in der Admin-Kopfzeile, die nur Admins sehen können.
. Die Schaltfläche "Bearbeiten" rechts in der Admin-Kopfzeile.
. Die Schaltfläche "Admin-Dashboard" in der Dropdown-Liste, die erscheint, wenn Sie auf Ihren Kontoavatar klicken.

image::admin_dashboard_menu.png[Decidim Admin Dashboard in user menu]

Die Schaltfläche "Bearbeiten" leitet Sie zur Verwaltung des Raums weiter, den Sie gerade im Teilnehmenden-Panel sehen, während die beiden anderen Schaltflächen
      zum Verwaltungs-Dashboard weiterleiten.

=== Nutzungsbedingungen für Admins

Wenn Sie zum ersten Mal auf die Verwaltung von Decidim zugreifen, werden Sie gebeten, die Nutzungsbedingungen für die Verwaltung zu prüfen.
Klicken Sie auf die Schaltfläche "Ich stimme diesen Bedingungen zu", um mit der Konfiguration der Plattform beginnen zu können.

image::admin_tos_pending.png[Decidim Admin Dashboard in user menu]

Diese Nutzungsbedingungen können nützlich sein, wenn Sie beginnen, weitere Admins auf die Plattform einzuladen, und diese über bestimmte
      Datenschutzregeln oder andere für sie relevante Punkte informiert sein sollen, bevor sie Zugriff auf die Verwaltung erhalten.

Diese Nutzungsbedingungen können im xref:admin:settings/configuration.adoc[Konfigurationspanel] konfiguriert werden.

=== Erklärung des Dashboards

Sobald Sie die Nutzungsbedingungen für Admins akzeptiert haben, können Sie das Dashboard sehen.
Bei einer neuen Instanz werden fast keine Daten angezeigt, aber Sie können sehen, wie es bei einer aktiven Instanz aussieht:

image::admin_dashboard.png[Decidim Admin Dashboard]

Auf dieser Seite sehen Sie mehrere Abschnitte:

. *Ausstehende Moderationen*: hebt die Anzahl der ausstehenden Moderationen, gemeldeten Teilnehmenden und Inhalte zusammen hervor.
. *Aktivität*: Anzahl der Teilnehmenden und Admins, die sich im letzten Monat, in der letzten Woche und am letzten Tag angemeldet haben.
. *Metriken*: die Grafiken zur Entwicklung mehrerer Komponenten innerhalb von Decidim:
. *Admin-Protokoll*: die letzten Aktionen, die von allen Admins auf der Plattform durchgeführt wurden.
