= Themen

== Die Grundlagen verstehen

In diesem Abschnitt können Sie Themen konfigurieren, um die statischen Seiten zu organisieren und den Teilnehmenden mehr Klarheit zu bieten.

== Konfiguration

=== Die Themen verwalten

Um auf die Themenliste zuzugreifen, klicken Sie auf den Tab Themen oben im Panel.
Hier können Sie Themen für Ihre statischen Seiten bearbeiten, löschen und erstellen.

image::pages/pages_backend_list_topics.png[Backend: list topics of pages]

=== Neues Thema erstellen

Um ein neues Thema zu erstellen, klicken Sie auf die Schaltfläche "Thema erstellen".

image::pages/pages_backend_topic_form.png[Backend: new topic form]

.Neues Themen-Formular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Titel dieses Themas. Zum Beispiel: "Hilfe"

|Beschreibung
|Optional
|Worum geht es bei diesem Thema.

|Reihenfolge
|Optional
|Die Reihenfolge des Themas im Verhältnis zu den anderen Themen. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Wenn Sie zum Beispiel zwei Themen haben, "Thema a" mit der Gewichtung "10" und "Thema b" mit der Gewichtung "0", dann steht "Thema b" bei der Sortierung an erster Stelle.

|Im Footer anzeigen
|Optional
|Ob Sie dieses Thema im Abschnitt "Hilfe" der allgemeinen Fusszeile anzeigen möchten (auf jeder Seite zugänglich).
|===
