= Projekte

== Die Grundlagen verstehen

Projekte sind Teile von Budgets.

== Konfiguration

=== Ein Projekt erstellen

Um auf die Erstellung und Verwaltung von Projekten zuzugreifen, klicken Sie auf den Titel des Budgets oder auf das Symbol
      image:icons/action_list.png[Symbol: Projekte verwalten] in der Budgetliste.

image::components/budgets/new_project_button.png[New project button]

Klicken Sie dann oben rechts auf der Seite auf die Schaltfläche "Neues Projekt".

image::components/budgets/new_project.png[New project form]

.Neues Projektformular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Der Titel für dieses Projekt.

|Beschreibung
|Benötigt
|Eine Beschreibung dessen, worum es bei diesem Projekt geht.

|Budgetbetrag
|Benötigt
|Wie hoch ist der Budgetbetrag für dieses Projekt. Wie viel Geld kostet die Umsetzung dieses Projekts?

|Adresse
|Optional
|Die Adresse des Projekts. Dies ermöglicht die Anzeige einer Stecknadel auf einer Karte, damit Teilnehmende das Projekt lokalisieren können.

|Kategorie
|Optional
|Welche Kategorie dem Projekt zugewiesen ist. Wird zum Filtern in der Budgetliste verwendet.

|Vorschläge
|Optional
|Wählen Sie verwandte Vorschläge für dieses Projekt. Wird beim Importieren von Vorschlägen automatisch zugewiesen.

|Bildergalerie hinzufügen
|Optional
|Fügen Sie mehrere Bilder hinzu, die veranschaulichen, worum es bei diesem Projekt geht, wie Entwürfe usw.
|===

=== Projekte verwalten

image::components/budgets/results_selected.png[Selected projects after voting]

In der Projektliste im Verwaltungspanel können Admins Folgendes sehen:

* *ID*: Identifikationsnummer für dieses Projekt.
* *Titel*: Titel des Projekts.
* *Kategorie*: Kategorie des Projekts.
* *Thema*: Thema des Projekts, sofern im partizipativen Raum aktiviert.
* *Anzahl Stimmen*: Anzahl der Stimmen für dieses Projekt.
* *Ausgewählt*: Ob das Projekt am Ende des Prozesses zur Umsetzung ausgewählt wurde.
* *Karte*: Standort des Projekts, wenn es eine Adresse hat.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können in der Suchleiste auch nach Projekten anhand ihrer ID und ihres Titels suchen.

image::components/budgets/projects_list_filter.png[Projects list filter]

=== Vorschläge in Projekte importieren

Je nach Normativ könnten Sie eine erste Phase haben, in der Teilnehmende
Vorschläge machen, und diese Vorschläge werden ausgewählt (durch Abstimmung oder durch technische Überprüfung),
dann können Sie diese Vorschläge importieren und in Projekte umwandeln.

Damit dies funktioniert:

. Die folgenden Einstellungen in der Vorschlags-Komponente müssen aktiviert sein:
.. Vorschlagsantwort aktiviert
.. Kosten bei Vorschlagsantworten aktivieren
. Eine bewertende Person oder ein Admin muss Vorschläge beantworten:
.. Vorschläge ansehen
.. Akzeptieren oder ablehnen Sie sie entsprechend Ihrer Normativen
.. Kosten zu den Vorschlägen hinzufügen, wenn angenommen wurde
. Ein Administrator kann Vorschläge in Projekte importieren

image:components/budgets/import_proposals.png[Vorschläge in Projekte importieren]
