= Budget

== Die Grundlagen verstehen

Es ist wichtig zu verstehen, dass Budget nicht nur der Name der Komponente ist, sondern auch eine Entität der Komponente.
Tatsächlich kann ein und dieselbe Budget-Komponente mehrere Budgets enthalten.

image::components/budgets/multiple_budgets_front.png[Budgets list in frontend]

Dies ermöglicht es, komplexe Abläufe zu erstellen und mehrere Anwendungsfälle abzudecken.

== Konfiguration

Sobald Sie Ihre Budget-Komponente erstellt haben, werden Sie zur Budgetliste weitergeleitet. Dort können Sie die Budgets
      Ihrer Komponente erstellen und verwalten. Je nachdem, welchen Prozess Sie organisieren möchten, können Sie wählen:

* Ein einziges Budget zu erstellen, in dem alle Ihre zur Abstimmung stehenden Projekte angezeigt werden.
* Mehrere Budgets zu erstellen, mit jeweils eigenen Projekten darin.

Als Erstes erstellen Sie Ihr erstes Budget, indem Sie auf die Schaltfläche "Neues Budget" klicken.

image::components/budgets/new_budget_button.png[New budget button]

=== Budgeterstellung

image::components/budgets/new_budget.png[New budget form]

.Neues Budgetformular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Wie lautet der Titel dieses Budgets. Zum Beispiel "Bezirk A"

|Reihenfolge
|Optional
|Welche Reihenfolge es im Verhältnis zu den anderen Budgets hat. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Wenn Sie zum Beispiel zwei Budgets haben, "Budget a" mit der Gewichtung "10" und "Budget b" mit der Gewichtung "0", dann steht "Budget b" bei der Sortierung an erster Stelle.

|Beschreibung
|Optional
|Die Beschreibung dieses Budgets, die Teilnehmenden nur angezeigt wird, wenn es mehrere Budgets gibt.

|Gesamt Budget
|Benötigt
|Der für dieses Budget insgesamt verfügbare Geldbetrag.
|===

=== Budgets verwalten

image::components/budgets/manage_budgets.png[Manage budgets table]

In der Budgetliste im Verwaltungspanel können Admins Folgendes sehen:

* *Name*: Name des Budgets.
* *Gesamtbudget*: Das dem Budget insgesamt zugewiesene Budget.
* *Anzahl Projekte*: Die Anzahl der in jedem Budget enthaltenen Projekte.

Auf dieser Seite können Sie ausserdem die abgeschlossenen und ausstehenden Stimmen einsehen, die die verschiedenen Projekte über alle Budgets hinweg erhalten haben.

Sie können auch alle Projekte der Komponente in verschiedenen Formaten exportieren: CSV, JSON und Excel.

=== Workflows

Ein nettes Feature der Budget-Komponente ist die Möglichkeit, eigene Workflows zu definieren.

Das bedeutet, dass Sie mehrere Budgets definieren können, zum Beispiel eines für jeden Stadtteil oder Bezirk, und mehrere
      Regeln dazu festlegen können, wie Personen über diese Budgets abstimmen können. Standardmässig sind drei Workflows verfügbar:

* Stimmen Sie in einem: ermöglicht den Teilnehmenden die Abstimmung in jedem Budget, aber nur in einem.
* Stimmen Sie in allen: Erlaubt den Teilnehmenden, in allen Budgets abzustimmen.
* Stimmen Sie in einer zufälligen Komponente: Erlaubt den Teilnehmenden, nur in einem zufällig ausgewählten Budget abzustimmen.

Dies kann in Ihrer Anwendung von einer entwickelnden Person erweitert werden, indem eigene Workflows entwickelt werden. Zum Beispiel für die
https://www.decidim. arcelona/processes/PressupostosParticipatius[2020/2021 partizipatorische Budgetverfahren in Decidim Barcelona],
die Menschen konnten in zwei Bezirken wählen: in dem Bezirk, in dem sie lebten und in dem sie sich entschieden haben. Dies wurde in der
https://github.com/AjuntamentdeBarcelona/decidim-barcelona/blob/743be2a210e8745d2dc443166642b285aed2b356/lib/budgets_workflow_pam2021.rb[decidim-barcelona Applikation] definiert.

Weitere Informationen zu Workflows finden Sie in der https://github.com/decidim/decidim/blob/1ab5cd8fdabef48f5be94ff9c30c6bb3bc9a2f8f/decidim-budgets/README.md#budget-workflows[decidim-budgets README.md].

NOTE: Sie möchten nur eine Abstimmung ohne grosse Komplikationen haben? Wie eine städtische Abstimmung? Keine Sorge: Wenn Sie nur ein
      Budget definieren, werden Personen direkt zur Projektliste weitergeleitet.
