= Vorschläge

== Die Grundlagen verstehen

Die Vorschläge-Komponente ermöglicht es Personen, Vorschläge zu erstellen, zu kommentieren, mit Gefällt mir zu markieren und für sie abzustimmen. Sie ist eine der Hauptkomponenten von
Decidim und verfügt über eine grosse Anzahl an Konfigurationseinstellungen.

image::components/proposals/example01.png[Proposals example]

In diesem Dokumentationsabschnitt erfahren Sie, wie Sie all diese Einstellungen konfigurieren und verwalten:

* xref:admin:components/proposals/proposals.adoc[Vorschlagsverwaltung]
* xref:admin:components/proposals/answers.adoc[Antworten]
* xref:admin:components/proposals/special_configurations.adoc[Spezifische Vorschlagskonfigurationen]
** xref:admin:components/proposals/special_configurations/amendments.adoc[Änderungsanträge]
** xref:admin:components/proposals/special_configurations/collaborative_drafts.adoc[Kollaborative Entwürfe]
** xref:admin:components/proposals/special_configurations/participatory_texts.adoc[Partizipative Texte]

== Konfiguration

Um eine Vorschläge-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/proposals/component_proposals.png[Add Proposals component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Vorschläge"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

Das Formular zur Komponentenerstellung ist in verschiedene Abschnitte unterteilt, die im Folgenden näher beschrieben werden.

image::components/proposals/component_01.png[Add component form]

.Komponente hinzufügen: Vorschlagsformular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Der Titel dieser Komponente.

|Reihenfolge
|Optional
|Die Reihenfolge der Komponente im Verhältnis zu den anderen Komponenten. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Wenn Sie beispielsweise zwei Komponenten haben, "Komponente a" mit der Gewichtung "10" und "Komponente b" mit der Gewichtung "0",
steht "Komponente b" bei der Sortierung an erster Stelle.
|===

image::components/proposals/component_02.png[Add component form]

.Komponente hinzufügen: Vorschlagsformular - Globale Einstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Themen aktiviert
|Optional
|Aktivieren, wenn die Themenfilterung in dieser Komponente erfolgen soll.

|Themen aktiviert
|Optional
|Aktivieren Sie dies, wenn Sie die Filterung nach Themen in dieser Komponente verfügbar haben möchten.

|Thema
|Optional
|Zu welchem xref:admin:settings/scopes.adoc[Thema] diese Komponente gehört.

|Abstimmungslimit pro teilnehmender Person
|Optional
|Muss eine Zahl sein. Die maximale Anzahl an Stimmen, die eine teilnehmende Person Vorschlägen geben kann.

|Mindestanzahl an Stimmen pro Nutzendem
|Optional
|Muss eine Zahl sein. Die Mindestanzahl an Stimmen, die eine teilnehmende Person Vorschlägen geben muss, damit ihre Stimmen berücksichtigt werden.

|Vorschlagslimit pro teilnehmender Person
|Optional
|Muss eine Zahl sein. Wie viele Vorschläge eine teilnehmende Person in dieser Komponente erstellen kann.

|Maximale Länge des Vorschlagskörpers
|Optional
|Muss eine Zahl sein. Wie viele Zeichen der Vorschlagskörper maximal haben kann.

|Bearbeitung von Vorschlägen
|Benötigt
|Wählen Sie, ob Teilnehmende nur begrenzt Zeit haben, ihre Vorschläge zu bearbeiten, oder ob sie diese unbegrenzt bearbeiten können.
Falls dies innerhalb eines bestimmten Zeitraums liegen soll, müssen Sie die Zeit im untenstehenden Feld angeben.
Beachten Sie, dass ein Vorschlag nicht mehr bearbeitet werden kann, sobald ein Admin xref:components/proposals/answers.adoc[ihn beantwortet].

|Vorschläge können von Autoren bearbeitet werden, bevor diese Minuten vergangen sind
|Benötigt
|Muss eine Zahl sein. Wie viele Minuten nach der Erstellung eines Vorschlags kann er von seinem Autor bearbeitet werden.

|Schwellenwert pro Vorschlag
|Optional
|Muss eine Zahl sein. Wie viele Stimmen ein Vorschlag benötigt, um als angenommen zu gelten.

|Kann Stimmen über den Schwellenwert hinaus ansammeln
|Optional.
|Ob der Vorschlag mehr Stimmen ansammeln kann als der Schwellenwert.

|Vorschlagsantwort aktiviert
|Optional
|Ob Admins oder Bewertende Vorschläge beantworten können.

|Standardsortierung der Vorschläge
|Optional
|Die Sortierreihenfolge der Vorschläge in der Vorschlagsliste. Automatisch bedeutet, dass die Vorschläge zufällig sortiert angezeigt werden, wenn die Abstimmung aktiviert ist,
und nach den meisten Stimmen sortiert, wenn die Abstimmung gesperrt ist.

|Offizielle Vorschläge aktiviert
|Optional
|Ob Admins offizielle Vorschläge über das Verwaltungspanel erstellen können.

|Kommentare aktiviert
|Optional
|Ob Sie Teilnehmenden erlauben möchten, die Vorschläge zu kommentieren.

|Maximale Länge der Kommentare
|Optional
|Das Zeichenlimit, das Teilnehmenden beim Verfassen von Kommentaren zur Verfügung steht. Lassen Sie 0 für den Standardwert.

|Geocoding aktiviert
|Optional
|Ob Teilnehmende eine Geokodierungsadresse für ihre Vorschläge angeben können.
Sie müssen xref:configure:geocoding[Geokodierung] aktiviert haben.

|Anhänge erlauben
|Optional
|Aktivieren, um den Teilnehmenden zu erlauben, Dateien an ihre Vorschläge anzuhängen. Wenn Sie diese Option aktivieren, werden Vorschläge standardmässig in der Rasteransicht angezeigt,
und das erste Bild erscheint auf der Karte.

|Aktionsberechtigungen können für jeden Vorschlag festgelegt werden
|Optional
|Ob Sie in der Lage sein möchten, Berechtigungen für jeden Vorschlag festzulegen.

|Gemeinschaftliche Entwürfe aktiviert
|Optional
|Aktivieren, um xref:components/proposals/special_configurations/collaborative_drafts.adoc[kollaborative Entwürfe] bei Vorschlägen zu aktivieren.

|Partizipative Texte aktiviert
|Optional
|Aktivieren, um xref:components/proposals/special_configurations/participatory_texts.adoc[partizipative Texte] bei Vorschlägen zu aktivieren.

|Änderungsanträge aktiviert
|Optional
|Aktivieren, um xref:components/proposals/special_configurations/amendments.adoc[Änderungsanträge] bei Vorschlägen zu aktivieren.
Falls aktiviert, konfigurieren Sie die Einstellungen für Änderungsanträge für jede Phase.

|Hilfetext für den Änderungsantrags-Assistenten
|Optional.
|Der Hilfetext, der beim Erstellen neuer Änderungsanträge sichtbar ist.

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die auf der Vorschlagslisten-Seite sichtbar ist.

|Neue Vorlage für Vorschlagskörper
|Optional
|Ein vordefinierter Text, der beim Erstellen neuer Vorschläge verwendet wird. Nützlich, wenn Sie ein Format definieren möchten, das Teilnehmende beim Erstellen neuer Vorschläge
einhalten müssen.

|Neuer Hilfetext für Vorschläge
|Optional
|Der Hilfetext, der beim Erstellen neuer Vorschläge sichtbar ist.

|Hilfetext für den Schritt "Erstellen" des Vorschlagsassistenten
|Optional
|Der Hilfetext, der beim Erstellen neuer Vorschläge im Schritt "Erstellen" sichtbar ist.

|Hilfetext für den Schritt "Veröffentlichen" des Vorschlagsassistenten
|Optional
|Der Hilfetext, der beim Erstellen neuer Vorschläge im Schritt "Veröffentlichen" sichtbar ist.
|===

image::components/proposals/component_03.png[Add component form]

.Komponente hinzufügen: Vorschlagsformular - Schritteinstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Unterstützungen aktiviert
|Optional
|Um Teilnehmenden zu ermöglichen, mit einer Schaltfläche "Gefällt mir" öffentlich Unterstützung für diese Vorschläge zu zeigen.

|Unterstützungen blockiert
|Optional
|Aktivieren Sie dies, damit Teilnehmende die bestehenden Unterstützungen sehen, aber keine neuen abgeben können.

|Abstimmung aktiviert
|Optional
|Um Teilnehmenden zu ermöglichen, in dieser Phase für Vorschläge abzustimmen.

|Abstimmung gesperrt
|Optional
|Aktivieren, damit Teilnehmende die bestehenden Stimmen sehen, aber keine neuen abgeben können.

|Stimmen ausgeblendet
|Optional
|Wenn die Abstimmung aktiviert ist, wird durch Aktivieren dieser Option die Anzahl der Stimmen vor Teilnehmenden verborgen.

|Kommentare blockiert
|Optional
|Ob Sie Kommentare für diese Phase aktivieren möchten.

|Teilnehmende können Vorschläge erstellen
|Optional
|Ob Sie die Erstellung von Vorschlägen durch Teilnehmende für diese Phase aktivieren möchten.

|Vorschlagsantwort aktiviert
|Optional
|Ob Sie xref:components/proposals/answers.adoc[das Beantworten von Vorschlägen] durch Admins aktivieren möchten.

|Vorschlagsantworten sofort veröffentlichen
|Optional
|Ob die Antworten zu Vorschlägen direkt veröffentlicht werden sollen, wenn Admins sie
xref:components/proposals/answers.adoc[beantworten], oder ob Sie selbst steuern möchten, wann die Antworten veröffentlicht werden.

|Kosten bei Vorschlagsantworten aktivieren
|Optional
|Ob Sie den Antworten auf Vorschläge wirtschaftliche Kosten hinzufügen möchten. Nützlich für den Import von Vorschlägen in xref:components/budgets.adoc[Budgets].

|Standardsortierung der Vorschläge
|Optional
|Die Sortierreihenfolge der Vorschläge in der Vorschlagsliste für diese Phase. Automatisch bedeutet, dass die Vorschläge zufällig sortiert
angezeigt werden, wenn die Abstimmung aktiviert ist, und nach den meisten Stimmen sortiert, wenn die Abstimmung gesperrt ist.

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die auf der Vorschlagslisten-Seite für diese Phase sichtbar ist.

|Hashtags zu allen Vorschlägen hinzugefügt
|Optional
|Fügt automatisch Hashtags zu jedem Vorschlag hinzu.

|Den Teilnehmenden für neue Vorschläge vorgeschlagene Hashtags
|Optional
|Schlägt Teilnehmenden, die neue Vorschläge erstellen, Hashtags vor. Teilnehmende können mehrere Hashtags auswählen.
|===
