Um die Skelett-Komponente zu konfigurieren:

. Als Admin anmelden
. Zum Admin-Panel wechseln
. Wählen Sie in der Haupt-Seitenleiste den Bereich aus, unter dem Sie die Komponente konfigurieren möchten.
Zum Beispiel "Prozesse", "Gremien" oder "Konferenzen".
. Gehe zu Komponenten
. Auf "Komponente hinzufügen"-Button klicken
. Klicken Sie auf "Skelett"
. Das Formular xref:_add_component[Komponente hinzufügen] ausfüllen

== Komponente hinzufügen

image:components/skeleton/component.png[Komponentenform] hinzufügen


.Komponente hinzufügen: Skelett Formular
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Wie lautet der Titel dieser Komponente. Zum Beispiel "Skelette"

|Bestellposition
|Optional
|Welche Reihenfolge wird es in Bezug auf die anderen Skelette haben. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Zum Beispiel, wenn Sie zwei Skelette haben, "Skelett" mit Gewicht "10" und "Skelett b" mit Gewicht "0", dann ist "Skeleton b" zuerst bei der Bestellung.
|===


.Komponente hinzufügen: Skelett-Formular - Globale Einstellungen
|===
|Feld |Typ |Beschreibung

|Bereiche aktiviert
|Optional
|Aktivieren, wenn die Bereichsfilterung in dieser Komponente erfolgen soll.

|Bereich
|Optional
|Zu welcher xref:admin:scopes.adoc[Scope] diese Komponente gehört.

|Globaler Umfang
|Optional
|

|Kommentare aktiviert
|Optional
|Ob Sie Kommentare in den Meetings haben möchten.

|Maximale Länge der Kommentare
|Optional
|Welche Zeichenbegrenzung haben die Teilnehmer, wenn sie Kommentare abgeben. Lassen Sie 0 für den Standardwert.

|Aktionsberechtigungen können für jedes Skelett festgelegt werden
|Optional
|Ob Sie Berechtigungen für jedes Skelett festlegen möchten. Meistens möchten Sie diese Option deaktiviert lassen.

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die auf der Landungsseite der Skelette zu sehen sein wird.
|===

== Berechtigungen

Ein Administrator kann wählen, welche Art von xref:customize:authorizations.adoc[Authorizations] ein Teilnehmer muss
bestimmte Aktionen in den Skeletten machen:

* Anlegen
* Befürwortung
