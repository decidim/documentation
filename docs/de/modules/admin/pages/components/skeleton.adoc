== Konfiguration

Um eine Blog-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/skeleton/component_skeleton.png[Add component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Skeleton" aus
. Füllen Sie das Formular zur Komponentenerstellung aus

image:components/skeleton/component.png[Komponentenformular hinzufügen]


.Komponente hinzufügen: Skelett Formular
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Wie lautet der Titel dieser Komponente. Zum Beispiel "Skelette"

|Reihenfolge
|Optional
|Welche Reihenfolge es im Verhältnis zu den anderen Skeletons hat. Eine niedrigere Zahl bedeutet eine höhere Priorität.
|===


.Komponente hinzufügen: Skelett-Formular - Globale Einstellungen
|===
|Feld |Typ |Beschreibung

|Themen aktiviert
|Optional
|Aktivieren, wenn die Themenfilterung in dieser Komponente erfolgen soll.

|Thema
|Optional
|Zu welchem xref:admin:settings/scopes.adoc[Thema] diese Komponente gehört.

|Globales Thema
|Optional
|

|Kommentare aktiviert
|Optional
|Ob Sie Kommentare in den Meetings haben möchten.

|Maximale Länge der Kommentare
|Optional
|Was ist das Zeichenlimit, das Teilnehmende beim Verfassen von Kommentaren haben. Lassen Sie 0 für den Standardwert.

|Aktionsberechtigungen können für jedes Skelett festgelegt werden
|Optional
|Ob Sie Berechtigungen für jedes Skelett festlegen möchten.

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die auf der Landungsseite der Skelette zu sehen sein wird.
|===

=== Alle exportieren

Ermöglicht das Exportieren der Skelette in verschiedenen Formaten.

* Skelette als CSV
* Skelette als JSON
* Skelette als Excel
* Kommentare als CSV
* Kommentare als JSON
* Kommentare als Excel
