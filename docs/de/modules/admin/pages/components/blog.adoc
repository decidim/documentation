= Blog

== Die Grundlagen verstehen

Die Blog-Komponente ermöglicht es Admins, Neuigkeiten zu einem partizipativen Raum zu veröffentlichen, die Teilnehmende lesen können, um auf dem Laufenden zu bleiben.

image::components/blog/example01.png[Example of blog posts list]

Alle Blogbeiträge sind in der Beitragsliste verfügbar, und Teilnehmende können auf jeden Blogbeitrag klicken, um mehr über die Neuigkeiten zu erfahren.

image::components/blog/example02.png[Example of a blog post]

== Konfiguration

=== Eine Blog-Komponente erstellen

Um eine Blog-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/blog/component_blog.png[Add Blog component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Blog"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
      image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

image::components/blog/component.png[Add component form]

.Komponente hinzufügen: Blog Formular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Der Titel dieser Komponente. Zum Beispiel "Blogs" oder "Neuigkeiten"

|Reihenfolge
|Optional
|Welche Reihenfolge sie im Verhältnis zu den anderen Komponenten hat. Eine niedrigere Zahl bedeutet eine höhere Priorität.
|===

.Blogformular - Globale Einstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die auf der Startseite der Blog-Komponente sichtbar ist.

|Kommentare aktiviert
|Optional
|Wenn Teilnehmende die Blogbeiträge kommentieren können sollen.

|Maximale Länge der Kommentare
|Optional
|Das Zeichenlimit, das Teilnehmenden beim Verfassen von Kommentaren zur Verfügung steht. Lassen Sie 0 für den Standardwert.
|===

.Schritteinstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die auf der allgemeinen Startseite des Blogs sichtbar sein wird.

|Kommentare blockiert
|Optional
|Ob Sie das Erstellen von Kommentaren für diese Phase aktivieren möchten.

|Unterstützungen aktiviert
|Optional
|Ob Sie Bestätigungen für diese Phase aktivieren möchten.

|Unterstützungen blockiert
|Optional
|Ob Sie das Hinzufügen neuer Unterstützungen für diese Phase aktivieren möchten.
|===

=== Beiträge verwalten

Um mit dem Erstellen und Verwalten von Beiträgen zu beginnen, klicken Sie auf den Komponententitel in der Navigationsleiste oder in der Komponentenliste, oder klicken Sie auf das
      image:icons/action_edit.png[Symbol: Komponente verwalten] Verwalten-Symbol in der Komponentenliste.

image:components/blog/manage_posts.png[Beitragstabelle verwalten]

=== Einen Beitrag erstellen

Um einen Beitrag zu erstellen, klicken Sie oben rechts auf der Seite auf die Schaltfläche "Neuer Beitrag".

image:components/blog/new_post.png[Neues Beitragsformular]

.Neues Beitragsformular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Urheberschaft
|Benötigt
|Teilnehmendenkonto oder Benutzergruppe, die den Beitrag verfasst hat.

|Titel
|Benötigt
|Was ist der Titel dieses Beitrags.

|Körper
|Benötigt
|Was ist die Beschreibung dieses Beitrags.

|Veröffentlichungszeitpunkt
|Optional
|Veröffentlichungsdatum des Beitrags. Falls dieses Datum in der Zukunft liegt, wird der Beitrag erst zu diesem Zeitpunkt veröffentlicht.
|===

=== Aktionen

.Aktionen
[cols="10h,20h,~"]
|===
|Icon |Name |Definition

|image:icons/action_edit.png[Symbol: Bearbeiten]
|Bearbeiten
|Diesen Beitrag bearbeiten.

|image:icons/action_folder.png[Symbol: Ordner]
|Ordner
|Zum Klassifizieren von Anhängen.

|image:icons/action_attachments.png[Symbol: Anhänge]
|Anhänge
|Dokumente hinzufügen, die sich auf den Beitrag beziehen.

|image:icons/action_preview.png[Symbol: Vorschau]
|Vorschau
|Sehen Sie, wie er Teilnehmenden im Frontend angezeigt wird.

|image:icons/action_permissions.png[Symbol: Berechtigungen]
|Berechtigungen
|Verwalten Sie die Berechtigungen, die zum Kommentieren oder Unterstützen dieses spezifischen Blogbeitrags erforderlich sind.

|image:icons/action_delete.png[Symbol: Löschen]
|Löschen
|Diesen Beitrag löschen.
|===
