= Auslosungen

== Die Grundlagen verstehen

Die Komponente Auslosung ermöglicht es, eine Anzahl von Vorschlägen mit zufälligen, aber reproduzierbaren Verfahren auszulosen, die eine unverzerrte
und gleichmässige Verteilung garantieren.

Sie kann beispielsweise nützlich sein, um Kandidierende für eine Jury auszulosen oder Vorschläge für ein partizipatives Budget.

Um eine Auslosung durchzuführen, benötigen Sie einen Würfel oder eine andere zufällige Methode, um eine Zahl von 1 bis 6 zu erzeugen, sowie Zeugen.

== Konfiguration

Um eine Auslosungs-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/sortitions/component_sortitions.png[Add Sortitions component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Auslosung"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

image::components/sortitions/component.png[Add component form]

=== Eine Auslosung erstellen

image::components/sortitions/new_sortition_backend.png[New sortition backend form]

.Formular für neue Auslosung
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Der Titel dieser Auslosung.

|Vorschlagsmenge
|Benötigt
|Die Vorschläge-Komponente, auf der die Auslosung basiert. Beide Komponenten müssen sich im selben Raum befinden.

|Kategorien der Vorschlagsmenge, auf die Sie die Auslosung anwenden möchten
|Optional
|Falls Sie Kategorien haben, kann dies die Auslosung auf nur eine der Kategorien beschränken.

|Anzahl der auszuwählenden Vorschläge
|Benötigt
|Geben Sie an, wie viele Vorschläge aus der zuvor ausgewählten Vorschlagsgruppe per Losverfahren ausgewählt werden sollen.

|Zeugen
|Benötigt
|Die Zeugen, die bei der Auslosung anwesend sind und deren Echtheit bestätigen können.

|Informationen zur Auslosung
|Benötigt
|Erklärung, warum die Auslosung durchgeführt wird.

|Ergebnis des Würfelwurfs
|Benötigt
|Werfen Sie einen sechsseitigen Würfel oder suchen Sie nach einer anderen zufälligen Methode, um eine Zahl von 1 bis 6 zu erzeugen, und geben Sie hier die resultierende
Zahl im Beisein von Zeugen ein. Dies trägt zur Qualität und zu den Garantien der Zufälligkeit des Ergebnisses bei.
|===

=== Auslosungen verwalten

Um mit der Erstellung und Verwaltung von Auslosungen zu beginnen, klicken Sie auf den Komponententitel in der Navigationsleiste oder in der Komponentenliste, oder klicken Sie auf das
image:icons/action_edit.png[Symbol: Komponente verwalten] Verwalten-Symbol in der Komponentenliste.

image::components/sortitions/manage_sortitions.png[Manage sortitions table]

In der Auslosungsliste im Verwaltungspanel können Admins Folgendes sehen:

* *Referenz*: Referenz der Auslosung.
* *Titel*: Titel der Auslosung.
* *Erstellungsdatum*: Erstellungsdatum der Auslosung.
