= Seiten

== Die Grundlagen verstehen

Die Seitenkomponente erlaubt es den Menschen, Informationen über einen Raum zu erhalten. Admins können eine Seite mit informativen Inhalten,
Bildern und Links füllen, um Teilnehmende zu informieren und auf dem Laufenden zu halten.

Dies ähnelt den allgemeinen xref:admin:pages.adoc[Seiten], wobei der Hauptunterschied darin besteht, dass diese Komponente es ermöglicht, Seiten innerhalb
eines partizipativen Raums zu definieren und nicht im Hilfebereich.

== Konfiguration

=== Eine Seiten-Komponente erstellen

Um eine Seiten-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/page/component_page.png[Add Page component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Seite"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
      image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

image::components/page/component.png[Add component form]

.Komponente hinzufügen: Seitenformular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Der Titel dieser Komponente.

|Reihenfolge
|Optional
|Die Reihenfolge der Komponente im Verhältnis zu den anderen Komponenten. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Wenn Sie beispielsweise zwei Komponenten haben, "Komponente a" mit der Gewichtung "10" und "Komponente b" mit der Gewichtung "0",
steht "Komponente b" bei der Sortierung an erster Stelle.
|===

.Komponente hinzufügen: Seitenformular - Globale Einstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Mitteilung
|Optional
|Eine allgemeine Mitteilung, die oben auf der Seite sichtbar ist.
|===

.Komponente hinzufügen: Seitenformular - Schritteinstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Mitteilung
|Optional
|Eine allgemeine Mitteilung, die für diese Phase oben auf der Seite sichtbar ist.
|===

=== Eine Seite erstellen

Sobald Sie die Seiten-Komponente erstellt haben, klicken Sie auf das Symbol Bearbeiten, um den auf der Seite anzuzeigenden Inhalt zu schreiben.

image:components/page/new_page.png[Neue Seitenform]

.Neues Seitenformular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Körper
|Benötigt
|Der auf der Seite angezeigte Inhalt. Sie können Bilder, Links, Videos, Formatierungen usw. hinzufügen.
|===
