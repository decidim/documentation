= Umfrage

== Understand the basics

Die Umfrage-Komponente ermöglicht es Teilnehmenden, Fragebögen zu beantworten. Dies ist nützlich, wenn eine Organisation privates Feedback von Teilnehmenden erhalten möchte. Es erlaubt eine Reihe von Fragen mit mehreren Arten von Antworten zu definieren.

NOTE: Sobald eine Umfrage von Teilnehmenden beantwortet wurde, ist es nicht mehr möglich, ihre Fragen zu ändern, da dies die Integrität
der Antworten beeinträchtigen würde. Wenn Sie die Fragen ändern müssen, erstellen Sie eine neue Umfrage und heben Sie die Veröffentlichung der ursprünglichen auf.

== Konfiguration

=== Eine Umfrage-Komponente erstellen

Um eine Umfrage-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/surveys/component_survey.png[Add Survey component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Umfrage"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

=== Fragen

==== Eine Frage hinzufügen

Klicken Sie dann auf die Schaltfläche "Frage hinzufügen", um mit der Erstellung Ihrer Umfrage zu beginnen.
Sie können mehrere Fragen pro Umfrage hinzufügen und sie neu ordnen oder löschen.

Jede Frage muss mindestens eine Aussage und einen Typ haben.

image::components/surveys/question_form.png[Question form on survey creation]

[cols="20h,10h,~"]

|Beschreibung

|Zusätzliche Informationen zur Frage, falls erforderlich.

==== Bedingte Fragen

Sobald Sie Ihre Umfrage gespeichert haben, sehen Sie, dass in den Fragenblöcken eine neue Schaltfläche "Anzeigebedingung hinzufügen" erscheint.
Mit dieser Funktion können Admins komplexe Umfragen mit Bedingungen erstellen, das heisst, dass bestimmte Fragen nur
angezeigt werden, wenn Teilnehmende bei den vorherigen Fragen eine bestimmte Antwort gewählt haben.

TIP: Bedingte Fragen können schwierig zu konfigurieren sein. Testen Sie das Verhalten der Umfrage daher unbedingt vor der Veröffentlichung.

image::components/surveys/conditional_question.png[Display condition in backend]

.Formular zum Hinzufügen einer Anzeigebedingung
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Frage
|Benötigt
|Die vorherige Frage, die die Bedingung für die Anzeige dieser Frage darstellt.

|Bedingung
|Benötigt
|Legt die Bedingung fest, die für die Anzeige dieser Frage erforderlich ist.

|Antwortoption
|Benötigt
|Dieses Feld schlägt die Antwortoptionen der Fragen vor, die von Teilnehmenden ausgewählt werden müssen, damit die Bedingung erfüllt ist.
Nur verfügbar für die Bedingungen "Gleich" und "Nicht gleich".

|Enthaltener Text
|Benötigt
|Nur verfügbar für die Bedingung "Enthält Text".

|Diese Bedingung muss immer erfüllt sein, unabhängig vom Status anderer Bedingungen.
|Optional
|Aktivieren, wenn diese Bedingung zwingend erforderlich ist, selbst wenn andere Bedingungen die Anzeige der Frage ermöglichen würden.
|===

=== Trennlinien

Sie können auch Trennlinien zwischen Fragen einfügen, wenn Sie eine lange Umfrage oder unterschiedliche Themen haben.
Sie ermöglichen es, die Formularfragen in verschiedenen Schritten anzuzeigen.

Trennlinien können nur neu geordnet oder gelöscht werden.

image::components/surveys/separator.png[Separator in front end]

=== Titel und Beschreibung

Sie können auch einen Abschnitt mit Titel und Beschreibung hinzufügen, um das Formular übersichtlicher zu gestalten und in verschiedene Abschnitte zu unterteilen.
In Kombination mit Trennlinien lassen sich damit Titel und Beschreibungen für die Umfrageschritte vergeben.
Sie können auch alleine verwendet werden, in einer einseitigen Umfrage.

image::components/surveys/title_description_backend.png[Title and description in back end]

=== Antworten exportieren

Es ist möglich die Antworten der Umfrage in verschiedene Formate zu exportieren: CSV, JSON, XLSX (Excel) oder PDF.
Es werden keine Nutzerdaten exportiert. Wenn Sie diese erfassen möchten, erstellen Sie dafür eigene Umfragefragen.

NOTE: Die Plattform übernimmt weder die Verarbeitung der Antworten noch die Darstellung von Ergebnissen oder Zusammenfassungen für die Nutzenden; dies muss
extern erfolgen.
