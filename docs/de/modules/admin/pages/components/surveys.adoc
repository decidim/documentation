= Umfrage

Die Umfragekomponente ermöglicht die Beantwortung von Fragebögen. Dies ist nützlich, wenn eine Organisation private
Rückmeldungen erhalten möchte, obwohl es möglich ist, die Antworten auch manuell zu veröffentlichen. Es erlaubt eine Reihe von Fragen mit mehreren Arten von Antworten zu definieren.

Von diesem Ausgangspunkt aus könnte es andere Konfigurationen geben, wie:

* wenn die Beantwortung auf einen Zeitraum beschränkt ist
* welche Antworttypen die Fragen haben sollen, wie kurz (eine Zeile), lang (mehrere Zeilen), einzelne oder mehrere Optionen,
sortieren durch eine Liste, etc.
* wenn es eine Antwortüberprüfung gibt, wie viele Zeichen maximal eine Antwort haben sollen
* wenn es eine maximale Anzahl an Optionen gibt, die in mehreren Optionen ausgewählt werden können

Einige Beispiele, wo diese Komponente verwendet wurde:

* https://consultation.quebec.ca/processes/donneesquebec/f/82/[Data Quebec: Nehmen Sie an seiner Verbesserung teil! (Donne<unk> es Que<unk> bec : participez a<unk> son ame<unk> lioration!) in Que<unk> bec Konsultationen]
* https://meta.decidim.org/conferences/decidimfest2020/f/1403/?locale=de[DecidimFest2020 Assessment Survey]

image:components/surveys/example01.png[Beispiel einer Umfrage]

Um die Umfrage-Komponente zu konfigurieren:

. Als Admin anmelden
. Zum Admin-Panel wechseln
. Wählen Sie in der Haupt-Seitenleiste den Bereich aus, unter dem Sie die Komponente konfigurieren möchten.
Zum Beispiel "Prozesse", "Gremien" oder "Konferenzen".
. Gehe zu Komponenten
. Auf "Komponente hinzufügen"-Button klicken
. Klicken Sie auf "Umfrage"
. Das Formular xref:_add_component[Komponente hinzufügen] ausfüllen

Sobald eine Umfrage bereits von einigen Benutzern beantwortet wurde, ist es nicht möglich, ihre Fragen zu ändern da dies die Integrität
der Antworten beeinträchtigen würde. Wenn es notwendig ist, die Fragen zu ändern, dann ist es notwendig, eine neue Umfrage zu erstellen und die ursprüngliche zu entfernen.

image:components/surveys/edit_form.png[Umfrageformular bearbeiten]

NOTE: Haben Sie wiederholende Umfrage? Zum Beispiel das gleiche Feedback-Formular für jeden Prozess? Du kannst eine Umfrage haben, die

Jede Frage muss eine Aussage und einen Typ als Minimum haben.

== Fragentypen

Eine Umfrage kann mehrere Fragen mit verschiedenen Typen haben, wie:

- Kurze Antwort
- Lange Antwort
- Einzelne Option
- Mehrere Optionen
- Sortieren
- Dateien
- Matrix (Einzeloption)
- Matrix (mehrere Option)

== Vorlagen

Für die Fälle, in denen Administratoren mehrere Umfragen definieren müssen, die meist gleich sind, aber in verschiedenen Kontexten verwendet werden,
ist es möglich, eine Vorlage zu definieren. Wenn für eine Umfrage eine definiert ist, dann wird es darum bitten, das Template auszuwählen und die Umfrage
basierend auf dieser oder in der anderen Seite zu erstellen, wenn es keine Notwendigkeit gibt, eine Vorlage zu verwenden, dann ist es möglich, die Vorlage
Auswahl zu überspringen.

image:components/surveys/edit_questionnaire.png[Template form] wählen

== Antworten exportieren

Es ist möglich die Antworten der Umfrage in verschiedene Formate zu exportieren: CSV, JSON, XLSX (Excel) oder PDF.

Beachten Sie, dass die Plattform weder die Bearbeitung von Antworten noch die Ergebnisse oder Zusammenfassung für die Benutzer verwaltet, die extern
durchgeführt werden müssen.
