= Budget

== Understand the basics

Die Budget-Komponente ermöglicht es Teilnehmenden, abzustimmen, indem sie Projekte ihrer Wahl auswählen. Diese Komponente wurde entwickelt, um
die Abstimmung in der letzten Phase eines partizipativen Budgets zu organisieren, kann jedoch auch für andere Arten von Prozessen verwendet werden.

Admins können die Abstimmungsregeln festlegen, sodass Teilnehmende entweder eine festgelegte Anzahl von Projekten auswählen oder für so
viele Projekte abstimmen, wie sie möchten, bis ein bestimmter Betrag erreicht ist.

image::components/budgets/example01.png[Budgets example voting]

Admins haben mehrere Optionen für den Abstimmungsablauf und die Abstimmungsregeln.

image::components/budgets/example02.png[Budgets example voting]

In diesem Abschnitt der Dokumentation findest du Informationen dazu, wie du all diese Elemente konfigurierst und verwaltest:

* xref:admin:components/budgets/budgets.adoc[Budgets]
* xref:admin:components/budgets/projects.adoc[Projekte]

== Konfiguration

=== Erstellung der Budget-Komponente

Um eine Budget-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/budgets/component_budgets.png[Add Budgets component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Budget"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

Das Formular zur Komponentenerstellung ist in verschiedene Abschnitte unterteilt, die im Folgenden näher beschrieben werden.

=== Die Ergebnisse veröffentlichen

Nachdem die Abstimmung beendet ist, muss ein Admin:

. Ändern Sie die Abstimmungskonfiguration für die Budgetkomponente auf "Abstimmung beendet"
. Zur Projektliste gehen und die Ergebnisse ansehen
. Bei den ausgewählten Projekten zu jedem Projekt gehen, es bearbeiten und das Kontrollkästchen "Zur Umsetzung ausgewählt" aktivieren.

image::components/budgets/results_select_project.png[Select a project for implementation]

Anschliessend zeigt die Projektliste alle Projekte an, die zur Umsetzung ausgewählt wurden.

image::components/budgets/results_selected.png[Selected projects after voting]

Zudem wird ein Filter angezeigt, mit dem Teilnehmende sehen können, welche Projekte ausgewählt wurden, und diejenigen finden können, die nicht ausgewählt wurden.

image::components/budgets/results_selected_frontend.png[Selected projects after voting in the frontend]

TIP: Sobald Sie Projekte ausgewählt haben, können Sie die xref:components/accountability.adoc[Rechenschaft]-
Komponente aktivieren, damit Teilnehmende den Fortschritt der Projektumsetzung sehen können.
