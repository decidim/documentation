= Meetings

== Die Grundlagen verstehen

Die Veranstaltungen-Komponente ermöglicht es Admins, persönliche oder Online-Veranstaltungen zu organisieren, zu bewerben, deren Anmeldungen zu verwalten und abzuschliessen.
Je nach Konfiguration der Komponente können Veranstaltungen nur von Admins oder auch von Teilnehmenden erstellt werden.

In diesem Abschnitt der Dokumentation finden Sie Informationen dazu, wie Sie all diese Elemente konfigurieren und verwalten:

* xref:admin:components/meetings/meetings.adoc[Veranstaltungserstellung]: Offizielle Veranstaltungen oder Veranstaltungen von Teilnehmenden erstellen.
* xref:admin:components/meetings/registrations.adoc[Anmeldungen]: Verwalten, wie sich Teilnehmende für die Teilnahme an den Veranstaltungen anmelden können.
* xref:admin:components/meetings/agenda.adoc[Traktandenliste]: Die zu besprechenden Themen der Veranstaltungen ankündigen.
* xref:admin:components/meetings/polls.adoc[Umfragen]: Schnelle Abstimmungen während einer Online-Veranstaltung ermöglichen.
* xref:admin:components/meetings/close.adoc[Abschliessen]: Den Abschlussbericht und das Protokoll der Veranstaltung hinzufügen.

== Konfiguration

Um eine Veranstaltungen-Komponente zu erstellen, gehen Sie zunächst zum xref:admin:spaces.adoc[partizipativen Raum], in dem Sie sie erstellen möchten.

image::components/meetings/component_meeting.png[Add Meetings component button]

Dann:

. Klicken Sie im Sekundärmenü auf den Punkt "Komponenten"
. Klicken Sie auf die Schaltfläche "Komponente hinzufügen"
. Wählen Sie "Veranstaltungen"
. Füllen Sie das Formular zur Komponentenerstellung aus

Sie können dieses Formular und die Konfiguration auch nach der Erstellung der Komponente noch aktualisieren, indem Sie in der Komponentenliste auf das
      image:icons/action_configure.png[Symbol: Konfigurieren] Konfigurieren-Symbol klicken.

image::components/meetings/component.png[Add a meetings component]

.Komponente hinzufügen - Meetings-Formular
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Name
|Benötigt
|Wie lautet der Name dieser Komponente.

|Reihenfolge
|Optional
|Die Reihenfolge der Komponente im Verhältnis zu den anderen Komponenten. Eine niedrigere Zahl bedeutet eine höhere Priorität.
Wenn Sie beispielsweise zwei Komponenten haben, "Komponente a" mit der Gewichtung "10" und "Komponente b" mit der Gewichtung "0",
steht "Komponente b" bei der Sortierung an erster Stelle.
|===

.Komponente hinzufügen - Meeting-Formular: Globale Einstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Themen aktiviert
|Optional
|Aktivieren, wenn die Themenfilterung in dieser Komponente erfolgen soll.

|Thema
|Optional
|Zu welchen xref:admin:settings/scopes.adoc[Themen] diese Komponente gehört.

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die in der Veranstaltungsliste in der Teilnehmenden-Oberfläche sichtbar ist.

|Standard-Registrierungsbedingungen
|Optional
|Die Anmeldebedingungen, die die teilnehmende Person bei der Anmeldung akzeptieren muss.

|Kommentare aktiviert
|Optional
|Ob Sie das Erstellen von Kommentaren bei den Veranstaltungen aktivieren möchten.

|Maximale Länge der Kommentare
|Optional
|Das Zeichenlimit, das Teilnehmenden beim Verfassen von Kommentaren zur Verfügung steht. Lassen Sie 0 für den Standardwert.

|Registrierungscode aktiviert
|Optional
|Aktivieren Sie dies, wenn Teilnehmenden automatisch Anmeldecodes zugeteilt werden sollen.
Erfahren Sie mehr unter xref:components/meetings/registrations.adoc[Registrations].

|Aktionsberechtigungen können für jedes Meeting festgelegt werden
|Optional
|Wenn Sie mehr granulare Berechtigungen in jedem der Meetings wünschen.

|Pad-Erstellung aktivieren
|Optional
|Wenn Sie möchten, dass ein Etherpad in Ihre Meetings eingebettet ist. Die xref:services:etherpad.adoc[Etherpad]-Integration muss konfiguriert sein.

|Teilnehmende können Meetings erstellen
|Optional
|Erlaubt Teilnehmern neue Meetings zu erstellen. Weitere Informationen finden Sie unter xref:components/meetings/meetings.adoc#_participants_meetings[Veranstaltungen von Teilnehmenden].

|Karten aktiviert
|Optional
|Ob Sie eine Karte mit den Adressen der Veranstaltungen in der Veranstaltungsliste und auf den Seiten anzeigen möchten.
|===

.Komponente hinzufügen - Meeting-Formular: Schritteinstellungen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Mitteilung
|Optional
|Eine allgemeine Ankündigung, die in der allgemeinen Veranstaltungsliste für diese Phase sichtbar ist.

|Kommentare aktiviert
|Optional
|Ob Sie das Erstellen von Kommentaren bei den Veranstaltungen für diese Phase aktivieren möchten.
|===
