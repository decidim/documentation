= Partizipative Texte

== Die Grundlagen verstehen

Diese Funktion ermöglicht es Teilnehmenden, durch die Vorschläge wie durch einen Text zu navigieren, anstatt durch eine Liste oder eine Übersicht.
Sie kann nützlich sein, um Normen, Pläne oder andere Arten von Texten zu diskutieren.

Jeder Absatz ist in einen Vorschlag aufgeteilt, sodass es möglich ist, ihn auf granularere Weise zu diskutieren.

image::components/proposals/participatory_texts/example01.png[Participatory text example]

== Konfiguration

Um "Partizipative Texte" bei Vorschlägen zu konfigurieren, aktivieren Sie die Einstellung "Partizipative Texte aktiviert" im Konfigurationsformular der Komponente.

image::components/proposals/component_specific_conf.png[Add component form - Specific configurations]

Klicken Sie oben in der leeren Vorschläge-Komponente auf die Schaltfläche "Partizipative Texte".

image::components/proposals/participatory_texts/manage_proposals.png[Manage proposals]

Klicken Sie anschliessend im leeren Vorschau-Panel für partizipative Texte auf die Schaltfläche "Dokument importieren", um zum Formular weitergeleitet zu werden.

image::components/proposals/participatory_texts/add_document_form.png[Add document form]


.Dokumentenformular hinzufügen
|===
|Feld |Typ |Beschreibung

|Titel
|Benötigt
|Der Titel des Dokuments, das in der Vorschläge-Komponente diskutiert werden soll.

|Beschreibung
|Optional
|Beschreibung für das Dokument.

|Dokument
|Benötigt
|Datei. Fügen Sie ein Dokument mit weniger als 2 MB hinzu; jeder Abschnitt bis zu einer Überschriftentiefe von 3 Ebenen wird in Vorschläge umgewandelt.
Unterstützte Formate sind: Markdown und ODT.
|===

TIP: Obwohl es möglich ist, sowohl mit Markdown (.MD)- als auch mit ODT (.ODT)-Dateien zu arbeiten, empfehlen wir, mit Markdown zu arbeiten, da es
einfacher ist, die Formatierung zu sehen. link:{attachmentsdir}/participatory_text.md[Laden Sie den partizipativen Beispieltext im MD-Format herunter] als Hilfestellung.

Klicken Sie auf die Schaltfläche "Dokument hochladen", um die Vorschau des partizipativen Texts zu sehen.

=== Vorschau des Dokuments

image::components/proposals/participatory_texts/preview_participatory_text.png[Preview participatory text]

Dank der Vorschau können Sie prüfen, ob das Dokument korrekt importiert und wie gewünscht unterteilt wurde.

Je nach Vorschau können Sie:

* *Verwerfen*: wenn Sie nicht zufrieden sind und Ihr Dokument neu formatieren möchten, um den Import erneut zu starten.
* *Entwurf speichern*: wenn Sie mit dem Ergebnis zufrieden sind, aber noch einige Änderungen vornehmen möchten.
* *Dokument veröffentlichen*: wenn Sie bereit sind zu sehen, wie der Text in der Benutzeroberfläche aussieht.

Sobald Sie das Dokument veröffentlicht haben, werden alle Abschnitte als Vorschläge im Verwaltungspanel für Vorschläge angezeigt.

image::components/proposals/participatory_texts/imported_document_proposals.png[Imported document proposals]

Abschliessend können Sie die Vorschläge-Komponente veröffentlichen, damit der partizipative Text für Teilnehmende sichtbar ist.

NOTE: Diese Funktion könnte bestehende Vorschläge beeinträchtigen; falls sie mit einem vorhandenen Vorschlag nicht funktionieren kann, wird eine Warnmeldung angezeigt:

====
Kann nicht mit dieser Einstellung interagieren, wenn es existierende Vorschläge gibt. Bitte erstellen Sie eine neue `Proposals component`, wenn Sie
diese Funktion aktivieren möchten, oder verwerfen Sie alle importierten Vorschläge im Menü `Participatory Texts`, wenn Sie sie deaktivieren möchten.
====

Sobald das Dokument importiert und die Vorschläge-Komponente veröffentlicht ist, können Teilnehmende durch den partizipativen Text navigieren.
