= Vorschlagsverwaltung

== Die Grundlagen verstehen

Es ist wichtig zu verstehen, dass Vorschläge nicht nur der Name der Komponente ist, sondern auch die Entitäten der Komponente.

image::components/proposals/proposals_list_frontend.png[Proposals list frontend]

== Konfiguration

Sobald Sie Ihre Vorschläge-Komponente erstellt haben, werden Sie zur Vorschlagsliste weitergeleitet. Dort können Sie die Vorschläge
Ihrer Komponente erstellen und verwalten.

Je nachdem, ob Sie nur Vorschläge von Teilnehmenden sammeln oder auch offizielle Vorschläge erstellen möchten, lesen Sie den
entsprechenden Abschnitt.

=== Erstellung von Vorschlägen

==== Offizielle Vorschläge

Um mit der Erstellung offizieller Vorschläge zu beginnen, müssen Sie zunächst Ihren ersten Vorschlag erstellen, indem Sie auf die Schaltfläche "Neuer Vorschlag" klicken.

der Rasteransicht der Vorschlagsliste verwendet.
|===

==== Vorschläge von Teilnehmenden

Sobald Sie das Erstellen von Vorschlägen durch Teilnehmende für die aktive Phase aktiviert haben, sehen Teilnehmende auf der Vorschlagsliste
eine Schaltfläche "Neuer Vorschlag".

image::components/proposals/new_proposal_button_frontend.png[New proposal button on proposals list]

Wenn sie auf die Schaltfläche klicken, werden sie zu einem zweistufigen Formular weitergeleitet, mit dem sie ihren Vorschlag erstellen können.
Dieses Formular hängt stark davon ab, welche Einstellungen Sie in der Komponente aktiviert haben.

Sobald der Vorschlag verfasst und alle Eigenschaften festgelegt sind, kann die teilnehmende Person auf die Schaltfläche Vorschau klicken, um ihren Vorschlag zu überprüfen.
Der Vorschlag wird als Entwurf gespeichert, falls Teilnehmende ihn später noch bearbeiten möchten.

image::components/proposals/new_proposal_frontend_publish.png[New proposal form (by a participant) - Publish]

Sie können auf die Schaltfläche "Veröffentlichen" klicken, um die Veröffentlichung des Vorschlags abzuschliessen.

image::components/proposals/new_proposal_frontend_published.png[Published proposal made by a participant]

=== Vorschläge verwalten

Sobald mehrere Vorschläge im Prozess vorhanden sind, können Admins sie verwalten.

image::components/proposals/manage_proposals.png[Manage proposals table]

In der Vorschlagsliste im Verwaltungspanel können Admins Folgendes sehen:

* *Titel*: Titel des Vorschlags.
* *Veröffentlicht am*: Veröffentlichungsdatum des Vorschlags.
* *Kommentare*: Die Anzahl der Kommentare zu diesem Vorschlag.
* *Stimmen*: Die Anzahl der Stimmen, die dieser Vorschlag hat.
* *Bewertende*: Die Anzahl der bewertenden Personen für diesen Vorschlag.
* *Status*: Der Status der xref:admin:components/proposals/answers.adoc[Antwort] zu diesem Vorschlag.

Sie können diese Liste filtern und sortieren, indem Sie auf die Schaltfläche "Filter" und die Spaltenüberschriften klicken.
Sie können auch in der Suchleiste nach Vorschlägen anhand ihres Titels oder ihrer ID suchen.

=== Massenaktionen

Bei der Verwaltung von Vorschlägen können Sie mehrere Vorschläge gleichzeitig auswählen, um Massenaktionen durchzuführen.

image::components/proposals/bulk_actions.png[Proposals bulk actions]

=== Exportieren

Mit der Schaltfläche "Alles exportieren" können Admins die Vorschläge und ihre Kommentare in verschiedenen Formaten exportieren.

* Vorschläge als CSV
* Vorschläge als JSON
* Vorschläge als Excel
* Kommentare als CSV
* Kommentare als JSON
* Kommentare als Excel

=== Importieren

* Vorschläge aus einer anderen Komponente importieren: Ermöglicht den Import von Vorschlägen aus einer Vorschläge-Komponente desselben Raums.
* Vorschläge aus einer Datei importieren
* Antworten aus einer Datei importieren
