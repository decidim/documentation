= Spezifische Konfigurationen

== Die Grundlagen verstehen

Die Vorschlagskomponente wurde mit verschiedenen Layouts konzipiert, um unterschiedliche Anwendungsfälle abzudecken.
Diese spezifischen Konfigurationen werden seltener verwendet und erfordern gute Kenntnisse der Software.
