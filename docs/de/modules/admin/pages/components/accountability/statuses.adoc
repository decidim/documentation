= Status

== Die Grundlagen verstehen

Ein Status stellt den aktuellen Zustand eines Ergebnisses dar.
Für Teilnehmende zeigen Status den Zustand jedes Ergebnisses klar an, da die Statusnamen immer zusammen mit den Ergebnissen angezeigt werden.
Für Admins helfen Status dabei, den Fortschritt der Ergebnisse aktuell zu halten, da jeder Status einen Standard-Fortschrittsprozentsatz haben kann.

Nach der Konfiguration der Status können Sie xref:admin:components/accountability/results.adoc[einem Ergebnis einen Status zuweisen].
Sobald der Status eines Ergebnisses aktualisiert wird, wird dessen Fortschritt automatisch auf den im Status definierten Standardfortschritt gesetzt.

Das Aktualisieren des Status eines Ergebnisses aktualisiert nicht dessen Verlauf, kann jedoch xref:admin:features/participant_actions/notifications.adoc[Benachrichtigungen senden].

== Konfiguration

Um Status zu erstellen, klicken Sie oben rechts in der Ergebnisliste auf die Schaltfläche "Status".

image::components/accountability/statuses_button.png[Statuses button]

Dort können Sie die verschiedenen Status für die Ergebnisse erstellen und verwalten.

image::components/accountability/statuses_list.png[Statuses list]

Klicken Sie auf die Schaltfläche "Neuer Status", um mit der Erstellung von Status zu beginnen.

image:components/accountability/new_status.png[Formular für neuen Status]


.Formular für neuen Status
|===
|Feld |Typ |Beschreibung

|Schlüssel
|Benötigt
|Wird als eindeutige Kennung für den xref:admin:components/accountability/import.adoc[CSV-Import] verwendet.

|Name
|Benötigt
|Name für diesen Status.

|Beschreibung
|Optional
|Beschreibung für diesen Status.

|Fortschritt
|Optional
|Standardfortschritt für ein Ergebnis, dem dieser Status zugewiesen ist (Prozentsatz von 0 bis 100).
|===
