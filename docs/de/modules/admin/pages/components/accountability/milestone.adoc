= Projektentwicklung

== Die Grundlagen verstehen

Damit Teilnehmende die Entwicklung der Projekte verfolgen und überwachen können, können Admins Einträge im Zeitverlauf erstellen, indem sie auf das
image:icons/action_clock.png[Symbol: Projektentwicklung] klicken.

image::components/accountability/results_entries.png[Result page with timeline entries]

== Konfiguration

image::components/accountability/timeline_list.png[Timeline entries list]

Dort können Sie die verschiedenen Umsetzungsphasen für das Ergebnis erstellen und verwalten sowie neue Einträge im Zeitverlauf erstellen.

image::components/accountability/new_entry.png[New timeline entry form]


.Formular für neuen Eintrag
|===
|Feld |Typ |Beschreibung

|Datum
|Benötigt
|Erwartetes Format: dd/mm/yyyy

|Titel
|Benötigt
|Titel des Eintrags im Zeitverlauf.

|Beschreibung
|Optional
|Beschreibung des Eintrags im Zeitverlauf.
|===

Die Einträge im Zeitverlauf sind anschliessend auf der Ergebnisseite verfügbar.
