= Ergebnisse importieren

== Understand the basics

Manchmal wird der Rechenschaftsinhalt nach einem internen Prozess in einer Organisation verwendet, wie zum Beispiel der Bewertung der Kosten von
      Projekten des partizipativen Budgets in externen Dateien. Daher kann es nützlich sein, neue Ergebnisse und Ergebnisänderungen im Batch zu importieren.

Dafür können Sie die Funktionen zum Exportieren und Importieren von Ergebnissen verwenden.

== Konfiguration

=== Ergebnisse exportieren

Sie können Ergebnisse und ihre Kommentare in verschiedenen Formaten exportieren, indem Sie in der Ergebnisliste auf die Schaltfläche "Alle exportieren" klicken:

* Ergebnisse als CSV
* Ergebnisse als JSON
* Ergebnisse als Excel
* Kommentare als CSV
* Kommentare als JSON
* Kommentare als Excel

image::components/accountability/export.png[Import results from CSV form]

=== Ergebnisse importieren

Sie können Ergebnisse auch importieren, indem Sie in der Ergebnisliste im Verwaltungspanel auf die Schaltfläche "Importieren" klicken.

image::components/accountability/import.png[Import results from CSV form]

==== Aus einer Komponente importieren

Sie können Ergebnisse direkt aus einer xref:admin:components/budgets.adoc[Budget]-Komponente desselben partizipativen Raums importieren
      und wählen, ob Sie alle Projekte als Ergebnisse importieren möchten oder nur die zur Umsetzung ausgewählten.

image:components/accountability/import_component.png[Formular zum Importieren von Ergebnissen aus CSV]

==== Aus einer CSV-Datei importieren

Sie können Ergebnisse auch aus einer CSV-Datei importieren.

image:components/accountability/import_csv.png[Formular zum Importieren von Ergebnissen aus CSV]

Gehen Sie dazu wie folgt vor:

. Erstellen Sie die xref:admin:components/accountability/statuses.adoc[Status] für die Ergebnisse, die Sie hinzufügen möchten
. Erstellen Sie vor dem Import mindestens ein xref:admin:components/accountability/results.adoc[Ergebnis] manuell über dieses Verwaltungspanel,
      um das Format besser zu verstehen und zu wissen, was Sie ausfüllen müssen.
. Laden Sie den xref:_export_results[Export im CSV-Format] herunter
. Nehmen Sie die Änderungen lokal vor. Sie können nur die folgenden Spalten der CSV-Datei ändern:
** category/id: ID für die Kategorie des Ergebnisses
** scope/id: ID für das Thema des Ergebnisses
** parent/id: ID des übergeordneten Elements (für verknüpfte Ergebnisse). Optional
** title/en: Titel in englischer Sprache. Dies hängt von der Sprachkonfiguration Ihrer Plattform ab.
** description/en: Beschreibung in englischer Sprache. Dies hängt von der Sprachkonfiguration Ihrer Plattform ab.
** start_date: Datum, an dem die Umsetzung des Ergebnisses beginnt (Format JJJJ-MM-TT)
** end_date: Datum, an dem die Umsetzung des Ergebnisses endet (Format JJJJ-MM-TT)
** status/id: ID des Status für dieses Ergebnis
** progress: Prozentsatz (von 0 bis 100) der Umsetzung
** proposals_ids: interne ID der verknüpften Vorschläge (durch Komma getrennt). Wird automatisch in proposal_url umgewandelt
