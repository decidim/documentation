= Umfragen

== Die Grundlagen verstehen

Veranstaltungsumfragen ermöglichen es Admins, Fragen für eine Veranstaltung zu definieren, die Teilnehmende beantworten können,
während diese stattfindet. Dies kann sehr nützlich sein, um schnelles Feedback zu sammeln und während Veranstaltungen Entscheidungen zu treffen, ohne die Veranstaltung verlassen und
andere Arten von Tools verwenden zu müssen.

Mit dieser Funktion können Admins Fragen definieren und festlegen, wann diese Fragen und ihre Ergebnisse
Teilnehmenden angezeigt werden.

== Konfiguration

=== Umfrage erstellen

Um Umfragen für eine bestimmte Veranstaltung zu konfigurieren, klicken Sie auf die Schaltfläche image:icons/action_list.png[Symbol: Umfragen verwalten] "Umfragen verwalten".

image::components/meetings/polls/backend.png[Backend for meeting polls]

.Formular für Umfragefragen
[cols="20h,10h,~"]
|===
|Feld |Typ |Beschreibung

|Anweisung
|Benötigt
|Titel für die Frage

|Typ
|Benötigt
|Wählen Sie zwischen einer Frage mit Einzel- oder Mehrfachauswahl.

|Antwortoptionen
|Benötigt
|Jede mögliche Antwort.
|===

Sie können so viele Fragen und Antwortoptionen hinzufügen, wie Sie möchten.

=== Umfrage verwalten

Vor der Veranstaltung, sofern die Admins die Umfragefragen bereits konfiguriert haben, sehen Teilnehmende auf der Veranstaltungsseite eine Schaltfläche "Umfrage beantworten",
die sie darauf hinweist, dass bei dieser Veranstaltung eine Umfrage veröffentlicht wird.

image::components/meetings/polls/frontend_before_meeting.png[Reply poll page before meeting]

Wenn die Veranstaltung beginnt, kann der Admin im Frontend zur Umfrageverwaltungsseite gehen, um mit dem Versenden der Fragen
an die Teilnehmenden zu beginnen.

image::components/meetings/polls/poll_administration_page.png[Polls administration page]

Sobald eine Frage gesendet wurde, sehen die Teilnehmenden sie auf der Umfrageseite erscheinen und können sie beantworten.

image::components/meetings/polls/poll_participant_reply.png[Polls question for participant]

Anschliessend können Admins entscheiden, die Ergebnisse der Fragen an die Teilnehmenden zu senden, damit diese wissen, welche Option am meisten Stimmen erhalten hat.

image::components/meetings/polls/poll_participant_replies_sent.png[Polls replies view for participant]

=== Exportieren

Die Antworten der Teilnehmenden können über die Schaltfläche "Alle exportieren" im CSV-, JSON-, Excel- und PDF-Format exportiert werden.
