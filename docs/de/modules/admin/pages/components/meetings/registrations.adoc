= Anmeldungen

== Die Grundlagen verstehen

NOTE: Dieser Artikel widmet sich Anmeldungen über "Auf dieser Plattform" beim Erstellen oder Bearbeiten einer Veranstaltung.

Durch die Registrierung können Sie die Teilnahme an einem Meeting kontrollieren. Mit dieser Funktion können Sie beispielsweise
begrenzen, wie viele Personen an der Veranstaltung teilnehmen können, oder vor Beginn einer Veranstaltung wissen, ob Sie einen grösseren
Raum für die Veranstaltung benötigen.

Wenn Sie diese Funktion aktivieren, wird eine Schaltfläche "Anmelden" hinzugefügt, mit der Teilnehmende ihren Wunsch äussern können, an der Veranstaltung teilzunehmen.

image::components/meetings/registrations/frontend_join_meeting.png[Join a meeting button on meeting page]

Je nachdem, wie diese Funktion konfiguriert ist, können Admins:

. festlegen, wie viele Plätze verfügbar sind, um die maximale Kapazität dieser Veranstaltung zu steuern
. ein xref:_registration_form[individuelles Anmeldeformular] erstellen, um Informationen von Teilnehmenden zu erfragen
. xref:_invitations[Einladungen] an andere Teilnehmende oder nicht auf der Plattform registrierte Personen senden
. die Teilnahme an der Veranstaltung über xref:_registration_code[Anmeldecodes] kontrollieren

== Konfiguration

=== Für eine Veranstaltung anmelden

Wenn eine teilnehmende Person auf die Schaltfläche "Anmelden" klickt, wird sie gefragt

* ob sie eine xref:admin:participants/groups.adoc[Gruppe] vertritt.
* ob sie öffentlich zeigen möchte, dass sie an der Veranstaltung teilnimmt.

image::components/meetings/registrations/frontend_confirm.png[Join a meeting confirm modal]

=== Anmeldungen verwalten

Sobald Sie sich beim Erstellen einer Veranstaltung dafür entschieden haben, Anmeldungen "Auf dieser Plattform" zu verwalten, können Sie die Anmeldungen verwalten, indem Sie auf das
image:icons/action_registrations.png[Symbol: Anmeldungen] Anmeldungen-Symbol klicken.

image:components/meetings/registrations/backend.png[Registrierungseinstellungen in einem Meeting]

=== Anmeldeformular

Mit dieser Funktion können Sie ein individuelles Formular wie die xref:admin:components/surveys.adoc[Surveys] Komponente definieren, um Teilnehmende
nach Registrierungsinformationen zu fragen.

Um ein Anmeldeformular zu erstellen, aktivieren Sie "Anmeldeformular aktiviert" auf der Anmeldeseite und klicken Sie auf die Schaltfläche "Speichern".
Anschliessend können Sie oben rechts auf der Seite auf die Schaltfläche "Anmeldeformular" klicken.

=== Alle exportieren

Sie können Anmeldungen in mehreren Formaten exportieren: CSV, JSON und XLSX (Excel).

Die exportierten Daten enthalten folgende Felder:

* id: Die Registrierungsnummer
* code: der xref:_registration_code[Registrierungscode] (wenn diese Funktion aktiviert ist)
* user/name: der Name des Benutzers
* user/email: die E-Mail des Benutzers
* user/user_group: die Gruppe der Person, sofern sie bei der Anmeldung angegeben hat, dass sie eine Gruppe vertritt

=== Einladungen

Mit dieser Funktion können Sie Teilnehmende zu einer Veranstaltung einladen. Dabei kann es sich um aktive Teilnehmende oder um Personen handeln, die noch nicht
auf der Plattform registriert sind.

image::components/meetings/registrations/invite_attendee.png[Invite attendee for registration in a meeting]

=== Registrierungscode

Mit dieser Funktion können Sie überprüfen, ob eine teilnehmende Person korrekt für die Veranstaltung angemeldet ist.

Nach der Anmeldung erhält die teilnehmende Person einen Anmeldecode in der Bestätigungs-E-Mail und auf der Veranstaltungsseite.

image:components/meetings/registrations/frontend_w_code.png[Anmeldecode im Frontend einer Veranstaltung]

Die Validierung des Codes steht noch aus. Das bedeutet, dass die teilnehmende Person den Code bei der Veranstaltung einer veranstaltenden Person
zur Validierung übergeben muss.
Die veranstaltende Person gibt den Code dann in das Feld "Anmeldecode validieren" ein, um zu bestätigen, dass er in der Datenbank vorhanden ist.

image:components/meetings/registrations/backend_w_registration_code.png[Registrierungscode Formular in Meeting]

Sobald der Code überprüft wurde, gilt die teilnehmende Person als an der Veranstaltung teilgenommen, und der Code wird als validiert markiert.

image:components/meetings/registrations/frontend_confirmed_w_code.png[Registrierungscode in einem Meeting-Frontend]
