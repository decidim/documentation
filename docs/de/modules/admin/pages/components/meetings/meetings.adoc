= Meetings

== Understand the basics

Veranstaltungen sind auch die Entitäten, die Teil der Veranstaltungen-Komponente sind.
Sie werden in der Regel von Admins erstellt, aber Teilnehmende können ebenfalls Veranstaltungen erstellen, wenn diese Funktion aktiviert ist.

Admins können verschiedene Aktionen für Veranstaltungen durchführen, je nachdem, ob diese über die Administration oder von Teilnehmenden erstellt wurden.

einen Kinderbereich, Hörassistenz, Übersetzungen usw. gibt. Sie können mehrere Dienste innerhalb eines Meetings nutzen.

=== Participants meetings

Veranstaltungen können von Teilnehmenden erstellt werden, wenn die Komponenteneinstellung "Teilnehmende können Veranstaltungen erstellen" aktiviert ist.
Wenn ein Teilnehmender einer verifizierten xref:admin:participants/groups.adoc[Benutzergruppe] angehört, kann er Veranstaltungen
auch im Namen dieser Gruppe erstellen.

Wenn sich ein Teilnehmender in der Veranstaltungsliste befindet, kann er auf die Schaltfläche "Neue Veranstaltung" klicken.

image::components/meetings/new_meeting_button_front.png[Create a new meeting button (frontend)]

Anschliessend wird er zum Erstellungsformular für Teilnehmenden-Veranstaltungen weitergeleitet.

=== Online-Meetings

Bei Online-Veranstaltungen werden den Teilnehmenden je nach Zeitpunkt und Konfiguration der Veranstaltung unterschiedliche Meldungen angezeigt,
um sie darüber zu informieren, wie sie der Online-Veranstaltung beitreten können.

Wenn die "URL der Online-Veranstaltung" noch nicht festgelegt ist, wird die Meldung "Link demnächst verfügbar" angezeigt.

image::components/meetings/online_meeting_available_soon.png[Online meeting available soon]

Wenn die "URL der Online-Veranstaltung" festgelegt ist, lautet die Meldung wenige Minuten vor Beginn der Veranstaltung: "Der Link zur Teilnahme
an der Veranstaltung wird wenige Minuten vor Beginn verfügbar sein"

image::components/meetings/online_meeting_available_before.png[Online meeting available before it starts]

Wenn die "URL der Online-Veranstaltung" festgelegt ist, die Startzeit der Veranstaltung erreicht wurde und Sie als Iframe-Einbettungstyp
"URL in neuem Tab öffnen" gewählt haben, lautet die Meldung, dass "die Veranstaltung gerade jetzt stattfindet", mit einem Link zur Teilnahme an der Veranstaltung.

image::components/meetings/online_meeting_happening.png[Online meeting available before it starts]

Wenn die "URL der Online-Veranstaltung" festgelegt ist, die Startzeit der Veranstaltung erreicht wurde und Sie als Iframe-Einbettungstyp
"In Veranstaltungsseite einbetten" gewählt haben, lautet die Meldung, dass "die Veranstaltung gerade jetzt stattfindet", wobei die Veranstaltung im Block eingebettet ist.

image::components/meetings/online_meeting_happening_embed.png[Online meeting available before it starts]
