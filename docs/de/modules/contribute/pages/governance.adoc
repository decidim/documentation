= Governance

== Über den Code

Um neue Funktionen zu erstellen, können Sie ein https://decidim.org/modules[neues Modul] für Ihre eigene Anwendung erstellen. Wenn Sie es auf der Webseite veröffentlichen möchten, können Sie https://decidim.org/contact[uns eine Nachricht senden].

Wenn Sie eine neue Funktion oder eine Änderung der Codebase hinzufügen möchten, lautet der Prozess:

. Schlagen Sie Ihre Änderung auf https://meta.decidim.barcelona/processes/roadmap[Metadecidim] vor
. Warten Sie, bis das Produktteam die Funktion überprüft und akzeptiert, da es wichtig ist, mit dem Rest der Software konsistent zu sein, den Gesellschaftsvertrag einzuhalten, etc.
. Dann können Sie die Pull Request machen.
. Die PR wird überprüft von:
.. Produktteam: überprüft die Funktionalität
.. Betreuer: überprüfen die Code-Qualität

image::workflow-features.png[new feature workflow process]

Einige Dinge, die Sie bei diesem Prozess berücksichtigen müssen:

* Wenn Sie die PR ohne Produkt-Team-Genehmigung machen, können Sie abgelehnt werden (nachdem Sie viel Zeit in die Entwicklung investiert haben).
* Vorschläge können Unterstützungen erhalten, obwohl diese nicht entscheidend für die Aufnahme eines Vorschlags in den Fahrplan sind. Die Unterstützungen dienen als Indikatoren für die Interessen des Vorschlags oder die darin enthaltene Notwendigkeit. Die Kommentare zu den Vorschlägen sind auch möglich, die ursprüngliche Idee gemeinsam auszuarbeiten und zu einem produktiven Ergebnis zu führen.
* Jeden Donnerstag überprüft das Produktteam alle neuen Vorschläge, die in der vergangenen Woche veröffentlicht wurden
* Wenn keine Mittel zur Verfügung stehen, ist sie im Rückstand der entsprechenden Komponente oder des entsprechenden Moduls enthalten.

== Über die Organisation

Decidim wurde ursprünglich von der Stadt Barcelona erstellt, aber schnell entwickelte es sich durch die Hilfe von Localret und anderen Einheiten und Verwaltungen aus Katalonien, wie Diputació de Barcelona (Provinz Barcelona) und andere katalanische Städte: Terrassa, Sabadell, Gavà, L'Hospitalet de Llobregat, Badalona und Sant Cugat. Lesen Sie mehr über den Verlauf in xref:understand:about.adoc[About].

Seit unserer ersten Version im Jahr 2017 haben wir erkannt, dass es für die Nachhaltigkeit des Projekts notwendig ist, nicht von einer bestimmten Institution wie der Stadt Barcelona abhängig zu sein, da dies für die Zukunft problematisch sein könnte. Andere Open-Source-Projekte öffentlicher Institutionen, die keine starke Gemeinschaft oder eine Nachhaltigkeitsstrategie hatten, werden geschlossen oder sterben ohne Finanzierung langsam aus.

Diese Art von Open-Source-Software von den öffentlichen Institutionen und durch das öffentliche Auftragsrecht zu machen, ist wirklich schwierig, und ein weiteres Problem, das wir mit dieser neuen Organisation angehen wollen, ist die Bereitstellung von Ressourcen für die Vergabe von Inhouse-Entwicklern.

Aus diesem Grund haben wir mit dem https://meta.decidim.org/processes/decidim-gov[Metadecidim Governance partizipatorischen Prozess] angefangen im November 2017:

****
Ein Prozess, der der gesamten Gemeinschaft hinsichtlich der Entscheidungsorgane und der Vertretungsorgane offen steht, mit denen wir uns ausstatten müssen, um eine autonome, transparente und demokratische Organisation für das Decidim-Projekt aufzubauen.

Ziel ist es, ein Organisations- und Repräsentationssystem (interne Organe und wie sie ausgewählt werden) zu definieren, das in eine autonome Einheit oder Vereinigung umgewandelt werden kann, an der die gesamte Gemeinschaft beteiligt ist und das Projekt auf mehreren Ebenen verwalten kann

Das Decidim-Projekt braucht ein System seiner eigenen Führung, das es ihm ermöglicht, ausreichende Autonomie zu geniessen, um weiterhin nachhaltig zu wachsen, aus diesem Grund müssen Entscheidungs- und Konfliktbeilegungsstellen zur Verfügung gestellt werden.
****

Im Ergebnis dieses partizipatorischen Prozesses wurde im Februar 2019 die Decidim Free Software Association (_Associació de Software Lliure Decidim_ auf Katalanisch) gegründet. Lesen Sie mehr über die https://meta.decidim.org/assemblies/general-assembly-association[Generalversammlung der Decidim Association].
