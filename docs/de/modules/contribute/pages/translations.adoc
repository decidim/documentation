= Übersetzungen

Für die Übersetzung von Decidim verwenden wir eine Web-Plattform namens Crowdin, zugänglich auf https://translate.decidim.org/

Zur Zeit wird in mehr als 18 Sprachen übersetzt: Katalanisch, Tschechisch, Niederländisch, Finnisch, Französisch, Deutsch, Griechisch, Ungarisch,
Italienisch, Japanisch, Lettisch, Norwegisch, Polnisch, Portugiesisch, Rumänisch, Slowakisch, Spanisch und Schwedisch.

Da Decidim ein lebendiger und in ständiger Entwicklung befindlicher Prozess ist, ist es notwendig, die Übersetzungen zu pflegen, zu verbessern und speziell zu aktualisieren, wenn es eine neue Version gibt. Dafür gilt:

== Vorhandene Sprache

Sie können in der Sprache Ihrer Wahl um Erlaubnis bitten, zum Beispiel für Esperanto:

== Neue Sprache

Wenn Ihre Sprache noch nicht erstellt wurde, dann müssen wir es tun, da es notwendig ist, einige Anpassungen vorzunehmen. Sie müssen uns über das https://decidim.org/contact[Kontaktformular] kontaktieren.

== So funktioniert es

Falls Sie neugierig sind: Auf technischer Ebene haben wir einen Bot (den grossartigen decidim-bot), der regelmässig einen PR in die relevanten Branches (letzte Releases und develop) erstellt.

image::translation-bot.png[Decidim Bot in GitHub]

Wenn Sie eine neue Übersetzung ausprobieren wollen, bevor sie freigegeben wird, dann können Sie dies tun, indem Sie auf den xref:install:update.adoc#_from_git_repositories[relevanten Branch] verweisen, zum Beispiel `chore/l10n/develop`.

=== Gebietsschemata überprüfen

Sie können sicherstellen, dass neue Übersetzungen für alle Sprachen Ihrer Anwendung vollständig sind mit:

[source,console]
----
bin/rails decidim:check_locales
----

Standardmäßig wird dies gegen den Entwicklungszweig überprüfen. Wenn Sie auf einen anderen Zweig in Ihrer Gemfile verweisen, können Sie die TARGET_BRANCH Umgebungsvariable verwenden:

[source,console]
----
TARGET_BRANCH=release/0.22-stable bin/rails decidim:check_locales
----

Seien Sie sich bewusst, dass diese Aufgabe möglicherweise nicht in der Lage ist, alles zu erkennen, also stellen Sie sicher, dass Sie Ihre Anwendung vor dem Upgrade auch manuell überprüfen.

Wenn Sie 100% in Ihrer Crowdin-Sprache haben, können Sie ziemlich sicher sein, dass alles übersetzt ist.

== Regeln

* Alle Übersetzungen beginnen immer bei Englisch. Wenn Sie Änderungen an der englischen Sprache vorschlagen wollen, dann müssen Sie dies direkt in den Ruby-on-Rails-Übersetzungsdateien tun (wie `decidim-core/config/locales/en.yml`)
* Für jede Sprache (außer Englisch) können Sie keine Änderungen in den Ruby on Rails Übersetzungsdateien direkt vornehmen (zum Beispiel `decidim-core/config/locales/es.yml`), da diese Übersetzungen in Zukunft von decidim-bot ungültig gemacht werden könnten. Siehe Abschnitt "Wie es funktioniert".
* Wir versuchen, von Teilnehmenden anstelle von Nutzenden zu sprechen, wenn es möglich ist
* Auf Spanisch und Katalanisch folgen wir https://en.wikipedia.org/wiki/Gender_neutrality_in_Spanish[Gender Neutrality]
