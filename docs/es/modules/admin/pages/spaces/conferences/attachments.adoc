= Adjuntos

Los archivos adjuntos permiten a un administrador subir archivos estáticos a una conferencia.

Cuando se inicia una conferencia, es importante proporcionar a los ciudadanos tanta información como sea posible sobre ellos para que
puedan participar con conocimiento. Por eso es útil añadir archivos (adjuntos) con la información que
se considera relevante.

Opcionalmente, estos documentos pueden agruparse en *Carpetas*.

Se pueden encontrar en la sección "Medios de comunicación y enlaces":

imagen:spaces/conferences/attachments.png[Adjuntos de conferencias (backend)]

imagen:espacios/conferencias/media_links_frontend.png[Adjuntos de conferencias (frontend)]

Lee más sobre esto en xref:admin:spaces/conferences/media_links.adoc[Media links].

== Crear un nuevo archivo adjunto

image:spaces/attachments_admin.png[Ver los archivos adjuntos de una conferencia en la interfaz de administrador]

Para crear una nueva fase de una conferencia:

. Iniciar sesión como administrador
. Ir a la sección de la conferencia en la barra lateral
. Haga clic en la acción de edición de conferencia
. Haga clic en el enlace de adjuntos en la barra lateral
. Haz clic en el botón "Nuevo adjunto"

image:spaces/attachments_new_form.png[Crear un nuevo formulario adjunto]


.Crear archivo adjunto
|===
|Campo |Tipo |Descripción

|Adjunto o nombre de imagen
|Requerido
|¿Cuál es el título de este archivo adjunto?

|Peso
|Opcional
|¿Qué orden tendrá en relación con los otros archivos adjuntos. Tener un número más bajo significa una prioridad mayor. Por ejemplo, si tienes dos categorías, "Adjunto a" con el peso "10" y "Adjunto b" con el peso "0", entonces "Adjuntar b" será el primero al hacer el pedido.

|Descripción
|Requerido
|Una descripción larga que explica de qué trata este fichero.

|Carpeta
|Opcional
|A qué carpeta pertenece este archivo adjunto.

|Fichero
|Requerido
|Subir el archivo. Guía para el archivo: Debe ser una imagen o un documento. Para imágenes, utilice imágenes preferiblemente apaisadas, el servicio
recorta la imagen. Para archivos CSV, el separador entre columnas debe ser una coma (","). Tamaño máximo de archivo: 10MB. Allowed
file extensions depends in your server configuration.
|===

== Crear una nueva carpeta

image:spaces/attachments_new_folder_form.png[Crear una nueva carpeta para el formulario de adjuntos]


.Crear carpeta
|===
|Campo |Tipo |Descripción

|Nombre
|Requerido
|Nombre de la carpeta

|Peso
|Opcional
|Que orden tendrá en relación con las otras carpetas. Tener un número más bajo significa una prioridad mayor. Por ejemplo, si tiene dos carpetas, "Carpeta" con el peso "10" y "Carpeta b" con el peso "0", entonces "Carpeta b" será la primera vez que se haga el pedido.

|Descripción
|Requerido
|Una descripción larga que explica de qué trata esta carpeta.
|===
