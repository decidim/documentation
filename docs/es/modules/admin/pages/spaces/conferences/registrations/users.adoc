= Registros de usuario

Una vez que los participantes se hayan registrado, aparecerán en esta sección.

imagen:spaces/conferences/user_registrations.png[Conferencias de registro de usuarios (backend)]

Como administrador, puedes:

* Exportar los registros
* Confirmar registro

== Exportar

Es posible exportar los registros en múltiples formatos: CSV, JSON, y XLSX (Excel).

== Flujo

. Un participante se registra en la conferencia
. She receives a pending registration notification
image:spaces/conferences/user_registration_pending_notification.png[Notification for pending user registration]
. She receives a pending registration email
image:spaces/conferences/user_registration_pending_email.png[Email for pending user registration]
. Un administrador revisa y confirma el registro con el botón image:action_check.png[Confirm]
. El participante recibe una notificación confirmada de registro
image:spaces/conferences/user_registration_confirmed_notification.png[Notificación para registro confirmado de usuario]
. She receives a confirmed registration email with an calendar file (.ICS).
imagen:espacios/conferencias/usuario_registration_confirmed_email.png[Email para registro de usuario confirmado]
