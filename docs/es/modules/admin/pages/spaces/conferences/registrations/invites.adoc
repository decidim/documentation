= Invitaciones

Los administradores pueden invitar a participantes a unirse a la conferencia.

imagen:espacios/conferences/invites.png[Invitaciones de usuario (backend)]

== Flujo

. Un administrador envía una invitación para unirse a la conferencia a un participante no existente o existente
. El participante acepta la invitación

imagen:spaces/conferences/invite_participant_form.png[Invitar a un formulario participante]


.Invitar formulario de participante
|===
|Campo |Tipo |Descripción

|Tipo de asistente
|Requerido
|La persona invitada es un participante no existente o existente. ¿Ya tienen una cuenta creada en la plataforma?

|Nombre
|Requerido si es un participante no existente.
|Nombre del invitado.

|E-mail
|Requerido si es un participante no existente.
|Email de la persona invitada.

|Usuario
|Requerido si es un participante existente.
|Escriba al menos tres caracteres para buscar.

|xref:admin:spaces/conferences/registrations/types.adoc[Tipo de registro]
|Requerido
|Lo que xref:admin:spaces/conferences/registrations/types.adoc[registration type] tendrá este participante.
|===
