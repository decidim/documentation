= Registros

Como administrador de una conferencia usted puede administrar las inscripciones para la conferencia desde la plataforma.

Para hacerlo, tienes estas secciones de administración:

. xref:admin:spaces/conferences/registrations/types.adoc[**Tipos de registros**] te permite definir qué formas de registrar participantes
tendrá. Por ejemplo, si hay una serie de precios dependiendo de si los asistentes son estudiantes o trabajadores.
. xref:admin:spaces/conferences/registrations/users.adoc[**Registro de usuarios**] le permite confirmar las solicitudes para asistir a la conferencia.
. xref:admin:spaces/conferences/registrations/invites.adoc[**Invitaciones**] le permite invitar participantes a la conferencia.
. xref:admin:spaces/conferences/registrations/certificates.adoc[**Certificados de asistencia**] te permite configurar y enviar certificados
de asistencia en formato PDF a las personas que han ido a la conferencia.
