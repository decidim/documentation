= Procesos

Un proceso participativo es una secuencia de actividades participativas (p. ej. primero rellenar una encuesta, luego hacer propuestas,
discutiéndolas en reuniones virtuales o cara a cara, y finalmente priorizarlos) con el objetivo de definir y tomar una decisión sobre un tema específico.

Ejemplos de procesos participativos son: un proceso de elección de los miembros del comité (donde se presentan por primera vez las candidaturas,
luego debatido y finalmente se elige una candidatura), presupuestos participativos (donde se hacen las propuestas, valorado económicamente,
y votado con el dinero disponible), un proceso de planificación estratégica, la redacción colaborativa de un reglamento o norma,
el diseño de un espacio urbano o la producción de un plan de política pública.

Un concepto realmente importante para hacer un buen uso de Decidim es entender la relación entre las fases y los componentes
en un proceso participativo en Decidim:

image::process_steps_components.png[Relation between Steps and Components in a Process in Decidim]

Lo que muestra este diagrama es que para un proceso participativo puedes tener 7 fases:

. Configuration & Presentation
. Diagnóstico
. Creación de propuesta
. Selección de propuesta
. Resultados
. Evaluación
. Monitoreo

Dentro de cada una de estas fases, hay algunos componentes (como blog, reuniones, encuestas, debates, propuestas, resultados).
Algunos de estos componentes permiten algunas características dependiendo de la Fase que somos.

En esta sección, explicaremos cómo podemos configurar un proceso participativo en Decidim.

== Lista

Para configurar procesos participativos en la plataforma Decidim, haga clic en btn:[Processes] en el menú lateral del administrador. Aparecerá una lista
con los procesos existentes si los hay:

image::processes_list.png[Participatory processes list]

Puedes filtrar por los que son:

* Publicado / Sin Publicar
* Público / Privado

image::processes_list_filter.png[Participatory processes list filtered]

También puede buscar por título y controlar cuántos elementos hay en la lista.

Tiene 4 posibles acciones en esta lista después de crear un proceso participativo:

1. Exportar: enviar por correo electrónico la configuración de un proceso determinado. Puede importarse en otra instalación de Decidim.
1. Duplicar: para duplicar este proceso.
1. Configuración: para editar los metadatos y la configuración de un proceso.
1. Vista previa: cómo se verá una vez publicado.

.Nuevo formulario de proceso participativo: Información general
|===
|Campo |Tipo |Descripción

|Título
|Requerido
|Título del proceso participativo. Por ejemplo, "Participatory Budgeting 2020".

|Subtítulo
|Requerido
|Subtítulo. Por ejemplo, "Decidamos nuestras prioridades juntas"

|Slug URL
|Requerido
|Los slugs de URL se utilizan para generar las URLs que apuntan a este proceso. Solo acepta letras, números y guiones, y debe
comenzar con una letra. Ejemplo: si su dominio es 'example.org' y su slug 'participatory-budget-2020' entonces su URL será
https://example.org/processes/participatory-budget-2020

|Etiqueta

|Hashtag para Twitter

|Requerido
|Una breve explicación de lo que es su proceso participativo.

|Descripción
|Requerido
|Una larga explicación de lo que es su proceso participativo.

|Anuncio
|Opcional
|El texto que introduzca aquí se mostrará al usuario justo debajo de la información del proceso.

.Nuevo formulario de proceso participativo: Filtros
|===
|Campo |Tipo |Descripción

|Ámbitos habilitados
|Opcional
|Marque si desea tener filtrado de Scopes en este proceso.

|Alcance
|Opcional
|A qué xref:admin:scopes.adoc[Scope] pertenece este proceso.

|Profundidad del filtro de ámbito
|Opcional
|Restringir la profundidad del filtro de alcance, el filtro se mostrará de general al tipo de ámbito seleccionado. Esto solo es relevante si
tienes relaciones complejas en niños de alcance (como una dolla rusa). Por ejemplo, si tienes una Abuela -> Madre ->
Niño, Esta opción le permite elegir a la Madre, para que los participantes sólo puedan elegir al Niño. Este sería el caso
, por ejemplo, si tiene Provinces -> Ciudades -> Distritos, y el proceso es acerca de una ciudad en particular.

|Área
|Opcional
|A qué xref:admin:areas.adoc[Area] pertenece este proceso.
|===


.Nueva forma de proceso participativo: visibilidad
|===
|Campo |Tipo |Descripción

|Grupo de procesos
|Opcional
|Permite crear grupos de múltiples procesos participativos. Ideally for processes that are related between them, for
instance multiple squares in a City or multiple documents using the same participatory rules.

|Espacio privado
|Opcional
|Compruebe si este proceso sólo debe ser accesible por xref:admin:spaces/processes/private_participants.adoc[Participantes Privados]

|Promocionado
|Opcional
|Marque si desea que el proceso tenga más visibilidad en la lista pública de procesos. También será visible en el Bloque de Contenido de Proceso Participatorio
en la configuración xref:admin:homepage.adoc[Homepage]. Esto es accesible en la
btn:[Edit] acción en un proceso.
