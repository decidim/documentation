= Incrustar

A veces quieres incrustar algo de contenido en una página externa. Para esto puedes usar la función 'Embed'.

image:features/embed/example.png[Una tarjeta de propuesta integrada en otra página]

== Cómo insertar

. Navega al contenido que quieres incrustar.
. Haga clic en el enlace 'Embed' en la barra lateral. image:features/embed/link.png[]
image:features/embed/sidebar.png[]
. Copia el código de la modal.
imagen:características/embed/modal.png[]
. Pega ese código en la página externa donde quieras incrustarlo. El CMS o plataforma que estás utilizando necesita soporte
para cambiar el código HTML.

Un ejemplo de este código es:

[source,html]
----
<script src="https://meta.decidim.org/processes/roadmap/f/122/proposals/16243/embed.js"></script>
<noscript><iframe src="https://meta.decidim.org/processes/roadmap/f/122/proposals/16243/embed.html" frameborder="0" scrolling="vertical"></iframe></noscript>
----
