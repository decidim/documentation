= Respaldos

Mediante aprobaciones, los participantes pueden demostrar públicamente que quieren apoyar un contenido en particular, por ejemplo, una propuesta.

image:features/endorsements/list.png[Lista de endorsements]

Esto se hace a través del botón de la barra lateral. Los administradores pueden habilitarlos o desactivarlos paso a paso en un proceso participativo determinado, y también pueden definir permisos con autorizaciones.

imagen:features/endorsements/sidebar.png[Botón de Endsement en la barra lateral]

Cuando un participante pertenece a un grupo verificado, también puede respaldar como ese grupo seleccionando la identidad.

image:features/endorsements/modal.png[Seleccionar modal]

Por defecto se colapsa la lista de aprobaciones. Para verlo completamente, los visitantes necesitan también hacer clic en el enlace "(ver más)".

imagen:features/endorsements/full_list.png[Lista completa de endorsements]
