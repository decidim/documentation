= Seguidores

La siguiente sección contiene una lista de participantes y grupos que el participante está siguiendo actualmente. Seguir a otro participante o grupo en la plataforma, el participante recibirá notificaciones sobre la actividad realizada por aquellos otros participantes o grupos de la plataforma. Algunos participantes también pueden requerir que tengan que seguir al otro participante antes de poder intercambiar mensajes privados entre ellos.
