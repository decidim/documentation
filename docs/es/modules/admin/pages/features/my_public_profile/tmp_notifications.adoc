= Notificaciones

En esta sección los participantes pueden ver las notificaciones que el sistema les ha enviado. Por ejemplo, si el participante sigue un espacio participativo o una propuesta, reciben notificaciones relacionadas sobre las acciones que ocurren en estas secciones de la plataforma.

Se puede acceder a esta sección a través del icono de la campana en la barra de cabecera de la plataforma. El icono de la campana muestra resaltado como activo cuando hay notificaciones y atenuación cuando no hay notificaciones nuevas para el usuario en este momento.
