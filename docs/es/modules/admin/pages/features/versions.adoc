= Versiones

La función de versiones permite a un visitante ver la evolución de las diferentes versiones de recursos que pueden editarse,
propuestas o resultados parecidos.

Con las versiones es posible ver quién hizo el cambio, cuando el cambio se ha hecho y exactamente qué ha cambiado.

image:features/versions/side_by_side_escaped.png[Versiones en recursos]

== Ver las versiones

. Ve al contenido del que quieres ver la versión.
. Haga clic en el enlace "ver otras versiones" en la barra lateral
image:features/versions/sidebar.png[Ver el enlace de otras versiones en la barra lateral]
. Haga clic en la versión anterior que desea ver
image:features/versions/list.png[List of versions]
. Desde allí puede cambiar la visualización de las diferencias de versión
image:features/versions/unified_unescaped.png[Vista unescapada Unificada]

Es posible ver las diferencias de las versiones en dos formatos: lado a lado o unificado. En caso de que el contenido sea
en HTML, entonces también es posible ver el diff sin escapar y escapado, y vea el código HTML completo.

image:features/versions/side_by_side_unescaped.png[Vista unescapada paralela]
image:features/versions/unified_escaped.png[Vista unificada de escapado]
