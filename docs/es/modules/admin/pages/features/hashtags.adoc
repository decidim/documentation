= Etiquetas

Las etiquetas son una forma de clasificar el contenido globalmente en la plataforma y hacerlo más fácil de buscar a través de estas categorizaciones. Permite que diferentes contenidos relacionados sean fácilmente detectables bajo el mismo tema. La funcionalidad similar se utiliza a menudo en otras plataformas de redes sociales.

Las etiquetas pueden establecerse para diferentes registros dentro de la plataforma, tales como espacios participativos. También se pueden generar para el contenido creado por los participantes para facilitar el descubrimiento del contenido. Algunos componentes también pueden permitir establecer hashtags sugeridos o hashtags específicos para todos los registros enviados por los participantes.
