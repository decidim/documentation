= Notificaciones

== El menú de notificaciones

La mayoría de las acciones en la plataforma generan notificaciones para que los pantalones sepan cuándo hay cosas nuevas que ver.

Esto es accesible desde el elemento de menú `Notificaciones` (image:icon_bell.png[Icono de notificación]) en la cabecera, después de que un participante se haya conectado.

Para ver las notificaciones:

. Registrarse como participante
. Haga clic en el icono de notificaciones en el encabezado

Si hay notificaciones, el participante verá el icono con un color image:icon_bell_on.png[Icono de notificación con color]

image:features/notifications/notifications.png[Ejemplo de página de notificaciones cuando hay notificaciones]

image:features/notifications/no_notifications_yet.png[Ejemplo de página de notificaciones cuando no hay notificaciones]
