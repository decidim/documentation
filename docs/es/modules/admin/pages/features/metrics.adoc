= Métricas

NOTE: ¿Buscas cómo activar esta característica técnicamente? Ir a la guía xref:develop:metrics.adoc[Métricas en la guía de desarrolladores]

Con Métricas los participantes pueden ver la evolución en el tiempo de algunos recursos, tales como Propuestas, Apoyos, Respaldos, Seguidores, Participantes, Propósitos Aceptados, Comentarios, etc. Puede ver un ejemplo real de esto en https://meta.decidim.org/processes/roadmap/all-metrics[Metadecidim Roadmap process].

Para que esto funcione, necesita ser el primero xref:develop:metrics.adoc[configurado técnicamente] y también habilitado por la configuración en el espacio participativo (casilla `Mostrar métricas`).

Entonces esta sección será visible en la página de inicio del espacio.

imagen:características/métricas/ejemplo.png[Ejemplo de métricas]

Al hacer clic en "Mostrar todas las métricas", los visitantes pueden ver otras métricas y descargar estos datos en formato CSV.
