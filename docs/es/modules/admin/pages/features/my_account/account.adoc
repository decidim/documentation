= Cuenta

En esta sección es posible hacer modificaciones que serán visibles en los participantes xref:features/my_public_profile. doc[public profile] y también modificar la dirección de correo electrónico o el idioma que la plataforma utilizará con el usuario.

. Inicia sesión como participante
. Haga clic en el nombre del participante en la cabecera
. Haz clic en "Mi cuenta"

image:features/my_account/account.png[Mi formulario de cuenta]


.Configuración del participante - Formulario de mi cuenta
|===
|Campo |Tipo |Descripción

|Avatar
|Opcional
|Avatar o foto para el participante. Guía para la imagen: Preferiblemente una imagen de paisaje que no tiene ningún texto.
El servicio cultiva la imagen. Tamaño máximo de archivo: 5MB

|Tu nombre
|Requerido
|El nombre del participante.

|Apodo
|Requerido
|El apodo del participante.

|Tu email
|Requerido
|El correo electrónico del participante, donde recibirán notificaciones, recuperación de contraseñas, etc. If it's changed it needs to be
confirmed.

|URL personal
|Opcional
|Metadatos que se muestran en el perfil del participante.

|Acerca de
|Opcional
|Metadatos que se muestran en el perfil del participante.

|Local
|Requerido
|Elija el idioma que desea utilizar para navegar y recibir notificaciones en Decidim
|===

Desde esta página también es posible modificar la contraseña del participante.
