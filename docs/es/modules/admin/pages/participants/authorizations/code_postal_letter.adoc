= Código por autorización de carta postal

This authorization allows a participant to request for a verification code to be sent to its address, to confirm that she
lives or works in this place. She'll need to then fill the code in the platform.

El proceso es:

. Los participantes solicitan que se envíe un código de verificación a su dirección.
. Un administrador envía la carta a su dirección con el código de verificación.
. Un administrador marca la letra como enviada.
. Una vez que hayas marcado la carta como enviada, el participante podrá introducir el código.
. If this code matchs, then she gets verified.

== 1. Un participante solicita el código de verificación

By going to the authorization section in its profile, or by clicking on the action button if this permission is requested,
a participant can see the form for filling in her full address to request the verification code.

image:authorizations_code_postal_letter_request.png[Código por solicitud de carta postal por participante]

If she tries to edit it, she'll see this message:

imagen:authorizations_code_postal_letter_edit.png[Editar la solicitud de carta postal]

Esto se debe a que la carta podría ser enviada. Si esto necesita ser corregido, entonces el participante necesita
para contactar con la organización.

== 2. Un administrador revisa esta solicitud y envió la carta

En el panel de administración, el administrador puede revisar la solicitud dirigiéndose al "Código por carta postal" en la sección "Participantes".

image:authorizations_code_postal_letter_ongoing.png[Código por carta postal panel en curso en admin]

Here she can see the verification code and can send it to the participant by mail. After the code is sent she can mark it
as sent with the icon image:action_mark_as_sent.png[Mark as sent]. También se mostrará cuando la carta fue enviada.

== 3. Un participante rellena el código de verificación

After the participant has received the code, she can go to it's account settings and click in the "Code by postal letter"
verfication method.

image:authorizations_code_postal_letter_verify.png[Código por carta postal en curso en la cuenta del participante]

Then she'll see the form for confirming the code.

image:authorizations_code_postal_letter_confirm.png[Código por formulario de confirmación de carta postal]

== 4. El código de verificación coincide o no

Si el código de verificación coincide, el participante verá el mensaje "Felicidades". Has sido verificado con éxito".

Por otro lado, si el código de verificación no coincide, el participante verá el mensaje "Tu código de verificación
no coincide con el nuestro. Por favor, comprueba la carta que te hemos enviado."

Después de ser verificado, como en otras verificaciones, pueden verlo en la configuración de su cuenta.

image:authorizations_code_postal_letter_verified.png[Verified by code by postal letter]
