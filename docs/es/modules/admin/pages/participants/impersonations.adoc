= Suplantaciones de participantes

For participants that don't have the knowledge or don't have an email for registering
an account, there's the Impersonation feature.

This allows an 'Administrator' or 'Participant manager' to search through a
Verification system for an already existing participant and also to create a
participant without email.

NOTE: At the code and the User Interface we say both *Impersonation* and *Managed
Participants*. Es lo mismo.

== Panel

image::participants_impersonations.png[Admin's Impersonations panel]

Este es el panel donde puedes encontrar a todos los participantes:

* filtrando por participantes administrados o no gestionados
* buscando por nombre

Después de hacer clic en `Administrar nuevo participant` irás al formulario para ingresar
los datos personales para comprobar la verificación:

image::participants_impersonations_form.png[Admin's Impersonations form]

NOTE: Si no ves el botón `Administrar nuevo participante`, es porque esta función
solo funciona cuando tienes una Verificación de tipo `direct` (también conocida como
como `form authorizations`). Vea en su xref:admin:system.adoc[panel del sistema] que
`Autorizaciones disponibles` están habilitadas. Puedes aprender más sobre cómo programar
tu autorización de formulario en https://github.com/decidim/decidim/blob/develop/decidim-verifications/README.md[decidim-verification README].

Después de confirmar estos datos, habrá una sesión para el participante durante
30 minutos:

image::participants_impersonations_user.png[Impersonated user session]

Finally, it's also possible to Promote a participant, meaning that after a
participant has been managed, an administrator can add the email and send her
an Invitation:

image::participants_impersonations_promotion.png[Admin's promotion Impersonations]
