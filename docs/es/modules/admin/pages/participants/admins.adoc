= Administradores

En la página de listado de administradores puede ver todos los administradores de la plataforma:

image:admins.png[Admins list]

Aquí puedes:

* invitar nuevos administradores
* revocar permisos de administradores
* ver cuándo fue la última vez que un administrador se conectó

For inviting a new administrator, you need to go to the button "New user" and fill
the form with the admin username, email and which role will she have:

* Administrador: para dar acceso completo a la plataforma
* Gestor de participantes: dar permiso para hacer solo xref:admin:participants/impersonations.adoc[Impersonations]

image:admins_invite.png[Invitar participante como administrador de formulario]

Puede invitar a un participante ya inscrito o no inscrito.
