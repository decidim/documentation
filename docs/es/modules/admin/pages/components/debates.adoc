= Debate

El componente Debate permite a la gente tener discusiones, sin votación ni priorización. También permite cerrarlos,
agregando conclusiones o un resumen de lo que fue el debate.

Desde este punto de partida, podría haber otras configuraciones, como:

* Permitir la creación de debates por los participantes
* Para tener debates con una fecha fija de inicio y fin o abierta
* Mostrar respaldos (apoyo público) o no

Algunos ejemplos de donde se usó este componente:

* https://meta.decidim.org/processes/roadmap/f/219/[Proponer nuevas funcionalidades para el software Decidim en Metadecidim]

image:components/debates/example01.png[Debates listando ejemplo]
image:components/debates/example02.png[Ejemplo de debate]

Para configurar el componente Debate:

. Iniciar sesión como administrador
. Ir al panel de administración
. En la barra lateral principal, haga clic en el botón para el espacio para el que desea configurar el componente.
Por ejemplo, podría ser "Procesos", "Colmenas" o "Conferencias".
. Ir a los componentes
. Haga clic en el botón "Añadir componente"
. Haga clic en "Debate"
. Rellene el formulario xref:_add_component[Añadir componente]

== Añadir componente

image:components/debates/component.png[Añadir formulario de componente]


.Añadir componente: Formulario de debate
|===
|Campo |Tipo |Descripción

|Nombre
|Requerido
|¿Cuál es el título de este componente. Por ejemplo, "Debates"

|Posición del pedido
|Opcional
|¿Qué orden tendrá en relación con los demás debates. Tener un número más bajo significa una prioridad mayor.
Por ejemplo, si tienes dos debates, "Debate a" con el peso "10" y "Debate b" con el peso "0", entonces "Debate b" será el primero en ordenar.
|===


.Añadir componente: Formulario de debate - Configuración global
|===

|Ámbitos habilitados
|Opcional
|Marque si desea tener filtrado de Scopes en este componente.

|Alcance
|Opcional
|A qué xref:admin:scopes.adoc[Scope] pertenece este componente.

|Ámbito global
|Opcional
|

|Comentarios habilitados
|Opcional

== Permisos

Un administrador puede elegir qué tipo de xref:customize:authorizations.adoc[Authorizations] un participante necesita tener que hacer
ciertas acciones en los debates:

* Crear
* Respaldar

==== Tipos de debate

Es posible tener dos tipos de debates:

. Finalizar: con fecha de inicio y fin
. Abrir: sin fecha de inicio y fin

Esto se muestra públicamente en la lista de debate.

=== Cerrar formulario de debate

Se puede cerrar un debate. Esto es útil para añadir conclusiones. Después de cerrar un debate, no se puede editar ni comentar más

image:components/debates/close_debate_backend.png[Cerrar formulario de debate backend]

Take in account that if the debate was created by a participant then only that
participant can close it.

imagen:components/debates/close_debate_frontend.png[Cerrar formulario de debate frontend]


.Cerrar formulario de debate
|===
|Campo |Tipo |Descripción

|Conclusiones
|Requerido
|¿Cuál es la conclusión de este debate?
|===

Las conclusiones se muestran públicamente con la fecha y hora de cierre.
