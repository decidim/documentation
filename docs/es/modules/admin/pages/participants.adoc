= Participantes

A veces como administrador necesitarás hacer ciertas tareas con los participantes, entre ellos:

* Dar permisos a otros administradores para que puedan administrar el contenido de la plataforma
* Para verificar grupos de usuarios (organizaciones o colecciones)
* Para verificar participantes
* Reconocer que un participante tiene un estatus especial en la plataforma, con Oficializaciones
* Autorizar que una persona tiene derecho a voto, con Autorizaciones
* Para contactar con un participante

Puede acceder a esta sección en la barra lateral principal del panel de administración.

imagen:participants_menu.png[Menú de participantes]
