Usted puede controlar cómo es la página principal de su organización. Para ello tiene la sección Configuración -> Página de inicio a través del panel de administración:

image::admin_homepage.png[Decidim Admin Homepage]

== Cómo funciona

Esto significa que cada sección de la página principal se llama **bloque de contenido**.

Por ejemplo, este es el bloque de contenido *Cómo participar*:

image::homepage_how_to_participate.png[How to participate example]

Para gestionar estos contenidos necesitas arrastrar y soltar el contenido entre las dos columnas, a la izquierda son los Activos y a la derecha están los bloques de contenido inactivos.
