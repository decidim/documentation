= Componentes

include::parcial$components_list.adoc[]

Para configurar los componentes, haga clic en *Componentes* desde el submenú espacial. Aparecerá una lista mostrando los componentes
que ya han sido configurados para el espacio.

image::spaces/components.png[Components of space]

Para configurar un nuevo componente, haga clic en *Añadir componente* de la parte superior derecha de la pantalla y seleccione el tipo de componente
que desea configurar en el menú desplegable.

image::spaces/components_new_dropdown.png[Add a component in a space]

== Acciones

|===
|Icono |Nombre |Definición

|image:action_manage.png[Administrar icono]
|Gestionar
|Administrar todos los recursos dentro de un componente. Por ejemplo, todas las Propuestas de un componente Proponal, las Reuniones
en un componente Reunión, etc.

|image:action_publish.png[Publicar icono]
|Publicar
|Para publicar un componente. Esto significa que el componente será visible para el público.

|image:action_unpublish.png[Despublicar icono]
|No publicar
|Para despublicar un componente. Esto significa que el componente será invisible para el público.

|image:action_configure.png[Configurar icono]
|Configurar
|Para configurar un componente con las reglas específicas. Depende en el tipo de componente. Por ejemplo, en el caso de las reuniones:
son comentarios activados, los participantes pueden crear reuniones, etc.

|image:action_permissions.png[Icono de permisos]
|Permisos
|Para configurar qué xref:customize:authorizations.adoc[Authorization] será necesario para realizar ciertas acciones en
este componente. Por ejemplo, en el caso de las Propuestas, que la Verificación será necesaria para crear una nueva propuesta o
para dar apoyos.

|image:action_share.png[Compartir icono]
|Compartir
|Compartir en privado antes de publicar este componente. Útil para revisar con otras personas dentro de su organización.

|image:action_delete.png[Borrar icono]
|Eliminar
|Para eliminar este componente. If there are contents most of the components will not let you delete them so it doesn't break
relations with other resources. En esos casos se recomienda anular la publicación del componente.
|===
