= Moderación

Las moderaciones dentro de un espacio funcionan como xref:global_moderations.adoc[Moderaciones globales].

La diferencia principal es que si así lo deseas, puedes invitar moderadores de este espacio
específico y solo tendrán acceso a los informes hechos para
contenidos de este espacio.

Los moderadores son una especie de administradores del espacio. Vea por ejemplo xref:spaces/processes/admins.adoc[administradores de procesos participativos].
