= Categorías

Las categorías (y subcategorías) se utilizan para clasificar los recursos dentro de un espacio.

An administrator can define them, can be assigned to when creating resources, and then participants can filter the
different resources by these categories. Por ejemplo, pueden establecerse en propuestas, reuniones y debates.

Como ejemplo de este mecanismo en acción puede verlo en el proceso https://meta.decidim.org/processes/roadmap/f/122/[Proponer nuevas funcionalidades para el software Decidimformat@@1:

. Los administradores han definido las categorías en el proceso.
. Los participantes pueden crear propuestas que tengan una categoría.
. Los participantes pueden filtrar por estas categorías y navegar entre todas las propuestas.

imagen:spaces/categories_sidebar.png[Filtrar categorías en propuestas]

image:spaces/categories_form.png[Selecciona una categoría al crear una propuesta]

NOTE: Una vez que una categoría está en uso no se puede eliminar, ya que hay recursos que la están utilizando.

Decidim tiene otras maneras de clasificar recursos, por ejemplo xref:admin:scopes.adoc[Scopes] y xref:admin:features/hashtags.adoc[Hashtags].
La diferencia principal es que las categorías se pueden definir en un espacio determinado. Los ámbitos son globales para toda la plataforma, y los participantes definen Hashtags
.

Las categorías pueden ser anidadas, lo que significa que una categoría puede tener subcategorías.

== Crear una nueva categoría

Para configurar una nueva categoría, vaya al panel de administración del espacio y haga clic en la pestaña "Categorías".

image:spaces/categories.png[Ver categorías en una página de administración de espacio]

Luego haga clic en "Añadir categoría" y rellene el formulario.

imagen:spaces/categories_new_form.png[Crear un nuevo formulario de categoría]


.Crear categoría
|===
|Campo |Tipo |Descripción

|Nombre
|Requerido
|¿Cuál es el nombre de esta categoría.

|Peso
|Opcional
|¿Qué orden tendrá en relación con las otras categorías. Tener un número más bajo significa una prioridad mayor. Por ejemplo, si tienes dos categorías, "Categoría" con el peso "10" y "Categoría b" con el peso "0", luego "Categoría b" será primero cuando se haga el pedido.

|Descripción
|Requerido
|Una descripción larga que explica de qué trata esta categoría.

|Padres
|Opcional
|¿Cuál es la categoría padre.
|===
